## 관찰과 조작

상태 준비·측정·에너지 계산·각도 갱신을 한 단계씩 따라가세요. 입력값을 바꾸거나 선택 버튼을 눌러 그림과 수치가 함께 바뀌는지 확인하세요. 키보드로도 모든 입력을 조작할 수 있습니다.

## 그림 없이 이해하기

새 각도의 상태를 다시 준비하고 에너지를 새로 평가해야 합니다. 일반적으로 최적화 갱신에도 추가 평가가 필요합니다.

## 적용 조건과 출처

설명용 유한 차원 모형입니다. 표시된 수치는 실제 분자 계산값이 아닌 경우 실험 화면에 모형 조건을 표시합니다.

기존 개념 노트 `concept-vqe-algorithm.html`의 검토된 예시와 계산을 독립 실험으로 분리했습니다.

## 확인할 결과

각도를 갱신한 뒤 이전 측정값을 그대로 써도 될까요? 새 각도의 상태를 다시 준비하고 에너지를 새로 평가해야 합니다. 일반적으로 최적화 갱신에도 추가 평가가 필요합니다.
