## 관찰과 조작

각 자리의 추가 버튼을 누릅니다. 이미 점유된 자리에 다시 추가하거나, 반대 스핀 쌍과 같은 스핀의 다른 공간 점유를 비교합니다. 각 자리의 제거와 전체 초기화도 가능합니다.

## 그림 없이 이해하기

Aα를 두 번 추가하면 총 전자 수는 1에 머뭅니다. Aβ를 추가하면 A의 전자는 2개가 됩니다. Aα·Bα처럼 스핀이 같고 공간이 다른 점유도 가능합니다.

## 적용 조건

공간 오비탈 A·B와 스핀 α·β를 고정한 점유 모형입니다. 전자 반발과 에너지 순서, 실제 바닥상태를 계산하지 않습니다. 상자는 실제 위치 구획이 아니며 화살표는 스핀 표기입니다.
