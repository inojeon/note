## 비교할 것

0°·±90°·180°를 비교하며 X와 Z의 읽기 회로, 확률, 항별 곱셈 표를 읽습니다.

## 그림 없이 읽는 결과

+ 상태는 X 평균 1, Z 평균 0이므로 E=1−0.5=0.5입니다. 0 상태는 X 평균 0, Z 평균 1이므로 E=0.8입니다.

## 모형과 조건

공통 설명용 H=I−0.5X−0.2Z의 정확한 기대값입니다. I는 측정하지 않고 1로 사용하며 X·Z는 별도 상태 준비로 읽습니다.
