## 두 방향 사이의 계수가 짝을 이루는 행렬 {#행과-열을-바꿔도-같은-행렬은-왜-특별할까}

실수 행렬 \(A=\begin{pmatrix}2&1\\1&1\end{pmatrix}\)를 보겠습니다. 첫째 입력에서 둘째 출력으로 가는 계수와 둘째 입력에서 첫째 출력으로 가는 계수가 모두 1입니다. 이처럼 대각선을 사이에 두고 마주 보는 원소가 같으면 **대칭행렬**입니다.

실험은 두 비대각 원소를 함께 \(b\)로 바꿉니다. \(b=0\)에서는 행렬이 이미 대각이고 고유방향은 두 좌표축입니다. \(b\)가 달라지면 방향이 기울지만 두 고유방향은 계속 서로 수직입니다.

## 대칭과 켤레전치

행과 열을 맞바꾸는 연산을 **전치**라고 하고 \(A^T\)로 적습니다. 실수 대칭행렬은 \(A^T=A\), 성분으로는 \(A_{ij}=A_{ji}\)를 만족합니다.

복소수에서는 행과 열을 바꾼 뒤 각 원소의 켤레도 취합니다. 이 **켤레전치**를 \(A^\dagger\)라고 씁니다. \(A^\dagger=A\)이면 **에르미트 행렬**이라고 합니다. 예를 들어

$$H=\begin{pmatrix}2&i\\-i&1\end{pmatrix}$$

에서 마주 보는 두 원소 \(i,-i\)는 서로 켤레입니다. 대각 원소는 자기 자신의 켤레와 같아야 하므로 실수입니다. 실수만 가진 에르미트 행렬이 바로 실수 대칭행렬입니다.

이 조건은 분자의 모양이 좌우 대칭이라는 뜻과 다릅니다. 여기서는 행렬 원소의 관계를 말합니다. 에르미트 행렬이라고 비대각 원소가 모두 0인 것도 아닙니다.

## 실수 고유값과 수직인 기준

실수 대칭행렬에는 실수 고유값과 정규직교 고유기저가 있습니다. 복소수 에르미트 행렬도 고유값은 실수이고 복소수 내적으로 정규직교하는 고유기저를 고를 수 있습니다. 그래서 [관측량](../observable/)과 [해밀토니안](../hamiltonian/)을 표현하는 데 사용됩니다.

실험의 \(b=1\)에서 고유값은 \((3+\sqrt5)/2\approx2.618\), \((3-\sqrt5)/2\approx0.382\)입니다. 두 고유벡터의 성분은 다르지만 내적을 계산하면 0입니다.

{{< answer title="서로 다른 고유값의 방향이 수직인 이유" >}}
\(Au=\lambda u\), \(Av=\mu v\)라고 하겠습니다. 대칭성 때문에 \(u^TAv=(Au)^Tv\)입니다. 왼쪽은 \(\mu u^Tv\), 오른쪽은 \(\lambda u^Tv\)여서 \((\lambda-\mu)u^Tv=0\)입니다. 두 고유값이 다르면 \(u^Tv=0\)이어야 합니다. 같은 고유값에 속하는 벡터는 자동으로 모두 수직인 것은 아니지만, 그 공간 안에서 정규직교 기저를 선택할 수 있습니다.
{{< /answer >}}

## 대칭이면 양수라는 뜻일까

\(\begin{pmatrix}-1&0\\0&2\end{pmatrix}\)는 대칭이지만 고유값에 −1이 있습니다. 대칭이라는 조건만으로 고유값이 양수라고 결론낼 수 없습니다. 또 대칭행렬이 모든 벡터를 그대로 두거나 길이를 유지하는 것도 아닙니다.

에르미트 조건이 보장하는 것은 고유값이 **실수**라는 사실입니다. 에너지의 음수·양수는 선택한 기준 에너지에 따라 해석해야 합니다. 음수 에너지가 나왔다고 계산이 잘못된 것은 아닙니다.

{{< answer title="심화: 양의 정부호와 에너지의 부호" >}}
실수 대칭행렬에서 영벡터가 아닌 모든 x에 대해 \(x^TAx>0\)이면 **양의 정부호**라고 합니다. 정규직교 고유기저에서 쓰면 \(x^TAx=\sum_j\lambda_j c_j^2\)이므로 모든 고유값이 양수라는 조건과 같습니다. 에르미트 행렬에서는 \(x^\dagger Ax\)로 바꿉니다. 모든 고유값이 0 이상이면 양의 준정부호입니다. 실험의 b=0에서 고유값은 2와 1이라 양의 정부호이지만 b=2에서는 작은 고유값이 음수로 바뀝니다.
{{< /answer >}}

## 확인 문제 {#스스로-확인하기}

**1. \(\begin{pmatrix}1&2+i\\2-i&3\end{pmatrix}\)는 에르미트 행렬인가요?**

{{< answer >}}
네. 대각 원소 1과 3은 실수이고 비대각 원소 \(2+i\), \(2-i\)는 서로 켤레입니다. 행과 열을 바꾸고 켤레를 취하면 원래 행렬입니다.
{{< /answer >}}

**2. 단위행렬의 두 고유벡터 (1,0), (1,1)은 수직이 아닙니다. 대칭행렬의 성질에 어긋나나요?**

{{< answer >}}
아닙니다. 이 둘의 고유값은 모두 1입니다. 서로 다른 고유값의 고유벡터에 대한 자동 직교 조건을 적용할 수 없습니다. 같은 고유공간에서 (1,0), (0,1)처럼 정규직교 기저를 선택할 수 있다는 성질은 여전히 성립합니다.
{{< /answer >}}
