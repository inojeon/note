## 고유방향으로 입력을 나누기 {#기준을-바꾸면-행렬-계산이-단순해질까}

\(A=\begin{pmatrix}2&1\\1&2\end{pmatrix}\)는 \((1,1)\) 방향을 3배, \((1,-1)\) 방향을 1배 합니다. 이 두 고유벡터는 서로 다른 방향이어서 평면의 [기저](../basis/)가 됩니다.

입력 \((1,0)\)을 이 기저로 적으면 좌표는 \((1/2,1/2)\)입니다. 첫 좌표에 3, 둘째 좌표에 1을 곱하면 \((3/2,1/2)\)이고, 원래 좌표로 복원하면 \((2,1)\)입니다. 행렬을 직접 곱한 결과와 같습니다.

이처럼 고유벡터를 기저로 선택해 각 좌표에 배율만 곱하도록 만드는 것이 **대각화**입니다. 아래의 P, D, P⁻¹을 선택하면 각각이 맡는 계산을 볼 수 있습니다.

## 기저를 바꾸고, 배율을 곱하고, 돌아오기

고유벡터를 열로 모은 행렬과 배율을 모은 행렬은

$$P=\begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad D=\begin{pmatrix}3&0\\0&1\end{pmatrix}$$

입니다. \(P\)는 고유기저의 좌표 \((a,b)\)를 원래 벡터 \((a+b,a-b)\)로 복원합니다. 반대로 \((x,y)\)에서 \(a+b=x\), \(a-b=y\)를 풀면 \(a=(x+y)/2\), \(b=(x-y)/2\)입니다. 이 되돌리기가 \(P^{-1}\)입니다.

$$P^{-1}=\frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}.$$

따라서 전체 변환은 오른쪽부터 **좌표 변환 → 배율 적용 → 복원** 순서로 계산합니다.

$$Av=PDP^{-1}v,\qquad A=PDP^{-1}.$$

대각행렬 \(D\)의 대각선 밖에는 0만 있습니다. 그래서 한 좌표가 다른 좌표의 출력에 섞이지 않고 각각 독립적으로 배율을 적용받습니다.

## 2차원 예를 단계별로 보기

\(v=(1,0)\)에 위 세 단계를 직접 적용하겠습니다.

$$P^{-1}v=(1/2,1/2),\quad D(P^{-1}v)=(3/2,1/2),$$
$$P(3/2,1/2)=(3/2+1/2,3/2-1/2)=(2,1).$$

두 번 변환하면 각 고유방향에 배율을 두 번 곱하므로 9와 1이 됩니다. \(A^2v=(5,4)\)이고, 실제로 \(A(2,1)=(5,4)\)입니다. 여러 번 계산할 때 \(A^k=PD^kP^{-1}\)를 쓰면 대각선의 수만 거듭제곱하면 됩니다.

실수 대칭행렬에서는 고유벡터를 서로 수직이고 길이 1이 되도록 고를 수 있습니다. 그 열을 모은 \(Q\)는 \(Q^{-1}=Q^T\)를 만족해 \(A=QDQ^T\)로 적습니다. 위 \(P\)의 열은 길이가 \(\sqrt2\)이므로 \(P^{-1}=P^T\)라고 쓰면 안 됩니다.

## 모든 행렬이 대각화되지는 않는다

\(n\)차 정사각행렬을 대각화하려면 선형 독립인 고유벡터 \(n\)개가 필요합니다. 고유값을 구하는 것만으로는 충분하지 않습니다. 예를 들어 \(\begin{pmatrix}1&1\\0&1\end{pmatrix}\)의 고유값은 1뿐이고 고유벡터는 가로축 방향뿐입니다. 평면의 기저를 만들 수 없어 대각화되지 않습니다.

반대로 고유값이 반복된다고 항상 실패하는 것도 아닙니다. 항등행렬은 모든 벡터를 그대로 두므로 어느 기저든 고유기저이고 이미 대각행렬입니다. 고유값 0도 대각화의 장애가 아닙니다. 필요한 역행렬은 고유벡터를 모은 \(P\)의 역행렬이며 \(A\) 자체가 가역일 필요는 없습니다.

## 확인 문제 {#스스로-확인하기}

**1. \(v=(0,1)\)을 위 고유기저의 좌표로 바꾸고, D를 적용한 뒤 복원하세요.**

{{< answer >}}
\(P^{-1}v=(1/2,-1/2)\), \(D(1/2,-1/2)=(3/2,-1/2)\)입니다. 복원하면 \((3/2-1/2,3/2+1/2)=(1,2)\)로, A의 둘째 열과 같습니다.
{{< /answer >}}

**2. P의 두 열을 바꾸고 D를 그대로 두면 같은 A가 되나요?**

{{< answer >}}
아닙니다. 이제 첫 고유벡터에 잘못된 배율이 붙습니다. 고유벡터의 열 순서를 바꿀 때 대응하는 고유값의 순서도 함께 바꿔야 합니다.
{{< /answer >}}
