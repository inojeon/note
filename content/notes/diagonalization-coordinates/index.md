## 같은 변환을 다른 좌표로 읽기 {#같은-행렬을-다른-기저로-보면-무엇이-달라질까}

\(A=\begin{pmatrix}2&1\\1&2\end{pmatrix}\)와 입력 벡터를 고정하겠습니다. 이제 벡터 자체를 돌리는 대신, 벡터를 읽는 두 기준 방향을 돌립니다. [기저와 좌표](../basis/)에서 같은 \((3,2)\)가 다른 계수로 표현되었던 것처럼, 입력과 출력 모두의 좌표가 달라집니다.

아래 실험에서 입력 방향을 그대로 두고 ‘기저 0도’와 ‘기저 45도’를 비교해 보세요. 왼쪽의 실제 입력과 출력은 움직이지 않지만 오른쪽 좌표와 행렬 원소가 바뀝니다.

## 입력과 출력 좌표를 함께 바꾸기

서로 수직이고 길이 1인 새 기저를 열로 모은 행렬을 \(Q\)라고 하겠습니다. 새 좌표 \(c\)로부터 원래 벡터를 복원하면 \(v=Qc\)입니다. 여기에 \(A\)를 적용한 출력은 \(AQc\)입니다.

아직 이 출력은 원래 좌표로 적혀 있습니다. 출력도 새 좌표로 읽으려면 \(Q^{-1}=Q^T\)를 왼쪽에서 곱합니다.

$$[Av]_Q=Q^TAQc,\qquad B=Q^TAQ.$$

따라서 \(B\)는 같은 변환을 새 기저에서 나타낸 행렬입니다. \(AQ\)에서 계산을 멈추면 입력은 새 좌표, 출력은 원래 좌표라는 서로 다른 기준을 사용하게 됩니다.

## 비대각 원소가 의미하는 것

45도 회전 기저를 \(q_1=(1,1)/\sqrt2\), \(q_2=(-1,1)/\sqrt2\)로 고르면 첫 방향은 A에 의해 3배, 둘째 방향은 1배 됩니다. 둘 다 고유벡터이므로

$$B=\begin{pmatrix}3&0\\0&1\end{pmatrix}.$$

\(B_{12}\)는 두 번째 기저 벡터를 입력했을 때 출력에 첫 번째 방향 성분이 얼마나 생기는지를 나타냅니다. 고유기저에서는 각 입력 방향이 자기 직선에 남아 이 성분이 0입니다. 기저가 25도일 때는 서로 다른 새 좌표 성분이 섞이므로 비대각 원소가 남습니다.

원래 입력 \(v=(1,0)\)을 예로 들면 새 좌표는 \((1/\sqrt2,-1/\sqrt2)\)입니다. B를 적용해 \((3/\sqrt2,-1/\sqrt2)\)를 얻고 복원하면

$$\frac3{\sqrt2}q_1-\frac1{\sqrt2}q_2
=\frac32(1,1)-\frac12(-1,1)=(2,1).$$

원래 행렬로 계산한 \(Av\)와 정확히 같습니다. 앞 대각화 노트의 두 번째 고유벡터는 \((1,-1)\)이었으므로 여기의 \(q_2\)와 부호가 반대입니다. 기저의 부호를 바꾸면 그 방향의 좌표 부호도 함께 바뀌어 복원 결과는 같습니다.

## 바뀌는 것과 유지되는 것

좌표와 행렬 원소는 바뀌지만, 원래 공간의 입력과 출력, 고유값 3과 1은 그대로입니다. 두 대각 원소의 합인 **대각합**은 어느 기저에서도 4입니다. 행렬식도 \(2\times2-1\times1=3\)에서 \(3\times1-0\times0=3\)으로 유지됩니다.

{{< answer title="정규직교가 아닌 기저에서는" >}}
선형 독립인 기저 열을 모은 행렬을 S라고 하면 좌표 변환식은 \(S^{-1}AS\)입니다. 전치를 쓸 수 있는 것은 \(Q^{-1}=Q^T\)인 정규직교 기저에서만입니다. 복소수 정규직교 기저에서는 전치 대신 켤레전치 \(Q^\dagger\)를 씁니다. 고유값·대각합·행렬식은 일반적인 가역 기저 변환에서도 유지됩니다.
{{< /answer >}}

## 확인 문제 {#스스로-확인하기}

**1. 45도 기저에서 입력 좌표가 (1,0)이면 실제 입력과 출력은 무엇인가요?**

{{< answer >}}
실제 입력은 첫 기저 벡터 \(q_1=(1,1)/\sqrt2\)입니다. 새 좌표의 출력은 \((3,0)\)이고, 실제 출력은 \(3q_1=(3,3)/\sqrt2\)입니다. 새 좌표 (1,0)을 원래 가로 방향으로 읽으면 안 됩니다.
{{< /answer >}}

**2. B의 비대각 원소가 0이 되면 실제 변환이 사라진 것인가요?**

{{< answer >}}
아닙니다. 두 방향을 섞는 항이 사라졌을 뿐, 첫 방향을 3배 하는 작용은 남습니다. 어느 기저에서 계산하더라도 같은 실제 입력의 출력은 같습니다.
{{< /answer >}}
