# ‘벡터에서 부분공간까지’ 재작성 계획

2026-10-26 · 첫 세 편의 문체 피드백을 반영해 중심 다섯 편과 실험을 작성했다. 아래에 내용 검토와 실제 검증 범위를 기록한다.

## 출발점과 도착점

독자는 좌표평면과 사칙연산을 알고 있으며 선형대수는 처음 배운다. 좌표의 순서, 음수, 분수도 작은 예와 함께 다시 설명한다. 삼각함수·행렬·미적분·양자역학은 선수 지식으로 요구하지 않는다.

이 경로를 마치면 평면 벡터들을 더하고 수를 곱할 수 있다. 주어진 벡터들로 만들 수 있는 범위를 설명하고, 원점을 지나는 직선·이동된 직선·선분·두 좌표축의 합집합 중 무엇이 부분공간인지 이유를 말할 수 있다. ‘원점을 포함한다’는 조건만으로 충분하지 않음도 설명한다.

첫 경로는 실수 좌표평면에 집중한다. 추상 벡터 공간의 공리, 함수 공간, 복소수, 내적, 투영, 고유값 근사는 후속 주제다. 벡터를 모든 맥락에서 물리적 이동이라고 정의하지 않고, **평면 벡터를 이해하기 위한 출발 예**로 이동을 사용한다.

## 노트 한 편에 담을 수준

노트 한 편은 하나의 중심 질문에 답한다. 분량보다 읽은 뒤 독자가 할 수 있는 행동을 기준으로 나눈다. 본문과 조작을 합쳐 약 10~15분을 예상하되, 첫 검토에서 실제 속도에 맞춰 조정한다.

| 항목 | 작성 기준 |
| --- | --- |
| 선수 지식 | 앞 노트의 결과만 사용한다. 다음 노트의 용어를 설명 없이 끌어오지 않는다. |
| 새 개념 | 핵심 용어 1~3개. 한 절에서 여러 정의를 연속으로 제시하면 노트를 나눈다. |
| 설명 | 구체적 상황 → 말로 풀이 → 계산 → 이름·정의 순으로 연결한다. 모든 절에 같은 제목을 강제하지 않는다. |
| 수식 | 기호를 먼저 소개하고, 숫자를 넣는 중간 계산을 한 번은 전부 보여준다. 불필요한 전치·행렬 표기는 늦춘다. |
| 예제 | 중심 예 하나를 본문·그림·실험에서 유지한다. 마지막에는 새 숫자로 적용해 본다. |
| 오해 | 현재 개념에서 실제로 생길 오해 하나를 예나 반례로 설명한다. 먼 후속 주제의 주의사항을 미리 열거하지 않는다. |
| 실험 | 먼저 예상하기 → 한 가지를 바꾸기 → 변한 것과 유지된 것을 말하기. 조작 자체가 학습 목표와 연결되어야 한다. |
| 확인 문제 | 계산 1개, 이유 설명 1개 정도. 해설은 접어 두고, 정답뿐 아니라 이유를 적는다. |
| 문장 | 문단 하나에 설명할 내용 하나. 예시·이유·결과를 자연스럽게 잇고 질문과 권유를 반복하지 않는다. ‘연결한다·읽는다·구조’ 같은 말은 구체적인 대상과 행동으로 풀어 쓴다. |
| 개념 링크 | 본문 설명을 다 읽은 뒤 추가로 볼 수 있게 한다. 필수 설명을 툴팁으로 떠넘기지 않는다. |
| 완료 판단 | 수학 검토, 문장 검토, 실제 조작, 모바일 화면 확인을 구분한다. 자동 검사 통과를 이해도 검증으로 취급하지 않는다. |

분량을 늘리기 위한 도입·요약·동일 정답의 반복은 피한다. 실험의 허용 오차·이관 기록·설치 정보는 개발 문서와 테스트에 둔다. 독자가 알아야 하는 범위 제한은 관련 설명 바로 옆에 둔다.

## 중심 학습 경로: 다섯 편

| 순서·ID | 중심 질문과 설명할 내용 | 읽은 뒤 할 수 있는 일 | 실험과 확인 기준 | 이번 단계 |
| --- | --- | --- | --- | --- |
| 1 · `vector` | 이동을 두 숫자로 어떻게 적을까? 가로·세로 성분, 음수, 시작점과 이동량, 영벡터. | (3, 2)의 뜻을 말하고, 시작점이 달라도 같은 이동을 찾는다. | 성분을 바꾸며 화살표 관찰. 시작점만 옮겼을 때 이동량 유지. (0, 0)은 방향이 없는 이동. | 작성·검증 |
| 2 · `vector-operations` | 이동을 이어 붙이거나 몇 배로 늘리면? 성분별 덧셈, 수배, 음수·0·분수 배. | 두 이동의 결과를 계산하고 −1배·0배·반 배를 그림으로 설명한다. | u=(2,1), v=(−1,2). 순서를 바꿔도 합은 (1,3). 수배 화면은 한 벡터만 사용. | 작성·검증 |
| 3 · `linear-combination` | 정해진 이동들을 몇 배씩 더해 원하는 이동을 만들까? 계수와 선형결합. | au+bv에서 각각의 수가 하는 일을 말하고 목표 (3,2)를 만든다. | u=(1,0), v=(1,1). a=1,b=2로 목표 도달. 음수 계수와 0도 사용. 모든 계수를 탐색했다는 인상을 주지 않는다. | 작성·검증 |
| 4 · `span` | 계수를 전부 바꾸면 어디까지 만들 수 있을까? 한 결과와 결과들의 집합, 생성공간. | 한 벡터, 같은 직선의 두 벡터, 서로 다른 방향의 두 벡터가 만드는 범위를 구별한다. | 계수로 도착점을 그린 뒤 한 직선/평면 비교. 유한 슬라이더 구간과 모든 실수 계수의 차이를 명시. | 작성·검증 |
| 5 · `subspace` | 계산해도 벗어나지 않는 벡터들의 집합은 무엇일까? 영벡터, 덧셈·수배에 대한 닫힘. | 원점 직선은 해당하고 이동된 직선·선분·십자 모양은 왜 아닌지 반례를 든다. | 집합을 선택하고 두 벡터를 더하거나 배율 변경. 십자 모양에서는 합이 밖으로 나간다. {0}과 전체 평면도 포함. | 작성·검증 |

부분공간 설명에서는 관찰 결과에 그치지 않고, 원점 직선의 두 벡터 `au`, `bu`를 더하면 `(a+b)u`이고 수를 곱하면 `(ca)u`라는 짧은 일반 설명까지 한다. 임의의 두 벡터와 모든 실수 배율이라는 조건을 분명히 한다.

## 이후 확장할 세 편

독립·기저·차원은 부분공간의 정의를 이해하는 필수 선수 조건이 아니다. 중심 다섯 편을 읽은 뒤 ‘그 공간을 가장 적은 기준으로 어떻게 표현할까?’라는 질문으로 이어간다.

| 노트 | 범위 | 실험 |
| --- | --- | --- |
| 선형 독립 (`linear-independence`, 신규 예정) | 하나를 빼도 생성공간이 같은가? 중복, 영벡터, 간단한 0의 조합. | 벡터를 추가·제거하며 만들어지는 범위 비교. |
| 기저와 좌표 (`basis`, 재작성 예정) | 전체를 만들고 중복이 없는 기준. 같은 벡터와 서로 다른 좌표. | 같은 목표를 고정하고 기준을 바꿔 계수 비교. 역행렬 공식은 여기서 요구하지 않음. |
| 차원 (`dimension`, 신규 예정) | 독립적인 기준의 수. 성분 개수와 부분공간 차원의 차이. | 세 성분으로 적은 직선은 1차원임을 확인. 이때 3차원 좌표를 새로 소개. |

기존 내적·행렬·대칭행렬·고유값·대각화·대각화 좌표·멱법·Krylov 노트는 삭제하지 않는다. 이번 중심 경로에서는 빼고, 뒤에 내적·선형변환·근사 계산을 위한 경로를 별도로 설계한다. 기존 `subspace`의 투영·에너지 근사 내용과 실험은 `orthogonal-projection`으로 분리해 보존한다. 투영을 선수 지식으로 삼는 후속 노트의 연결도 새 목적지로 바꾼다.

기존 각도 실험 `vector-direction`은 삼각함수를 전제하므로 새 첫 노트에서 뺀다. 이미 이를 쓰는 `prep-math`와 실험 주소는 유지한다. 옛 `concept-vector.html` 주소는 계속 `vector`로 연결된다.

## 첫 세 편의 검토와 후속 요청

1. 세 편을 연속으로 읽는다. 멀리 떨어진 벡터·기저·부분공간을 샘플로 고르지 않는다.
2. 각 실험에서 조작 전에 결과를 예상하고, 바뀐 그림을 본 뒤 자기 말로 설명한다.
3. 확인 문제의 해설을 열기 전에 답을 생각한다. 틀린 경우 계산 실수인지, 설명에서 빠진 단계인지 구분한다.
4. 사용자가 멈칫한 문장, 한 번 더 보고 싶은 그림, 너무 쉬운 부분을 함께 확인한다.
5. 그 피드백으로 세 편과 작성 기준을 고친 뒤 `span`·`subspace`를 작성한다.

첫 검토에서는 AI가 작성한 느낌이 남는다는 피드백을 받았다. 문장을 검토하며 질문·권유·반복 요약이 많아 수업 대본처럼 읽히는 문제를 확인했다. 벡터 한 편을 차분한 설명체로 고쳤고, 사용자가 같은 수준으로 남은 노트의 내용 검토와 인터랙티브 콘텐츠 개선까지 요청했다. 이에 따라 다섯 편 전체의 문체·예시·확인 문제를 맞추고 생성공간과 부분공간 실험을 추가한다. 독립·기저·차원은 이번 중심 경로에 포함하지 않는다. 공개 배포는 별도 요청 시 진행한다.

실험에서는 현재 계산한 벡터, 유한한 계수로 찍은 예시 점들, 모든 실수 계수로 만드는 집합을 구분한다. 부분공간 실험은 집합 안에서 고른 입력이 덧셈·수배 후에도 안에 남는지를 보여 준다. 성공 사례 몇 개를 부분공간의 증명으로 표시하지 않고, 본문의 일반 설명과 연결한다.

## 실험 제작 기준과 사용 스킬

프로젝트에 복사한 `scientific-visualization`의 축척·직접 라벨·색 이외의 구별 수단·실제 출력 검토 기준을 적용한다. 자세한 출처와 적용 범위는 [프로젝트 스킬](project-skills.md)에 기록한다. 이 스킬은 한국어 교육과정 설계를 대신하지 않는다.

- SVG와 일반 JavaScript로 구현한다. 두 축의 한 칸 길이를 같게 두고, 조작 중 축 범위를 고정한다.
- 자동 재생은 쓰지 않는다. 입력 하나를 바꿨을 때 무엇이 바뀌는지 바로 확인한다.
- 모든 입력에 이름·현재 값·초기화를 제공한다. 슬라이더는 키보드로도 조작한다.
- 0배 결과는 방향 없는 점으로 보여 준다. 0길이 화살표에 임의의 화살촉을 붙이지 않는다.
- 숫자 결과와 문장 설명을 함께 제공한다. JavaScript가 꺼져도 본문과 실험의 대체 설명을 읽을 수 있게 한다.
- 화면의 유한 입력 범위를 수학 개념 전체의 범위로 설명하지 않는다.
- 검산은 작은 정수·유리수의 알려진 결과와 불변식으로 한다. 일반 작성에 Python 과학 패키지나 npm을 추가하지 않는다.

검사 보고서는 무시되는 test-results/에 있으며, 위 기록은 검사 범위를 보존한다. 읽기 쉬운지와 설명 속도가 적절한지는 다음 사용자 검토에서 확인할 사항이다. 당시 변경은 로컬 검토본으로 남겼고 커밋·push·공개 배포하지 않았다. 일반 작성에 필요한 패키지는 추가하지 않았으며 WebKit 검사에 사용한 임시 브라우저는 검사 후 제거했다.

## 다섯 편 완성 및 개선 기록

2026-10-26 후속 요청으로 중심 경로를 `vector → vector-operations → linear-combination → span → subspace` 다섯 편으로 연결했다. 각 편에는 구체적인 예, 설명과 중간 계산, 실험, 오해하기 쉬운 점, 접힌 풀이 두 개가 있다. 기존 벡터의 문체에 맞춰 덧셈·선형결합도 다시 다듬었다.

| 노트·실험 | 검토에서 확인한 점과 개선 |
| --- | --- |
| 벡터 | 시작점 이동 시 원점에서 그린 같은 벡터를 점선으로 함께 보여 주어 이동량이 같음을 비교한다. 영벡터는 점으로 표시한다. |
| 덧셈과 수배 | 이동 순서와 합을 구별하고 음수·0·분수 배율을 설명한다. 그림 범위를 고정한 채 불필요한 여백을 줄이고 반 배·반대·0·두 배 버튼을 제공한다. |
| 선형결합 | 계수와 결과 성분을 구별한다. 세로 성분부터 맞추는 힌트를 접어 두고, 초기화하면 힌트도 닫는다. |
| 생성공간 | 한 결과와 결과들의 집합을 구분한다. 한 벡터·같은 직선의 두 벡터·평면·영벡터를 비교하며, 계수를 바꿔도 만들어지는 범위가 같은 경우를 설명한다. 유한한 예시 점들과 모든 실수 계수로 만든 집합을 따로 표시한다. |
| 부분공간 | 임의의 두 벡터와 모든 실수 배율에 대한 닫힘을 설명한다. 원점 직선의 일반 계산과 이동된 직선·선분·두 축 합집합의 반례를 제공한다. 실험은 입력·결과의 소속 여부와 영벡터 포함 여부를 나누어 보여 준다. |
| 기존 투영 내용 | `orthogonal-projection`에 기존 투영 실험, 행렬 축소, 에너지 근사와 조건을 보존했다. 내적·행렬·멱법·Krylov에서 투영 설명을 가리키던 연결도 옮겼다. 기존 `subspace` 주소와 원본 이관 기록은 유지한다. |

생성공간·부분공간은 작성 후 별도로 내용을 읽어 수학 조건을 검토했다. 같은 직선에서 반대 방향인 벡터도 공간을 넓히지 않는다는 점, 영벡터만 있는 경우, 벡터를 원점에서 그렸을 때 끝점으로 소속을 판단한다는 점을 보완했다. [Georgia Tech의 부분공간 정의](https://textbooks.math.gatech.edu/ila/subspaces.html)와 위 MIT 자료를 확인했으며, 본문의 수치 예와 설명은 입문 순서에 맞춰 작성했다.

최종 작성 원본은 노트 78개, 실험 80개, 경로 6개다. 이번 경로 밖의 다른 노트까지 같은 수준으로 전면 재작성했다는 뜻은 아니다. 독립·기저·차원은 이후 확장 주제로 남아 있다.

| 검사 | 결과 |
| --- | --- |
| 생성·구조 | 루트와 `/note/` 빌드 통과. 각각 255개 HTML/SVG 문서, 5,734개 로컬 참조, 기존 74개 학습 원문·86개 주소·15개 데이터 보존 확인. |

로컬 미리보기는 검사용 빌드와 다른 출력 폴더로 분리했다. 일반 작성에 필요한 패키지는 추가하지 않았고, 검사에만 사용한 임시 WebKit 브라우저는 제거했다. 이 변경은 커밋·push·공개 배포하지 않았다. 읽는 속도와 설명의 자연스러움은 이후 사용자 피드백으로 계속 검토한다.
