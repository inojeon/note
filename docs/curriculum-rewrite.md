2026-10-26 · ‘벡터에서 부분공간까지’ 다섯 편의 설명 깊이와 문체를 나머지 학습 내용으로 넓힌다. 첫 차수 ‘기저와 좌표’ 네 편의 구성을 사용자가 승인했고, 같은 구조로 나머지 화학·양자컴퓨팅 분야도 작성하도록 요청했다. 이 승인에 따라 필요한 수학 기초와 계산 실습까지 이어 작성했다. 사용자에게 읽기 편한지 확인받는 상태와 자동 검사 통과는 구별한다.

## 원본 대응과 진행 상태

[전체 대응표](curriculum-rewrite.json)는 기존 재작성 대상 73편과 신규 기초 노트 7편의 ID·목적지·학습 목표·예정 선수 지식·기존/예정 실험·개선 내용·검토 상태를 기록한다. 완료한 벡터 경로 5편은 `baseline_notes`로 구분한다. 이 대응표는 작업 계획이며 사이트의 콘텐츠 카탈로그나 검색 색인을 대신하지 않는다. 화면의 노트 정보는 계속 Markdown 원본에서 생성한다.

`planned`는 재작성 전, `authoring`은 작성·검사 중, `ready-for-review`는 내용·기능 검토 후 사용자 검토 대기, `reviewed`는 사용자 피드백을 반영한 상태다. 새 노트와 실험은 준비될 때 원본 폴더를 만든다. 계획의 ID만으로 빈 페이지를 생성하지 않는다.

## 노트의 수준과 문체

독자는 좌표평면과 사칙연산에서 출발한다. 한 편은 중심 질문 하나와 핵심 개념 1~3개를 다루며 본문·실험을 합해 약 10~15분을 기준으로 쓴다. 길이를 맞추기 위한 도입·요약은 넣지 않는다. 앞에서 배우지 않은 기호·용어·계산을 확인하고, 미적분·행렬식·다체 형식의 전체 유도는 선택적인 심화로 구분한다.

구체적 상황, 이유, 중간 계산, 정의가 이어지는 설명체를 사용한다. 질문과 권유를 반복하거나 독자가 이해했다고 단정하지 않는다. 본문·실험·문제의 기호와 예제를 맞춘다. 주요 오해 하나와 계산/이유 설명 문제 두 개를 제공하며 풀이는 접어 둔다. 툴팁은 복습을 돕고 필수 설명을 대신하지 않는다.

## 경로 묶음과 단계별 전환

수학 묶음 `mathematics`는 다섯 경로를 표시한다. 기존 `quantum-chemistry`, `quantum-computing`, `vqe`는 주소를 유지하면서 각각 다섯·두·두 경로를 안내하는 묶음으로 전환했다. SQD와 계산 실습은 각각 일곱 편의 독립 경로다. 총 16개 읽기 경로와 4개 묶음 페이지를 제공한다.

묶음은 `params.paths`, 실제 읽기 순서는 `params.steps`로 구분한다. 한 페이지에 두 필드를 함께 쓰지 않는다. 묶음이 다른 묶음을 포함하지 않으며 한 짧은 경로는 최대 한 묶음에 속한다. 홈·목록에는 상위 묶음과 독립 경로를 보여 주고 이전·다음 노트는 짧은 경로의 순서에서 생성한다. 기존 `linear-algebra` 주소와 다섯 단계는 유지한다.

## 검토와 공개

각 차수의 완료 조건은 내용·수학 검토, Hugo 빌드, 실제 브라우저 조작이다. root와 `/note/`에서 구조·링크·수식·자산을 확인한다. 새 실험은 알려진 값·불변식·경계값·초기화를 검사하고 공통 화면·3D 변경은 Chromium과 WebKit으로 확인한다. 좁은 화면·키보드·다크 모드·확대·오류와 재시도도 검사한다. 검사 전후 원본 지문을 비교한다.

계산 조건과 데이터 출처를 유지하며 저장 자료를 재계산했다고 표현하지 않는다. 프레임워크·과학 패키지를 일반 작성 의존성으로 추가하지 않는다. 시각화에는 기존 프로젝트 스킬의 축척·직접 라벨·접근성 원칙을 적용한다. 출처는 [프로젝트 스킬 기록](project-skills.md)에 있다.

첫 네 편의 검토 후 읽다 멈춘 문장, 설명이 부족한 계산, 조작으로 알기 어려운 점을 반영한다. 이후 위 경로 순서로 진행하되 투영은 필요한 응용 전에 읽을 수 있게 안내한다. 로컬 검토본을 자동으로 공개하지 않는다. 공개 배포는 별도 요청 시 기존 수동 워크플로로 진행한다.

## 후속 차수: 화학·양자컴퓨팅과 선수 지식

2026-10-26 사용자 요청에 따라 나머지 대상 76편을 작성·검토했다. 화학 29편, 양자컴퓨팅·VQE·SQD 24편, 수학 기초·응용 13편, 계산 실습과 종합 예제 10편이다. 수학 13편 가운데 확률·밀도·각도·복소수·복소수 내적 다섯 편은 신규다. 기준 다섯 편과 승인된 기저 경로 네 편을 더해 전체 노트는 85편이다.

각 노트는 선수 지식, 본문 예제, 중심 실험, 정의와 조건, 오해 또는 반례, 계산과 해석 문제 두 개, 미리보기를 갖춘다. 실습 문서의 코드·원자료·조건은 보존하고 코드를 읽기 전 예상할 입력과 출력을 설명했다. `intro`는 실제 H₂ 두 배치의 실험을 중심에 놓고 전체 네 배치를 A=g², B=u², C=gαuβ, D=uαgβ 순서로 표시한다. 원 JSON은 바꾸지 않았고 행렬 표시를 같은 순서로 재배열했다.

### 분야에 맞춘 실험

- 원자·전자: 원자·이온·분자 전자 수 계산, 오비탈 부호와 밀도, 측정축에 따른 스핀 확률, 여섯 점유 배치, 전자 교환의 부호를 비교한다.
- 분자 에너지: 원자 함수 합·차와 마디, 전자 적분과 배치 행렬, H₂의 같은 확률·다른 상대 부호, HF 반복 기록, CI 공간 확대와 활성 상수를 구별한다.
- 양자컴퓨팅: 상태와 측정 기준, 누출 확률, 게이트 순서, 회전 θ와 진폭 θ/2, 텐서곱, Bell 상태와 고전 혼합을 조작한다.
- VQE·SQD: 허용 각도 범위, 측정 샷, 후보 각도 갱신, 점유 비트열과 JW 부호, 회로의 중간 상태, 측정 빈도와 대각화 계수의 차이를 비교한다.
- 수학·실습: 새 기초 실험 다섯 개와 전자 수 실험 하나를 추가해 총 90개다. 기존 실험은 유지하고 필요한 프리셋·계산값·조건 설명을 개선했다.

### 독립 내용 검토에서 반영한 수정

화학 두 담당자가 서로의 29편을 검토하고 양자 24편과 계산 실습·종합 문서도 교차 검토했다. 수학 13편과 새 실험 다섯 개는 별도 검토했다. 다음 사항을 수정했다.

- 변분 원리의 선수 순서와 음의 에너지에서도 정확한 정규화 설명.
- H=X 들뜬 상태 버튼의 범위 밖 각도 및 안사츠 범위별 설명. 두 실행 오류에 회귀 검사를 추가.
- 기저 측정 설명의 적용 범위를 정규직교 기저 측정으로 한정.
- H₂ 종합 예제와 실험의 배치 이름 통일.
- 양의 정부호의 기존 심화 설명 복원, 대칭행렬 그림의 선 색과 라벨 일치, 복소수 내적 강의 출처와 선수 정보 정리.
- 기존 본문 앵커 보존. 상태·원자 13편에서는 이전 렌더링과 대조한 본문 앵커 76개를 모두 유지.

과학 계산을 다시 실행한 작업은 아니며 저장된 데이터의 조건·출처·예상값을 검토했다. 작성 의존성은 Hugo 하나로 유지했다. WebKit 검사용 임시 브라우저 캐시는 검사 후 제거했다. 커밋·push·공개 배포는 수행하지 않았으며, 현재 결과는 사용자가 읽고 조작하며 검토할 로컬 원본이다.
