# 개편 구현과 검증 기록

검증일: 2026-10-26. 공개 배포와 Git push는 실행하지 않았다.

## 구현 범위

- 기존 개념 63개와 주요 문서 11개를 `content/notes/`의 74개 노트로 재작성했다. 6개 학습 경로와 54개 선택적 개념 미리보기를 제공한다.
- 75개 실험을 설명·화면 조각·동작·데이터로 분리했다. 노트는 실험 ID만 참조하고 공통 실행기가 독립 HTML과 iframe을 연결한다.
- 흰색·회색·차콜과 파랑의 읽기 화면, 모바일 배치, 밝은/어두운 테마, 검색, 목차, 선수·관련·역방향 연결과 본문 개념 미리보기를 구현했다.
- 일반 작성과 빌드는 Hugo 표준 0.168.0만 요구한다. 고정 수식은 빌드 때 HTML·MathML로 생성하며, 동적 수식이 있는 14개 실험에만 로컬 KaTeX JavaScript를 추가한다. 3Dmol과 Three.js도 필요한 실험에만 포함한다.
- 기존 HTML 주소 86개와 주요 섹션 115개를 대응시켰다. 네 리더의 개념 해시, 관계도의 선택 개념과 기존 세 학습 경로 주소를 새 화면으로 연결한다.
- 기존 과학 데이터 15개는 원본 해시·생성 스크립트·조건을 기록했다. 선택적 재현기는 임시 복사본에서 실행하고 `research/results/`에 결과를 남긴다.

브라우저 실행별 JSON 보고서와 화면은 커밋하지 않는 `test-results/`에 있다. CI에서도 동일한 검사를 실행하고 결과를 30일간 아티팩트로 보관한다. GitHub에서의 실제 워크플로 실행·공개 결과는 이번 로컬 검증에 포함하지 않았다.

## 결과 크기와 재현 범위

현재 배포 결과 전체는 약 6.86 MB이며, 개별 노트 HTML의 중앙값은 약 27 KB다. 검색 색인 약 310 KB는 검색을 사용할 때 가져온다. 브라우저는 읽는 노트와 가까운 실험의 필요한 자산만 불러온다.

기존 과학 계산을 다시 설치하거나 실행하지는 않았다. 출처·체크섬과 예시 결과를 대조하고 보존 데이터를 사용한 브라우저 모델을 검증했다. 재계산이 필요하면 `research/README.md`를 따른다.

시작 명령은 `tools/hugo server -D`, 배포용 생성은 `tools/hugo --minify`다. 작성은 `docs/note-authoring.md`, 실험 추가는 `docs/experiment-authoring.md`, 공개와 복원은 `docs/deployment.md`를 따른다.
