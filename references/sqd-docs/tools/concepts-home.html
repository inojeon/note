행렬(Matrix)과 벡터(Vector)

한 번에 하나를 이해하고,
필요한 개념으로 이어갑니다.

먼저 일반 개념을 읽고, 마지막에 에너지 연산자인 해밀토니안과 연결합니다. 각 노트는 하나의 질문을 정의 → 쉬운 해설 → 예시·실험 → 적용 조건 순서로 다룹니다. 이미 아는 내용은 건너뛰어도 좋습니다.

벡터를 표현하기

  • 벡터여러 성분(Component)을 하나의 대상으로 다루려면?
  • 기저(Basis)와 좌표(Coordinates)같은 벡터를 다른 숫자로 적을 수 있을까?
  • 내적(Inner Product)과 길이두 벡터가 얼마나 같은 방향을 향할까?

변환을 이해하기

  • 행렬과 선형변환(Linear Transformation)벡터를 일관된 규칙으로 바꾸려면?
  • 대칭 행렬(Symmetric Matrix)행과 열을 바꿔도 같은 행렬은 왜 특별할까?
  • 고유벡터(Eigenvector)와 고유값(Eigenvalue)변환해도 같은 직선 위에 남는 벡터가 있을까?
  • 대각화(Diagonalization)기준을 바꾸면 행렬 계산이 단순해질까?

작은 계산으로 근사하기

  • 멱법(Power Method)과 반복행렬을 계속 곱하면 어떤 성분이 남을까?
  • 부분공간(Subspace)과 투영큰 공간의 일부만으로 근사하려면?
  • 크릴로프 공간(Krylov Subspace)과 랑초스(Lanczos Algorithm)반복 계산의 중간 결과도 활용할 수 있을까?

에너지 연산자로 연결하기

  • 해밀토니안과 에너지행렬에서 에너지와 양자 상태를 어떻게 읽을까?

읽기 경로: 벡터 → 기저 → 행렬 → 고유벡터 → 대각화. 내적과 부분공간은 근사 계산을 이해할 때 연결해서 읽으세요.
