E_BO(R) = E_e(R) + V_NN(R). 핵이 가까워질 때 커지는 양의 반발도 더해야 합니다. 이 곡선 위에서 핵의 진동·회전을 다루는 것이 다음 단계입니다.

계산 조건 · 단위와 전자 밀도 읽기

중성 H₂의 단일항 바닥상태를 STO-3G 기저와 완전 구성 상호작용(Full Configuration Interaction, FCI)으로 계산했습니다. FCI는 선택한 유한 기저 안에서 전자 문제를 풀며, 실제 분자의 정확한 해나 실험값과 같다는 뜻은 아닙니다. 최소 에너지 버튼은 계산한 거리들 중 최솟값을 고릅니다.

전자 에너지에는 전자 운동, 전자–핵 인력, 전자–전자 반발이 들어갑니다. 합계에는 핵간 반발을 더하고 핵 운동에너지는 넣지 않았습니다. 거리 단위 Å는 10⁻¹⁰ m이며, a₀는 보어 반지름(Bohr Radius), Ha는 하트리(Hartree)입니다. 원자 단위계에서 H₂의 핵간 반발은 V_NN = 1/(R/a₀) Ha입니다.

전자 밀도는 같은 FCI 상태의 스핀을 합한 일전자 밀도행렬에서 구했습니다. 공간 전체에 적분하면 전자 수 2가 됩니다. 3D 등가면은 일정한 밀도 값을 고른 표면이고, 단면은 밀도의 공간 변화를 보여줍니다. 전자의 궤적이나 한 전자의 오비탈이 아닙니다.
