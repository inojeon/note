계산 기저 측정과 에너지 측정(Energy Measurement)

0·1을 읽는 것과 에너지를 읽는 것은 어떻게 다를까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

에너지 측정(Energy Measurement)은 의 을 결과로 얻는 측정입니다. 측정(Computational Basis Measurement)은 의 0·1 상태를 구분합니다. 계산 기저가 와 일치할 때를 제외하면 두 측정은 다릅니다.

기준 상태의 이름이 에너지 이름은 아닙니다

큐빗의 0 상태가 항상 인 것은 아닙니다. 아래 모형에서는 0 상태를 준비해도 에너지는 낮은 값 또는 높은 값으로 나올 수 있습니다. 에너지의 기준 상태는 해밀토니안의 를 구해서 찾습니다.

평균 에너지

에너지는 임의 단위입니다. 평균은 가능한 에너지에 각각의 확률을 곱해 더한 값이며, 매번 측정되는 값은 아닙니다.

두 측정의 확률과 평균을 수식으로 확인하기

초기 상태는 0 상태이고, 각도를 바꾸어 다음 상태를 준비합니다. H는 이 준비 연산과 별개입니다.

|ψ(θ)⟩ = Ry(θ)|0⟩

= 열벡터 [cos(θ/2); sin(θ/2)]

계산 기저에서는 각 의 크기 제곱이 0·1의 확률입니다. 에너지 측정에서는 에너지 고유벡터 u와의 내적(Inner Product) 크기를 제곱합니다.

P(Ej) = |⟨uj|ψ⟩|²

평균 에너지 = P(E−)E− + P(E+)E+

이 예제에서 가능한 에너지는 H의 고유값인 E± = 1 ± √(0.5² + 0.2²)입니다. 회전각을 바꿔도 이 두 값은 변하지 않습니다.

실제 VQE는 에너지 고유상태를 먼저 구할까?

이 실험은 차이를 설명하려고 에너지를 직접 측정하는 이상적인 경우를 계산합니다. 실제 VQE는 정답인 에너지 고유상태를 미리 구할 필요 없이, H를 의 합으로 나누어 각 항을 측정하고 평균을 합칩니다.

H = I − 0.5X − 0.2Z

이 모형에서는 X 측정과 Z 측정을 위해 상태를 각각 여러 번 새로 준비합니다. Z 측정의 0·1 확률만으로는 일반적인 상태의 평균 에너지를 구할 수 없습니다. 실제 유한 횟수의 측정에서 생기는 는 이 화면의 정확한 확률 계산과 구별합니다.

수학 풀이 · 각도에서 평균 에너지까지

실험의 실수 계수를 사용해 한 단계씩 계산합니다. 각 단계는 펼쳐서 확인할 수 있습니다.

1. 회전각으로 상태 계수 정하기

처음에는 0 상태입니다. 회전 게이트로 된 상태 c를 준비합니다.

c=R_y(\theta)|0\rangle

c=\begin{pmatrix}a\\b\end{pmatrix}=\begin{pmatrix}\cos(\theta/2)\\\sin(\theta/2)\end{pmatrix}

a^2+b^2=1

θ = 90°라면 a = b = 1/√2입니다. 계수와 확률은 다르며, 계산 기저 측정 확률은 a²와 b²입니다.

2. 행렬 H를 상태에 곱하기

행과 열을 곱해 더하면 Hc의 두 성분을 얻습니다.

H=\begin{pmatrix}0.8&-0.5\\-0.5&1.2\end{pmatrix}

Hc=\begin{pmatrix}0.8a-0.5b\\-0.5a+1.2b\end{pmatrix}

이 곱은 에너지 계산의 중간 단계입니다. H를 상태 준비 게이트처럼 적용했다는 의미는 아닙니다.

3. 원래 상태와 내적하기

에너지 기댓값(Expectation Value)은 c†Hc입니다. †는 이며 이 예제의 계수는 실수입니다.

\langle H\rangle=c^\dagger Hc

=a(0.8a-0.5b)

\quad+b(-0.5a+1.2b)

=0.8a^2-ab+1.2b^2

=1-0.5\sin\theta-0.2\cos\theta

대각 원소에 0·1 확률만 곱한 0.8a²+1.2b²에는 −ab 항이 빠져 있습니다. 일반적인 계수라면 교차항은 −Re(a* b)입니다.

4. 90° 예제와 에너지 확률로 확인하기

90°에서는 a² = b² = ab = 1/2입니다.

\langle H\rangle=0.8\times\tfrac12-\tfrac12+1.2\times\tfrac12

=0.5

E_\pm=1\pm\sqrt{0.29}

P(E_j)=|\langle u_j|c\rangle|^2

\langle H\rangle=E_-P(E_-)+E_+P(E_+)

H의 고유벡터 uⱼ와의 겹침이 에너지 측정 확률을 정합니다. 90°에서는 낮은 에너지 확률이 약 96.424%, 높은 에너지 확률이 약 3.576%이며, 가중 평균은 0.5입니다. 가능한 한 번의 에너지 측정값은 약 0.461484 또는 1.538516이며 평균 0.5와 구별합니다.
