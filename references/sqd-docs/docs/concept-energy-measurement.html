계산 기저 측정과 에너지 측정(Energy Measurement)

0·1을 읽는 것과 에너지를 읽는 것은 어떻게 다를까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

에너지 측정(Energy Measurement)은 의 을 결과로 얻는 측정입니다. 측정(Computational Basis Measurement)은 의 0·1 상태를 구분합니다. 계산 기저가 와 일치할 때를 제외하면 두 측정은 다릅니다.

기준 상태의 이름이 에너지 이름은 아닙니다

큐빗의 0 상태가 항상 인 것은 아닙니다. 아래 모형에서는 0 상태를 준비해도 에너지는 낮은 값 또는 높은 값으로 나올 수 있습니다. 에너지의 기준 상태는 해밀토니안의 를 구해서 찾습니다.

실험 · 같은 상태를 두 가지 방법으로 읽기

설명용 H 은 고정합니다. 의 각도는 시험할 상태만 바꿉니다. 두 패널은 동일하게 준비한 상태를 각각 측정하는 별개의 실험이며, 한 큐빗을 연달아 측정하는 과정이 아닙니다.

H = [[0.8, −0.5], [−0.5, 1.2]]

평균 에너지

에너지는 임의 단위입니다. 평균은 가능한 에너지에 각각의 확률을 곱해 더한 값이며, 매번 측정되는 값은 아닙니다.

두 측정의 확률과 평균을 수식으로 확인하기

초기 상태는 0 상태이고, 각도를 바꾸어 다음 상태를 준비합니다. H는 이 준비 연산과 별개입니다.

|ψ(θ)⟩ = Ry(θ)|0⟩

= 열벡터 [cos(θ/2); sin(θ/2)]

계산 기저에서는 각 의 크기 제곱이 0·1의 확률입니다. 에너지 측정에서는 에너지 고유벡터 u와의 크기를 제곱합니다.

P(Ej) = |⟨uj|ψ⟩|²

평균 에너지 = P(E−)E− + P(E+)E+

이 예제에서 가능한 에너지는 H의 고유값인 E± = 1 ± √(0.5² + 0.2²)입니다. 회전각을 바꿔도 이 두 값은 변하지 않습니다.

실제 VQE는 에너지 고유상태를 먼저 구할까?

이 실험은 차이를 설명하려고 에너지를 직접 측정하는 이상적인 경우를 계산합니다. 실제 VQE는 정답인 에너지 고유상태를 미리 구할 필요 없이, H를 의 합으로 나누어 각 항을 측정하고 평균을 합칩니다.

H = I − 0.5X − 0.2Z

이 모형에서는 X 측정과 Z 측정을 위해 상태를 각각 여러 번 새로 준비합니다. Z 측정의 0·1 확률만으로는 일반적인 상태의 평균 에너지를 구할 수 없습니다. 실제 유한 횟수의 측정에서 생기는 는 이 화면의 정확한 확률 계산과 구별합니다.
