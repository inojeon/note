문서 4 / 6

양자 회로: 근사 바닥상태 만들기
hcore·eri에서 양자 상태까지

문서 1~3에서 만든 적분과 부품으로 실제 회로를 조립해 돌립니다. 실제로 어떤 회로를 쓰고, 그 각도는 어디서 오며, 만들어진 상태가 정답과 얼마나 다른지를 N₂(cc-pVDZ, 활성 8궤도·10전자)로 따라갑니다. 회로는 SQD 논문과 같은 LUCJ이고, Qiskit의 ffsim 패키지로 만들어 시뮬레이터에서 돌렸습니다. 숫자는 전부 실제 계산값입니다.

회로의 목표는 HF 기준 배치 하나에서 출발해 다른 배치들을 "적당한 비율로" 섞은 상태를 만드는 것입니다. 완벽할 필요는 없습니다. 중요한 배치가 측정에 걸릴 만큼만 들어 있으면 나머지는 SQD의 고전 대각화가 바로잡습니다.

한눈에 보기

1. 궤도를 큐비트로

궤도 하나에 전자가 있을 수 있는 방식은 α 있음/없음, β 있음/없음의 조합이므로, 궤도 하나를 큐비트 둘로 나타냅니다. 큐비트가 |1⟩이면 그 스핀의 전자가 있는 것입니다. 이 대응을 Jordan–Wigner 변환이라 부르는데, 핵심은 "비트열 = 배치"라는 앞 문서의 규약이 바로 이 대응이라는 점입니다.

hcore와 eri도 같은 변환으로 큐비트 연산이 됩니다. "전자가 i에서 k로 뛴다"는 큐비트 i를 내리고 k를 올리는 연산이 되고, 그 사이 큐비트들에 부호를 맞추는 Z 게이트 사슬이 붙습니다. 이 변환의 수학은 몰라도 됩니다. ffsim이 전부 처리하며, 사용자는 PySCF 객체를 넘기기만 합니다.

2. 회로가 할 일

HF 배치 하나만으로는 정답과의 겹침이 |⟨HF|Ψ⟩|² = 0.942입니다. 나머지 5.8%가 수백 개의 들뜬 배치에 흩어져 있고, 그것이 결합 에너지의 대부분을 차지합니다. 회로는 HF 상태에 이 배치들을 섞어 넣어야 합니다.

어떤 배치를 얼마나 섞을지를 회로가 스스로 알 수는 없으므로, 고전 근사법의 답을 빌립니다. CCSD는 "전자 한 쌍이 함께 들뜨는 진폭(t₂)"을 계산하는 표준 방법이고, HF보다 훨씬 정확하면서 궤도 수의 6제곱 정도로 빠릅니다. 이 t₂를 회로 각도로 바꾸는 것이 UCJ 회로입니다.

방법에너지 (Ha)CASCI와 차이비고
HF−108.954+80 mHa배치 하나
CCSD (고전)−109.033+1.6 mHat₂ 진폭의 출처
UCJ 회로, 1회 반복−108.985+50 mHat₂를 각도로 변환만 함
CASCI (정답)−109.0340활성 공간 정확 대각화

UCJ 회로가 CCSD보다 나쁜 것이 이상해 보일 수 있습니다. t₂를 각도로 "변환"하는 것은 근사이고, 논문에서는 이 각도를 출발점으로 삼아 추가로 최적화합니다. 이 문서는 변환만 한 초기 회로를 그대로 쓰므로 수치가 거칩니다. 그래도 겹침이 0.942 → 0.958로 늘고, 그 차이만큼 측정에서 들뜬 배치가 더 자주 나옵니다.

3. UCJ 회로의 구조

UCJ(unitary coupled Jastrow)는 세 종류의 층을 반복하는 회로입니다. 복잡해 보이지만 각 층이 하는 일은 하나씩입니다.

import ffsim
mol_data = ffsim.MolecularData.from_scf(mf, active_space=range(2, 10))  # 내각 2개 제외, 8개 활성
mol_data.run_ccsd(store_t2=True)                 # 고전 CCSD → t2 진폭 (8,8,8,8 중 점유×가상)

op = ffsim.UCJOpSpinBalanced.from_t_amplitudes(
    mol_data.ccsd_t2, n_reps=1,                   # t2 → 궤도 회전 + 대각 쿨롱 각도
)
print(ffsim.UCJOpSpinBalanced.n_params(8, n_reps=1))   # 136

4. LUCJ: 하드웨어에 맞추기

대각 쿨롱 층은 원칙적으로 모든 큐비트 쌍에 게이트를 겁니다. 그런데 실제 기기는 이웃한 큐비트끼리만 직접 연결되어 있어서, 멀리 떨어진 쌍에 게이트를 걸려면 스왑이 수십 개 붙습니다. LUCJ(local UCJ)는 기기 연결 그래프에 있는 쌍에만 게이트를 걸어 회로를 얕게 만듭니다. 정확도를 조금 내주고 잡음을 크게 줄이는 거래입니다.

각도 수2큐비트 게이트회로 깊이에너지 (Ha)겹침 |⟨Ψ|CASCI⟩|²
UCJ (모든 쌍)136312307−108.9850.958
LUCJ (이웃 쌍만)73198166−108.9640.947
HF만001−108.9540.942

깊이가 절반이 되었습니다. 잡음은 깊이에 지수적으로 쌓이므로 실제 기기에서는 이 차이가 "결과가 나오느냐 안 나오느냐"를 가릅니다. 어떤 쌍을 남길지는 기기의 큐비트 배치도(IBM 기기는 육각 격자)를 보고 정하며, 코드에서는 interaction_pairs 인자 하나로 지정합니다.

# 같은 스핀끼리는 이웃 궤도 쌍, 다른 스핀은 같은 궤도 쌍 일부만
pairs_aa = [(p, p + 1) for p in range(7)]
pairs_ab = [(p, p) for p in range(0, 8, 4)]
op = ffsim.UCJOpSpinBalanced.from_t_amplitudes(
    mol_data.ccsd_t2, n_reps=1, interaction_pairs=(pairs_aa, pairs_ab),
)

5. 만든 상태 vs 정답

회로가 만든 상태에서 각 배치의 확률 |c_x|²를 정답(CASCI)과 나란히 놓으면, 회로가 무엇을 잘 잡고 무엇을 놓치는지 보입니다.

그래서 SQD 논문에서는 회로 각도를 최적화하고, 샷을 수십만 번 쓰며, 결정적으로 구성 복구 루프로 "회로가 놓친 배치"를 되살립니다. 회로는 후보의 씨앗을 주는 역할이고, 씨앗이 부실해도 루프가 상당 부분 보완합니다.

6. 끝까지 돌려 보기

이제 네 문서의 내용이 전부 이어집니다. PySCF 입력 + 회로 샘플 → SQD 함수. 회로 두 종류와 샷 수 두 가지로 실제로 돌린 결과입니다.

from qiskit import QuantumCircuit, QuantumRegister
from qiskit.primitives import StatevectorSampler
from qiskit_addon_sqd.fermion import diagonalize_fermionic_hamiltonian

qubits = QuantumRegister(16)
circuit = QuantumCircuit(qubits)
circuit.append(ffsim.qiskit.PrepareHartreeFockJW(8, (5, 5)), qubits)   # X 게이트 10개
circuit.append(ffsim.qiskit.UCJOpSpinBalancedJW(op), qubits)          # UCJ/LUCJ 층
circuit.measure_all()

bit_array = StatevectorSampler(seed=1).run([circuit], shots=100_000).result()[0].data.meas

result = diagonalize_fermionic_hamiltonian(
    hcore, eri, bit_array, samples_per_batch=200,
    norb=8, nelec=(5, 5), num_batches=3, max_iterations=5, seed=1,
)
print(result.energy + ecore)     # UCJ, 10만 샷: -109.0213 (CASCI -109.0344)

실제 기기에서는 여기에 두 가지가 더 붙습니다. 회로를 기기의 게이트 집합과 연결 그래프에 맞춰 변환하는 transpile, 그리고 StatevectorSampler 대신 qiskit_ibm_runtime의 SamplerV2. 코드 구조는 같고 샘플러 객체만 바뀝니다.

전체 코드

import numpy as np, ffsim
from pyscf import gto, scf, mcscf, ao2mo
from qiskit import QuantumCircuit, QuantumRegister
from qiskit.primitives import StatevectorSampler
from qiskit_addon_sqd.fermion import diagonalize_fermionic_hamiltonian

# 문서 1: 분자 → 적분
mol = gto.M(atom="N 0 0 0; N 0 0 1.098", basis="cc-pvdz")
mf = scf.RHF(mol).run()
cas = mcscf.CASCI(mf, 8, (5, 5))
hcore, ecore = cas.get_h1eff()
eri = ao2mo.restore(1, cas.get_h2eff(), 8)
e_exact = cas.kernel()[0]                          # 검증용 정답

# 문서 4: 회로 각도 (고전 CCSD) → 회로
mol_data = ffsim.MolecularData.from_scf(mf, active_space=range(2, 10))
mol_data.run_ccsd(store_t2=True)
pairs_aa = [(p, p + 1) for p in range(7)]
pairs_ab = [(p, p) for p in range(0, 8, 4)]
op = ffsim.UCJOpSpinBalanced.from_t_amplitudes(mol_data.ccsd_t2, n_reps=1,
                                               interaction_pairs=(pairs_aa, pairs_ab))
qubits = QuantumRegister(16); circuit = QuantumCircuit(qubits)
circuit.append(ffsim.qiskit.PrepareHartreeFockJW(8, (5, 5)), qubits)
circuit.append(ffsim.qiskit.UCJOpSpinBalancedJW(op), qubits)
circuit.measure_all()

# 문서 5: 샘플링
bit_array = StatevectorSampler(seed=1).run([circuit], shots=100_000).result()[0].data.meas

# 문서 6: SQD
result = diagonalize_fermionic_hamiltonian(hcore, eri, bit_array, samples_per_batch=200,
    norb=8, nelec=(5, 5), num_batches=3, max_iterations=5, seed=1)
print(f"SQD {result.energy + ecore:.5f}  CASCI {e_exact:.5f}")

마무리: 이 문서에서 가져갈 것

  • 궤도 1개 = 큐비트 2개(α, β). HF 준비는 X 게이트 몇 개. 비트열 규약은 이 대응에서 나온다.
  • 회로 각도는 고전 CCSD의 t₂ 진폭에서 변환한다. 양자컴퓨터는 상태를 만들고 측정할 뿐, 각도를 스스로 찾지 않는다.
  • UCJ = (궤도 회전 → 대각 쿨롱 → 되돌리기) 반복. LUCJ는 기기 연결에 있는 쌍만 남겨 깊이를 절반으로 줄인다.
  • 초기 회로는 거칠다. N₂에서 π→π* 이중 들뜸을 거의 놓치고 오차 50~70 mHa. 각도 최적화, 샷 증가, 구성 복구가 이를 메운다.
  • 네 문서를 합치면 코드 30줄. 분자 → 적분 → 회로 → 샘플 → SQD.
