텐서곱(Tensor Product)과 여러 큐빗

큐빗 두 개의 계수는 어떻게 네 개가 될까?

먼저 알면 좋아요 · 계산 기저 측정과 에너지 측정(Energy Measurement)

01 · 정의와 핵심

은 두 계의 상태 공간을 하나의 전체 상태 공간으로 결합하는 연산입니다. 두 계가 각각 로 독립적으로 준비되었다면, 전체 는 두 의 텐서곱으로 표현됩니다.

A와 B를 각각 0 또는 1로 측정하면 가능한 결과 쌍은 00·01·10·11입니다. 이 문서에서는 왼쪽 비트가 A, 오른쪽 비트가 B이며, 의 도 이 순서로 읽습니다. 화학의 스핀이나 번호를 뜻하는 표기는 아닙니다.

독립적으로 준비한 A의 계수가 a, b이고 B의 계수가 c, d라면, 전체 계수는 ac, ad, bc, bd가 됩니다. 확률을 먼저 더하는 것이 아니라, 각 결과 쌍에 해당하는 진폭을 곱합니다.

03 · 기억할 점

스스로 확인하기 · 큐빗 둘을 한 번 측정하면 네 계수를 읽을 수 있을까요?

아니요. 계산 기저 측정 한 번은 00·01·10·11 중 하나를 줍니다. 네 계수는 측정 전 상태를 표현합니다.

일반적인 계수는 일 수 있습니다. 각 결과 확률은 계수의 절댓값 제곱입니다. 독립적으로 준비한 이 예제에서는 공동 확률이 각 큐빗 확률의 곱이 됩니다.

큐빗 수가 늘어나면 무엇이 늘어날까?

n개 큐빗에는 2ⁿ개의 계산 기저 상태가 있습니다. 큐빗 2개는 4개, 3개는 8개입니다. 이는 상태를 표현할 좌표의 수이지, 한 번 측정해서 모두 읽을 수 있는 숫자의 수는 아닙니다. 한 번 측정하면 n자리 비트열 하나를 얻습니다.

전체 상태 공간은 텐서곱으로 구성하지만, 모든 전체 상태가 개별 상태 벡터의 텐서곱으로 분리되지는 않습니다. 분리되지 않는 순수상태는 다음 페이지의 얽힌 상태입니다.
