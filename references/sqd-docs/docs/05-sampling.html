샘플링: 비트열 얻기
양자 상태에서 bit_array까지

SQD 함수의 마지막 인자 bit_array가 무엇이고 어떻게 만들어지는지 따라갑니다. 문서 1과 같은 N₂(cc-pVDZ, 활성 8궤도·10전자)를 쓰며, 숫자는 전부 실제 계산값입니다. 양자 회로는 문서 4에서 다뤘는데, 회로 자체의 근사 오차와 분리해서 보기 위해 여기서는 회로가 완벽했다고 가정하고 정확한 바닥상태(CASCI)에서 직접 샘플링합니다. 실제 기기에서는 상태가 근사이고 잡음이 섞이는데, 그 효과는 5절에서 따로 다룹니다.

양자컴퓨터를 한 번 측정하면 비트열 하나가 나오고, 그 비트열은 전자 배치 하나입니다. 수만 번 측정해 모은 비트열 목록이 SQD에 넘기는 "중요한 배치 후보"입니다.

한눈에 보기

1. 측정 한 번 = 배치 하나

회로가 준비한 상태는 여러 배치가 섞인 것입니다. |Ψ⟩ = Σ c_x |x⟩ 에서 x가 배치(비트열), c_x가 진폭. 측정하면 그중 하나가 확률 |c_x|²로 튀어나옵니다(Born 규칙). 측정은 "어떤 배치인가"만 알려 주고 c_x의 값이나 부호는 알려 주지 않습니다.

N₂의 정확한 바닥상태에서 |c_x|²가 큰 배치들을 보면, HF 기준 배치 하나가 94%를 차지하고 나머지는 모두 1% 미만입니다.

상위 k개11050100500
누적 확률0.9420.9720.9980.99971.000

이것이 SQD가 성립하는 이유입니다. 3,136개 중 50개면 상태를 거의 다 표현할 수 있고, 그 50개는 측정하면 저절로 자주 나옵니다. 궤도 36개·전자 36개로 가면 전체는 10¹⁸개지만 "중요한 몇 백만 개"가 같은 역할을 합니다.

2. 측정을 반복하면

측정 횟수를 "샷(shot)"이라 부릅니다. 샷을 늘릴수록 더 많은 종류의 배치가 나오지만, 새로 나오는 배치는 점점 덜 중요한 것들입니다.

SQD 논문에서 샷을 수만~수십만 번 쓰는 것은 이 꼬리 부분의 작은 배치들까지 모으기 위해서입니다. 작지만 많은 배치들이 합쳐져 마지막 수 mHa의 정확도를 만듭니다.

3. 비트열 읽는 법

궤도 8개면 큐비트 16개이고, 비트열은 16자리입니다. 규약은 문서 2·6과 같습니다. 왼쪽 8비트가 β, 오른쪽 8비트가 α, 각 절반 안에서는 궤도 번호가 큰 쪽이 왼쪽.

4. BitArray 형식

Qiskit의 Sampler는 측정 결과를 BitArray로 돌려줍니다. 샷 하나당 비트열 하나를 담은 2차원 비트 배열이며, 같은 비트열이 몇 번 나왔는지 세면 counts 사전이 됩니다. 두 형식은 서로 변환되고, SQD 함수는 어느 쪽이든 받습니다.

# 실제 기기/시뮬레이터에서
from qiskit.primitives import StatevectorSampler
sampler = StatevectorSampler()
job = sampler.run([circuit], shots=10_000)
bit_array = job.result()[0].data.meas        # BitArray, num_bits=16, num_shots=10000

# counts 사전에서 만들 때 (이 문서의 예처럼 직접 샘플링했을 때)
from qiskit.primitives import BitArray
counts = {"0001111100011111": 9400, "0011011100110111": 45, ...}
bit_array = BitArray.from_counts(counts, num_bits=16)   # num_bits 꼭 지정

bit_array.get_counts()      # 다시 사전으로
bit_array.num_shots, bit_array.num_bits

from_counts에 num_bits를 빼면 Qiskit이 문자열을 정수로 읽어 앞의 0을 버리고 비트 수를 잘못 추정합니다(위 예에서 16이 아니라 14가 됨). 그러면 β 절반의 길이가 어긋나 후선별이 전부 실패합니다. 조용히 틀리는 실수라 반드시 지정하세요.

5. 잡음이 하는 일

실제 기기에서는 측정 직전이나 측정 중에 비트가 뒤집힙니다. 가장 단순한 모형은 "각 비트가 독립적으로 확률 p로 뒤집힌다"입니다. 비트가 하나만 뒤집혀도 그 절반의 1 개수가 5에서 4나 6으로 바뀌어, 전자 수가 틀린 불가능한 배치가 됩니다.

두 가지가 보입니다. 첫째, 잡음은 샷을 "버리게" 만듭니다. p가 5%면 절반 이상을 잃습니다. 둘째, 잡음은 가짜 배치를 "만듭니다". 비트 두 개가 반대 방향으로 뒤집히면 전자 수는 맞지만 실제 상태에는 없는 배치가 됩니다. 첫 번째는 샷을 더 쏘면 되지만, 두 번째는 걸러낼 수 없어서 SQD의 구성 복구 루프가 필요합니다.

6. 후선별

SQD 패키지가 비트열을 받아 가장 먼저 하는 일이 전자 수 검사입니다. 오른쪽 절반(α)의 1 개수가 5, 왼쪽 절반(β)의 1 개수가 5인 비트열만 남기고, 남은 것들의 확률을 합이 1이 되도록 다시 정규화합니다.

from qiskit_addon_sqd.counts import bit_array_to_arrays
from qiskit_addon_sqd.subsampling import postselect_by_hamming_right_and_left

bitstrings, probs = bit_array_to_arrays(bit_array)
# bitstrings: bool[고유 비트열 수, 16], probs: 빈도 / 총 샷

kept, kept_probs = postselect_by_hamming_right_and_left(
    bitstrings, probs, hamming_right=5, hamming_left=5,   # = nelec
)

이 단계에서 걸러지는 것은 "확실히 틀린" 비트열뿐입니다. 전자 수가 맞는 가짜 배치는 통과하며, 그것을 다루는 것이 다음 단계(구성 복구)입니다. diagonalize_fermionic_hamiltonian은 첫 반복에서 이 후선별을 내부적으로 호출하므로 직접 부를 필요는 없지만, 몇 %가 살아남는지는 기기 상태를 가늠하는 좋은 지표라 따로 찍어 보는 것이 좋습니다.

7. SQD로 넘기기

from qiskit_addon_sqd.fermion import diagonalize_fermionic_hamiltonian

result = diagonalize_fermionic_hamiltonian(
    hcore, eri,                 # 앞 문서: PySCF에서
    bit_array,                  # 이 문서: 측정 결과 그대로. 후선별은 함수 안에서
    samples_per_batch=300,
    norb=8, nelec=(5, 5),
    num_batches=5, max_iterations=10,
)
print(result.energy + ecore)    # CASCI 값 -109.034407 에 접근해야 함

입력 다섯 개가 모두 모였습니다. hcore, eri, norb, nelec은 분자를 숫자로 바꾼 것이고, bit_array는 그 분자의 바닥상태를 양자컴퓨터가 "어떤 배치들로 이루어졌는지" 알려 준 것입니다.

전체 코드

이 문서의 숫자를 재현하는 코드입니다. 양자 회로 대신 CASCI 벡터에서 샘플링하므로 Qiskit 시뮬레이터 없이 돌아갑니다.

import numpy as np
from pyscf import gto, scf, mcscf, fci
from qiskit.primitives import BitArray

# 앞 문서와 같은 준비
mol = gto.M(atom="N 0 0 0; N 0 0 1.098", basis="cc-pvdz")
mf = scf.RHF(mol).run()
cas = mcscf.CASCI(mf, 8, (5, 5)); cas.kernel()
norb, (na, nb) = 8, (5, 5)

# 1. 정확한 바닥상태의 |c_x|² (56×56 = 3,136개 배치)
P = cas.ci ** 2
str_a = fci.cistring.make_strings(range(norb), na)   # α 문자열 56개 (정수)
str_b = fci.cistring.make_strings(range(norb), nb)

def to_bitstring(ia, ib):                         # [β 8비트 | α 8비트]
    return format(str_b[ib], "08b") + format(str_a[ia], "08b")

# 2. Born 규칙대로 샘플링 (이상적인 양자컴퓨터)
rng = np.random.default_rng(1)
flat = P.ravel()
idx = rng.choice(flat.size, size=10_000, p=flat)
shots = [to_bitstring(*np.unravel_index(i, P.shape)) for i in idx]

# 5. 비트 뒤집힘 잡음 (선택)
p_flip = 0.02
bits = np.array([[int(c) for c in s] for s in shots], dtype=bool)
bits ^= rng.random(bits.shape) < p_flip
shots = ["".join(map(str, row.astype(int))) for row in bits]

# 4. BitArray로
counts = {}
for s in shots: counts[s] = counts.get(s, 0) + 1
bit_array = BitArray.from_counts(counts, num_bits=2 * norb)

# 6. 몇 %가 살아남는지
from qiskit_addon_sqd.counts import bit_array_to_arrays
from qiskit_addon_sqd.subsampling import postselect_by_hamming_right_and_left
bs, pr = bit_array_to_arrays(bit_array)
kept, _ = postselect_by_hamming_right_and_left(bs, pr, hamming_right=na, hamming_left=nb)
print(f"고유 비트열 {len(bs)}개 중 {len(kept)}개 통과")

마무리: 이 문서에서 가져갈 것

  • 측정 한 번 = 비트열 하나 = 배치 하나. 빈도 ≈ |c_x|².
  • 중요한 배치는 적고(N₂는 50개면 99.8%), 측정하면 저절로 자주 나온다. 그래서 SQD가 된다.
  • 샷을 늘리면 꼬리의 작은 배치들이 모인다. 수만~수십만 샷이 보통.
  • BitArray는 샷×비트의 2차원 배열. from_counts에는 num_bits를 꼭 지정.
  • 잡음은 샷을 버리게도 하고(전자 수 불일치), 가짜 배치를 만들기도 한다(개수는 맞음). 전자는 후선별이, 후자는 구성 복구가 맡는다.
  • 이 문서는 회로가 완벽하다고 가정했다. 실제 회로가 만드는 상태는 근사라서 |c_x|² 분포가 조금 다르며, 그 차이는 문서 4의 5절에 있다.
