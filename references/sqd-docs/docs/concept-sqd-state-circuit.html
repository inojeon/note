상태 준비 회로(State Preparation Circuit) 읽기

X·CNOT·회전 게이트를 지나며 전자 배치의 진폭이 어떻게 달라질까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

상태 준비 회로(State Preparation Circuit)는 알려진 초기 상태에 를 순서대로 적용하여 원하는 상태를 만드는 회로입니다. 게이트는 의 진폭과 을 바꾸는 유니터리 연산입니다.

회로를 읽는 세 가지 규칙

X는 해당 의 0과 1을 바꿉니다. CNOT은 제어 큐빗이 1인 에서만 표적 비트를 바꿉니다. Rᵧ는 회전각에 따라 0과 1의 진폭을 섞습니다. 상태에서는 이 규칙이 각 성분에 선형적으로 적용됩니다.

비트열은 q₃q₂q₁q₀ = β₁β₀α₁α₀ 순서입니다. 이 설명용 회로는 0000에서 출발하여 X 두 개로 기준 배치 0101을 준비하고, 마지막에 0101과 1010의 중첩을 만듭니다.

실험 · 게이트를 하나씩 적용하기

선은 큐빗, ●는 제어, ⊕는 CNOT의 표적입니다. 모바일에서는 현재 단계의 게이트를 크게 표시합니다.

현재 배치실수 진폭측정 시 확률

이 표는 시뮬레이터가 계산한 상태입니다. 실제 장치에서 한 번 측정하면 이 표 전체가 아니라 비트열 하나를 얻습니다.

중간 단계에서 전자 수가 달라 보이는 이유

CNOT 묶음은 원하는 두 배치를 한 큐빗의 회전으로 섞기 쉽게 잠시 다시 표현합니다. 따라서 중간 비트열을 전자 점유로 읽으면 전자 수가 달라질 수 있습니다. 준비를 마친 상태는 0101과 1010만 포함하므로 α·β 전자 수가 각각 1입니다. 중간에 측정하면 준비가 중단되므로 마지막 상태와 다른 표본을 얻습니다.

실제 SQD의 상태 준비에는 UCJ(Unitary Cluster Jastrow) 같은 더 풍부한 회로를 사용할 수 있습니다. 여기의 간단한 회로는 UCJ가 아니며, 모든 입력 상태에서 전자 수를 보존하는 일반 화학 들뜸 연산자도 아닙니다. 정해진 기준 배치에서 목표 상태를 만드는 방법을 보여줍니다.

수학 · 회로가 목표 상태를 만드는 과정

C를 CNOT(0→1), CNOT(0→2), CNOT(0→3)의 묶음이라고 쓰면 C는 0101을 1011로 바꿉니다. 이때 회전 대상 q₀는 1입니다.

R_y(-\theta)|1\rangle=\sin(\theta/2)|0\rangle+\cos(\theta/2)|1\rangle

회전 직후의 상태는 다음과 같습니다.

\sin(\theta/2)|1010\rangle+\cos(\theta/2)|1011\rangle

CNOT를 역순으로 되돌리면 q₀가 0인 1010은 그대로이고, q₀가 1인 1011은 0101로 돌아갑니다.

|\psi\rangle=\cos(\theta/2)|0101\rangle+\sin(\theta/2)|1010\rangle

이것은 기준 배치에 대한 준비 결과입니다. 회로 전체를 임의의 입력에 적용한 작용까지 일반 이중 들뜸 유니터리와 같다고 해석하지 않습니다.

R_y(\phi)=\begin{pmatrix}\cos(\phi/2)&-\sin(\phi/2)\\\sin(\phi/2)&\cos(\phi/2)\end{pmatrix}

SQD로 이어가기

회로의 마지막 상태를 반복해서 준비하고 로 측정하면 표본을 얻습니다. 각도는 원하는 전자 배치가 포함되도록 정하는 이지, 을 회전시키는 각도가 아닙니다.
