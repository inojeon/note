문서 3 / 6

UCJ 회로 안쪽
층의 구조, 각도의 출처, 최적화

문서 4에서 상자 세 개로 그렸던 회로를 엽니다. 각 층이 큐비트에 실제로 무슨 게이트를 거는지, 각도 136개가 어떻게 나뉘는지, 그리고 각도를 최적화하면 얼마나 좋아지는지. N₂(활성 8궤도·10전자), ffsim, 실제 계산값입니다.

UCJ 회로의 각도는 두 묶음입니다. "전자를 어떤 방향으로 섞을지"(궤도 회전)와 "섞인 전자 쌍에 얼마나 위상을 줄지"(쿨롱). 둘 다 고전 CCSD에서 출발값을 얻고, 필요하면 에너지를 보며 다듬습니다.

한눈에 보기

1. 궤도 회전 층

궤도 회전은 "궤도를 새로 정의하는" 연산입니다. 전자 수는 그대로 두고, 전자가 궤도 p와 q에 걸쳐 있도록 섞습니다. 8×8 유니타리 행렬 하나로 표현되고, 큐비트에서는 이웃한 큐비트 쌍에 거는 2×2 회전(Givens 회전) 28개로 분해됩니다. 28 = C(8,2), 모든 궤도 쌍을 한 번씩 섞는 셈입니다.

왜 이웃 쌍만으로 충분한가 하면, 임의의 8×8 유니타리는 이웃 쌍 회전 28개의 곱으로 항상 쓸 수 있기 때문입니다(QR 분해의 양자판). 그래서 궤도 회전은 기기 연결성과 무관하게 항상 얕고, UCJ와 LUCJ에서 차이가 없습니다.

2. 대각 쿨롱 층

궤도 회전으로 전자를 섞어 놓은 뒤, 큐비트 쌍마다 "둘 다 1이면 위상 eiJ"를 겁니다. 문서 2에서 본 ZiZj 항이 바로 이것이고, 게이트로는 큐비트 쌍 하나당 2큐비트 게이트 하나입니다. 위상의 크기 J가 쌍마다 다른 각도이고, 어떤 쌍에 걸지가 UCJ와 LUCJ의 차이입니다.

3. t₂에서 각도로

CCSD의 t₂는 "전자 쌍 (i, j)가 (a, b)로 함께 들뜨는 진폭"이고, 모양은 점유 5 × 점유 5 × 가상 3 × 가상 3 = 225개입니다. 이것을 (궤도 회전, 쿨롱) 쌍으로 바꾸는 것이 from_t_amplitudes이며, 안에서는 t₂를 행렬로 펴서 고유분해(이중 인수분해)합니다.

단계하는 일결과
1t₂를 (ia) × (jb) 행렬로 펴서 고유분해고유벡터마다 "들뜸 방향" 하나
2각 고유벡터(8×8 행렬)를 다시 고유분해궤도 회전 U + 대각 위상 J
3고유값이 큰 순서로 n_reps개 선택반복 하나당 (U, Jαα, Jαβ)

즉 t₂ 안의 "가장 큰 들뜸 방향"을 하나씩 떼어 반복 층 하나로 만드는 것입니다. 1회 반복은 가장 큰 방향 하나만 쓰고, 나머지는 버립니다. 문서 4에서 초기 회로가 π→π* 이중 들뜸을 놓친 이유가 여기 있습니다. 그 방향이 두 번째 이하였던 것입니다.

4. 반복 횟수

n_reps를 늘리면 t₂의 더 많은 방향을 담지만, 각도와 깊이가 비례해서 늘어납니다. 그리고 변환만 한 상태에서는 반복을 늘려도 에너지가 단조롭게 좋아지지 않습니다(UCJ 2회가 1회보다 나쁨). 각 층이 독립적으로 근사된 것이라 서로 간섭하기 때문이고, 이것이 최적화가 필요한 두 번째 이유입니다.

회로n_reps각도변환만 (mHa)최적화 후 (mHa)겹침 전 → 후
UCJ113649.59.40.958 → 0.992
UCJ227253.3—0.945
LUCJ17369.942.90.947 → 0.959
LUCJ214662.228.30.950 → 0.973

오차는 CASCI 대비. 최적화는 L-BFGS-B 60회 반복, 시뮬레이터 에너지를 목적함수로 사용. 실제 기기에서는 에너지 추정 자체에 샷 잡음이 있어 더 어렵습니다.

5. 각도 최적화가 바꾸는 것

최적화는 회로가 만드는 상태의 에너지를 각도에 대해 최소화합니다. 136개 변수의 고전 최적화 문제이고, 에너지 한 번 계산에 상태벡터 시뮬레이션 한 번이 들어갑니다. 결과를 배치 확률로 보면 무엇이 달라졌는지 보입니다.

그래서 실제 SQD 실험의 순서는 "t₂로 초기 각도 → 시뮬레이터나 기기에서 최적화 → 최적화된 회로로 대량 샘플링 → SQD"입니다. 최적화를 생략하면 문서 4처럼 샷을 10배 쏟아부어도 오차가 10 mHa대에 머뭅니다. 반대로 회로가 좋으면 적은 샷으로도 중요한 배치가 고르게 나옵니다.

import scipy.optimize

x0 = op.to_parameters(interaction_pairs=pairs)          # 변환만 한 각도 136개

def energy(x):
    op_x = ffsim.UCJOpSpinBalanced.from_parameters(x, norb=8, n_reps=1, interaction_pairs=pairs)
    psi = ffsim.apply_unitary(ref, op_x, norb=8, nelec=(5, 5))
    return np.vdot(psi, H @ psi).real                   # 상태벡터 시뮬레이션

res = scipy.optimize.minimize(energy, x0, method="L-BFGS-B", options={"maxiter": 60})
op_opt = ffsim.UCJOpSpinBalanced.from_parameters(res.x, norb=8, n_reps=1, interaction_pairs=pairs)
# UCJ: -108.98491 → -109.02503 (CASCI -109.03441)

전체 코드

import numpy as np, scipy.optimize, ffsim
from pyscf import gto, scf, mcscf

mol = gto.M(atom="N 0 0 0; N 0 0 1.098", basis="cc-pvdz")
mf = scf.RHF(mol).run()
cas = mcscf.CASCI(mf, 8, (5, 5)); e_exact = cas.kernel()[0]

mol_data = ffsim.MolecularData.from_scf(mf, active_space=range(2, 10))
mol_data.run_ccsd(store_t2=True)
norb, nelec = 8, (5, 5)
H = ffsim.linear_operator(mol_data.hamiltonian, norb=norb, nelec=nelec)   # ecore 포함
ref = ffsim.hartree_fock_state(norb, nelec)

# 쌍 선택: None = UCJ, 튜플 = LUCJ
pairs = None
# pairs = ([(p, p + 1) for p in range(7)], [(p, p) for p in range(0, 8, 4)])

op = ffsim.UCJOpSpinBalanced.from_t_amplitudes(mol_data.ccsd_t2, n_reps=1, interaction_pairs=pairs)
x0 = op.to_parameters(interaction_pairs=pairs)
print("각도 수", len(x0))                                   # 136 (UCJ) / 73 (LUCJ)

def energy(x):
    op_x = ffsim.UCJOpSpinBalanced.from_parameters(x, norb=norb, n_reps=1, interaction_pairs=pairs)
    psi = ffsim.apply_unitary(ref, op_x, norb=norb, nelec=nelec)
    return np.vdot(psi, H @ psi).real

print("변환만:", energy(x0))
res = scipy.optimize.minimize(energy, x0, method="L-BFGS-B", options={"maxiter": 60})
print("최적화:", res.fun, "CASCI:", e_exact)

# 최적화된 회로로 문서 4의 샘플링·SQD를 그대로 이어가면 됨
op_opt = ffsim.UCJOpSpinBalanced.from_parameters(res.x, norb=norb, n_reps=1, interaction_pairs=pairs)

마무리: 이 문서에서 가져갈 것

  • 궤도 회전 = 8×8 유니타리 = 이웃 쌍 Givens 회전 28개. 기기 연결성과 무관하게 항상 얕다.
  • 대각 쿨롱 = 큐비트 쌍마다 ZZ 위상 하나. 어떤 쌍을 쓰는지가 UCJ(72개)와 LUCJ(9개)의 차이이고, 깊이 차이의 전부다.
  • t₂ → 각도는 "가장 큰 들뜸 방향"을 이중 고유분해로 떼어내는 것. 1회 반복은 방향 하나만 담아서 거칠다.
  • n_reps를 늘려도 변환만으로는 좋아지지 않는다. 최적화가 필요하다.
  • 최적화(136변수, L-BFGS)로 UCJ 오차 50 → 9 mHa, 겹침 0.958 → 0.992. 실험 순서는 초기각 → 최적화 → 샘플링 → SQD.
