전자 배치(Electronic Configuration)

같은 공간 오비탈 점유가 같은 다전자 상태를 뜻할까?

먼저: 궤도(Orbital) · 전자 스핀(Electron Spin) · 파울리 배타 원리(Pauli Exclusion Principle)

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

는 선택한 일전자 궤도들에 전자가 어떻게 점유되어 있는지를 지정한 것입니다. 의 만 지정하는 배치와, 스핀까지 포함한 스핀 궤도(Spin Orbital)의 점유를 지정하는 표현을 구별해야 합니다.

쉽게 풀어 보면

배치는 “어떤 궤도가 몇 개의 전자로 채워졌는가”를 말합니다. 전자들이 실제로 어디에 놓였는지를 그린 사진이나 궤적은 아닙니다. 공간 오비탈 a에 두 전자가 있으면 a², a와 b에 하나씩 있으면 a¹b¹처럼 씁니다.

공간 오비탈 점유가 같아도 스핀 점유는 여러 가지일 수 있습니다. 정해진 순서의 스핀 궤도에서 점유된 것들을 고르면 하나의 을 만들 수 있지만, 공간 배치 하나가 항상 식 하나를 뜻하지는 않습니다.

실험: 같은 a¹b¹에 몇 가지 스핀 점유가 있을까?

설명용 공간 오비탈 a, b와 전자 2개입니다. ↑는 α 스핀, ↓는 β 스핀을 뜻하며 실제 공간 방향이나 전자의 자전 그림이 아닙니다. 여섯 가능한 스핀 궤도 점유 중 하나를 고르세요.

계산 확인: 왜 6개이며, a¹b¹은 왜 4개일까?

네 스핀 궤도 aα, aβ, bα, bβ에서 서로 다른 두 개를 고르므로 전체 행렬식은 4개 중 2개를 고르는 경우의 수는 6개입니다. a¹b¹에서는 a의 스핀 두 가지와 b의 스핀 두 가지를 독립적으로 고르므로 2 × 2 = 4개입니다. a²와 b²는 각각 하나입니다.

총 스핀의 z성분은 M_S = (알파 전자 수 − 베타 전자 수)/2이고 실제 각운동량 성분은 ℏMS입니다. 여기서 MS가 같다고 총 스핀 S까지 같다는 뜻은 아닙니다.

적용 조건: 배치, 행렬식, 전체 상태는 다릅니다

용어 “배치”는 문헌에 따라 스핀 궤도의 구체적인 점유까지 포함합니다. 이 페이지는 공간 배치와 스핀 궤도 점유를 명시적으로 나눠 씁니다. 원자의 1s²2s² 같은 배치도 껍질·부분껍질 수준의 정보를 압축해서 나타낸 것입니다.

하나의 행렬식은 파울리 원리를 만족하는 반대칭 상태입니다. aα·bβ와 aβ·bα처럼 MS = 0인 개별 행렬식은 일반적으로 총 스핀 제곱의 고유상태가 아닙니다. 적절히 조합하면 스핀에 맞춘 상태를 만들 수 있습니다.

실제 여러 전자 상태는 여러 행렬식의 일 수 있습니다. 어떤 궤도를 선택했는지에 따라 점유 표현도 달라집니다. 점유만으로 상태의 모든 진폭이나 을 알 수는 없습니다.
