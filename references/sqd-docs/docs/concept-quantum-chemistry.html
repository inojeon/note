양자화학(Quantum Chemistry)

상태를 읽고, 에너지를 구하고,
분자를 이해하기까지.

분자의 전자 구조를 이해하는 데 필요한 개념을 하나씩 연결합니다. 먼저 와 에너지를 읽는 여섯 개의 노트부터 시작하세요. 이후에는 아래 후속 학습 지도의 16개 노트로 이어집니다.

어디서 시작할까요?

상태를 나타내는 숫자가 어떻게 관측 확률과 에너지로 이어지는지 읽습니다.

  1. 양자 상태
  2. 확률 진폭
  3. 중첩과 위상
  4. 관측량
  5. 해밀토니안
  6. 슈뢰딩거 방정식

01 양자 상태 읽기

  • 상태의 표현양자 상태(Quantum State)와 파동함수(Wavefunction)하나의 상태를 벡터와 함수로 어떻게 나타낼까?
  • 숫자에서 확률로확률 진폭(Probability Amplitude)과 보른 규칙(Born Rule)음수나 복소수인 계수에서 확률을 어떻게 구할까?
  • 계수의 상대적 관계중첩(Superposition)과 상대 위상(Relative Phase)확률이 같아 보여도 서로 다른 상태일 수 있을까?
  • 측정 결과와 평균관측량(Observable)과 기댓값(Expectation Value)평균 에너지가 한 번의 측정 결과와 다를 수 있을까?

02 에너지 문제 세우기

  • 수학에서 화학으로해밀토니안(Hamiltonian)과 에너지에너지 행렬의 각 숫자는 화학적으로 무엇을 뜻할까?
  • 상태가 만족할 방정식슈뢰딩거 방정식(Schrödinger Equation)어떤 상태에서 에너지가 하나로 정해질까?

양자컴퓨터가 처음이라면

  • 양자화학과 VQE 사이큐빗·회로·측정 학습 지도전자 상태를 큐빗으로 표현하고 회로로 바꾸어 측정하려면?

양자 알고리즘으로 이어가기

  • 회로 · 측정 · 최적화VQE 학습 지도평균 에너지를 낮추며 분자의 바닥상태를 어떻게 찾을까?

수학이 낯설 때 돌아갈 곳

상태의 표현은 벡터(Vector)와 기저(Basis), 확률과 평균은 내적(Inner Product), 에너지 방정식은 고유값(Eigenvalue)과 대각화(Diagonalization)에 연결됩니다.

수학의 기저와 화학의 기저 집합은 어떻게 연결될까?

수학의 는 선택한 의 표현 기준입니다. 화학의 은 한 전자 을 전개하는 함수들의 모음이며, 일반적으로 서로 할 필요는 없습니다.

다전자 상태는 오비탈들로 만든 ·슬레이터 식의 기저에서 전개할 수 있습니다. 오비탈 전개 계수와 다전자 상태의 배치 계수는 서로 다릅니다. 이 지도에서는 먼저 에서 상태를 읽는 법을 익힙니다.

04 여러 전자 표현하기

  • 한 전자의 상태오비탈(Orbital)전자의 상태를 함수와 확률 밀도로 어떻게 나타낼까?
  • 스핀 측정전자 스핀(Electron Spin)측정 방향을 바꾸면 스핀 결과는 어떻게 달라질까?
  • 전자 점유의 제약파울리 배타 원리(Pauli Exclusion Principle)같은 오비탈에 전자를 몇 개 넣을 수 있을까?
  • 다전자 점유 표현전자 배치(Electronic Configuration)전자 배치만으로 다전자 상태가 정해질까?
  • 반대칭 상태슬레이터 행렬식(Slater Determinant)전자를 맞바꿀 때 부호가 바뀌는 상태를 어떻게 만들까?

05 행렬의 숫자 계산하기

  • 함수의 표현 공간기저 집합(Basis Set)함수를 더 많이 쓰면 어떤 근사가 나아질까?
  • 실제 기저 선택STO-3G와 기저 집합의 선택3G, (d,p), ++는 무엇을 바꾸고 함수 수는 얼마나 늘어날까?
  • 원자에서 분자로분자 오비탈(Molecular Orbital)원자 중심 함수를 합치면 분자 오비탈은 어떻게 달라질까?
  • 에너지의 재료일전자·이전자 적분(One- and Two-Electron Integrals)에너지 행렬을 만드는 숫자는 어디에서 올까?
  • 배치 사이의 연결해밀토니안 행렬원소(Hamiltonian Matrix Element)어떤 전자 배치들이 서로 연결될까?

06 근사하고 화학적으로 해석하기

  • 에너지의 상계변분 원리(Variational Principle)시험 상태의 에너지는 정확한 바닥 에너지와 어떤 관계일까?
  • 평균장과 반복하트리–폭(Hartree–Fock)과 자기일관장(Self-Consistent Field)전자가 만드는 평균장을 어떻게 스스로 일치시킬까?
  • 평균장을 넘어서전자 상관(Electron Correlation)한 행렬식의 평균장으로 놓치는 것은 무엇일까?
  • 여러 배치의 조합구성 상호작용(Configuration Interaction)여러 행렬식을 섞으면 에너지는 어떻게 달라질까?
  • 계산 공간 선택활성 공간(Active Space)어떤 전자와 오비탈의 재배치를 직접 계산할까?
  • 결합과 힘퍼텐셜 에너지 곡선(Potential Energy Curve)결합 길이와 에너지·힘은 어떻게 연결될까?
