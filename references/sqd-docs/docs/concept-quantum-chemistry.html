양자화학(Quantum Chemistry)

상태를 읽고, 에너지를 구하고,
분자를 이해하기까지.

분자의 전자 구조를 이해하는 데 필요한 개념을 하나씩 연결합니다. 먼저 와 에너지를 읽는 여섯 개의 노트부터 시작하세요.

어디서 시작할까요?

상태를 나타내는 숫자가 어떻게 관측 확률과 에너지로 이어지는지 읽습니다.

01 양자 상태 읽기

  • 상태의 표현양자 상태(Quantum State)와 파동함수(Wavefunction)하나의 상태를 벡터와 함수로 어떻게 나타낼까?
  • 숫자에서 확률로확률 진폭(Probability Amplitude)과 보른 규칙(Born Rule)음수나 복소수인 계수에서 확률을 어떻게 구할까?
  • 계수의 상대적 관계중첩(Superposition)과 상대 위상(Relative Phase)확률이 같아 보여도 서로 다른 상태일 수 있을까?
  • 측정 결과와 평균관측량(Observable)과 기댓값(Expectation Value)평균 에너지가 한 번의 측정 결과와 다를 수 있을까?

02 에너지 문제 세우기

  • 수학에서 화학으로해밀토니안(Hamiltonian)과 에너지에너지 행렬의 각 숫자는 화학적으로 무엇을 뜻할까?
  • 상태가 만족할 방정식슈뢰딩거 방정식(Schrödinger Equation)어떤 상태에서 에너지가 하나로 정해질까?

수학이 낯설 때 돌아갈 곳

상태의 표현은 벡터(Vector)와 기저(Basis), 확률과 평균은 내적(Inner Product), 에너지 방정식은 고유값(Eigenvalue)과 대각화(Diagonalization)에 연결됩니다.

수학의 기저와 화학의 기저 집합은 어떻게 연결될까?

수학의 는 선택한 의 표현 기준입니다. 화학의 은 한 전자 오비탈을 전개하는 함수들의 모음이며, 일반적으로 서로 할 필요는 없습니다.

다전자 상태는 오비탈들로 만든 ·슬레이터 식의 기저에서 전개할 수 있습니다. 오비탈 전개 계수와 다전자 상태의 배치 계수는 서로 다릅니다. 이 지도에서는 먼저 에서 상태를 읽는 법을 익힙니다.

아래 주제는 다음 묶음에서 개별 페이지로 추가할 예정입니다.

  1. 핵과 전자의 움직임 나누기

    보른–오펜하이머 근사(Born–Oppenheimer Approximation): 핵 위치를 정하고 전자 문제를 풀어도 되는 이유와 조건.

  2. 여러 전자 표현하기

    오비탈(Orbital) → 전자 스핀(Electron Spin) → 파울리 배타 원리(Pauli Exclusion Principle) → 전자 배치(Electronic Configuration) → 슬레이터 행렬식(Slater Determinant).

  3. 행렬의 숫자 계산하기

    기저 집합(Basis Set) → 분자 오비탈(Molecular Orbital)의 전개 → 일전자·이전자 적분(One- and Two-Electron Integrals) → .

  4. 근사하고 화학적으로 해석하기

    변분 원리(Variational Principle) → –폭(Hartree–Fock)·자기일관장(Self-Consistent Field) → 전자 상관(Electron Correlation) → 구성 상호작용(Configuration Interaction)· → 퍼텐셜 에너지 곡선(Potential Energy Curve).
