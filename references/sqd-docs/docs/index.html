"준비"는 수학 문서를 위한 벡터·행렬·확률 기초, "수학"은 입문의 대각화·샘플링을 식으로 세운 보충, "배경"은 주기율표·원자 상식, "입문"이 배경지식 없는 독자용 출발점, 0번이 코드가 있는 시작점이고, 1~6이 데이터 흐름 순서로 깊이 들어갑니다. 모두 같은 예제(N₂, cc-pVDZ, 활성 8궤도·10전자)와 실제 계산값을 쓰고, 폰에서도 읽히도록 만들었습니다. 각 문서 위아래에 이전·다음 문서 링크가 있습니다. qiskit-addon-sqd 0.14, PySCF 2.x, ffsim, Qiskit 2.x 기준.

비전공자가 알아야 할 범위

반드시: 배치 = 비트열, 비트열 규약 [β|α], norb·nelec은 크기이고 hcore·eri는 가격표, 측정 빈도 ≈ 진폭², 양자컴퓨터는 후보만 만들고 에너지는 고전 대각화가 구함, 전자 수 불일치 = 잡음.

알면 좋음: 기저 = 블록 수, 활성 공간 = 궤도 자르기, HF는 출발점, charge·spin이 전자 수와 α/β를 정함, ecore를 더해야 전체 에너지, 상관이 커지는 상황이 SQD가 필요한 이유.
