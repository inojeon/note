내적(Inner Product)과 길이

두 벡터가 얼마나 같은 방향을 향할까?

먼저 알면 좋은 개념: 벡터

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

실수 의 은 두 에 실수를 대응시키며, ··을 만족하는 연산입니다. 길이 또는 은 ‖v‖ = √⟨v,v⟩로 정의합니다.

쉽게 풀어 보면

실수 의 표준 내적은 같은 위치의 을 곱해서 더합니다. 쌍선형성은 각 입력에 대해 덧셈과 수 배를 보존한다는 뜻이고, 대칭성은 입력 순서를 바꿔도 같다는 뜻입니다. 자기 자신과의 내적은 음수가 아니며, 0이 되는 것은 뿐입니다. 내적이 0인 두 벡터는 한다고 합니다.

작은 예시

v=34의 길이는 5입니다. x축 u=10와의 내적은 3으로, x축 방향의 성분을 알려 줍니다. v를 길이로 나눈 3/54/5는 길이 1인 벡터입니다.

수식으로 확인하기

u·v = Σᵢ uᵢvᵢ, ‖v‖ = √(v·v), cos θ = (u·v)/(‖u‖‖v‖)

적용 조건과 주의점

각도 식은 두 벡터가 모두 0이 아닐 때만 씁니다. 의 표준 내적은 첫 벡터 성분을 로 바꿔 곱합니다.

대칭 행렬(Symmetric Matrix) · 부분공간(Subspace)과 투영

벡터 · 대칭 행렬 · 멱법(Power Method)과 반복 · 부분공간과 투영

이전: 기저(Basis)와 좌표다음: 행렬과 선형변환(Linear Transformation)
벡터 공간(Vector Space)벡터의 덧셈과 스칼라배가 정의되고 벡터 공간의 공리를 만족하는 집합입니다.간단한 예시실수 좌표쌍 전체에서는 두 벡터를 더해도, 2배 해도 다시 실수 좌표쌍입니다. 덧셈·스칼라배와 벡터 공간의 공리를 만족합니다.10 + 01 = 11실수 좌표쌍 전체는 성분별 덧셈과 실수배에 대해 벡터 공간을 이룹니다.관련 개념 읽기 →내적(Inner Product)두 벡터에서 하나의 수를 만드는 연산입니다. 길이와 직교성을 정의하는 데 사용합니다.간단한 예시실수 표준 내적은 대응하는 성분의 곱을 더합니다.12 · 34 = 1×3+2×4 = 11실수 좌표의 표준 내적은 같은 위치 성분들의 곱을 더합니다.벡터(Vector)덧셈과 스칼라배가 정의된 벡터 공간의 원소입니다. 기저를 정하면 좌표로 나타낼 수 있습니다.간단한 예시평면의 표준 기저에서 오른쪽 3, 위로 4인 벡터입니다. 두 배하면 두 성분이 모두 두 배가 됩니다.v = 34 → 2v = 68같은 벡터도 기저에 따라 좌표가 달라집니다.관련 개념 읽기 →쌍선형성(Bilinearity)두 입력 각각에 대해 덧셈과 실수배를 보존하는 성질입니다. 다른 입력을 고정해 두고 확인합니다.간단한 예시실수 표준 내적에서 u를 두 배하면 내적도 두 배입니다. 두 입력 각각에 대해 이런 선형성이 성립합니다.u = 10, w = 34; ⟨2u,w⟩ = 6 = 2⟨u,w⟩⟨au+bv,w⟩ = a⟨u,w⟩+b⟨v,w⟩ ⟨u,av+bw⟩ = a⟨u,v⟩+b⟨u,w⟩ 복소수 내적에는 한쪽 입력에 켤레가 들어가는 반쌍선형성을 씁니다.대칭성(Symmetry)실수 내적에서 두 입력의 순서를 바꾸어도 값이 같은 성질입니다.간단한 예시실수 표준 내적에서 같은 성분끼리 곱해 더하면, 순서를 바꾸어도 같은 수가 나옵니다.u = 12, v = 34; ⟨u,v⟩ = 1×3+2×4 = 11 = ⟨v,u⟩⟨u,v⟩ = ⟨v,u⟩ 복소수 내적에서는 순서를 바꾸면 켤레가 되는 켤레 대칭성을 씁니다.양의 정부호성(Positive Definiteness)자기 자신과의 내적이 음수가 아니며 영벡터일 때만 0인 성질입니다.간단한 예시표준 내적에서 0이 아닌 벡터의 자기 내적은 양수입니다. 영벡터의 자기 내적만 0입니다.v = 34; ⟨v,v⟩ = 3²+4² = 25 > 0⟨v,v⟩ ≥ 0; ⟨v,v⟩ = 0 ⇔ v = 0 표준 내적에서 성분이 3, 4인 벡터는 3²+4² = 25입니다.노름(Norm)벡터의 크기를 재는 함수입니다. 양의 정부호성, 절대 동차성, 삼각부등식을 만족합니다.간단한 예시표준 유클리드 노름에서는 피타고라스로 벡터의 길이를 구합니다.v = 34, ‖v‖ = √(3²+4²) = 5‖av‖ = |a|‖v‖ ‖u+v‖ ≤ ‖u‖+‖v‖ 내적이 유도하는 노름은 ‖v‖ = √⟨v,v⟩입니다. 모든 노름이 내적에서 나오는 것은 아닙니다.좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.관련 개념 읽기 →성분(Component)좌표 벡터나 행렬의 개별 수입니다. 벡터 성분의 의미는 기저와 성분의 순서에 따라 달라집니다.간단한 예시아래 열벡터의 첫째 성분은 3, 둘째 성분은 4입니다.34성분이 3, 4인 평면 벡터에서 첫째 성분은 3입니다.관련 개념 읽기 →영벡터(Zero Vector)어떤 벡터에 더해도 그 벡터를 바꾸지 않는 덧셈의 항등원입니다.간단한 예시평면의 영벡터는 모든 성분이 0입니다. 어떤 벡터에 더해도 그 벡터를 그대로 둡니다.0 = 00, 21 + 0 = 21v+0 = v 어떤 기저에서나 모든 좌표가 0입니다.관련 개념 읽기 →직교(Orthogonality)두 벡터의 내적이 0인 관계입니다. 유클리드 공간의 0이 아닌 벡터에서는 서로 수직이라는 뜻입니다.간단한 예시x축 방향과 y축 방향의 내적이 0이므로 두 방향은 직교합니다.10 · 01 = 0⟨u,v⟩ = 0단위 벡터(Unit Vector)선택한 노름에 대해 길이가 1인 벡터입니다.간단한 예시성분이 3/5, 4/5인 벡터의 표준 유클리드 길이는 1입니다.q = 3/54/5, ‖q‖ = √(9/25+16/25) = 10이 아닌 v를 v/‖v‖로 바꾸면 단위 벡터가 됩니다.복소수(Complex Number)실수 a, b와 i² = −1인 i를 사용해 a+bi로 나타내는 수입니다.간단한 예시2+3i는 실수부가 2, 허수부가 3인 복소수입니다. i를 두 번 곱하면 −1입니다.(2+3i)+(1−i) = 3+2i; i² = −1양자 상태의 계수는 일반적으로 복소수입니다.켤레(Complex Conjugate)복소수 a+bi에서 허수부의 부호를 바꾼 a−bi입니다.간단한 예시허수부의 부호만 바꾸면 켤레가 됩니다. 실수부는 그대로입니다.z = 2+3i → z̄ = 2−3iz = 2+3i이면 z̄ = 2−3i입니다. 복소수 내적은 첫 벡터 성분을 켤레로 바꾸는 관례를 이 노트에서 사용합니다.
