계산 기저(Computational Basis)와 상태 벡터

왜 0 상태는 영벡터가 아니라 첫째 좌표가 1인 벡터일까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

는 상태를 비트 이름 0과 1로 구별해 표현하는 표준 입니다. 한 큐빗에서는 순서를 0, 1로 정합니다.

의 은 의 이름이 아니라, 각 기저 상태를 곱하는 계수입니다. 0 상태를 그대로 만들려면 0 상태에 1을 곱하고, 1 상태에는 0을 곱합니다.

|0\rangle=\begin{pmatrix}1\\0\end{pmatrix}　|1\rangle=\begin{pmatrix}0\\1\end{pmatrix}

일반적인 상태와 정규화

|\psi\rangle=a|0\rangle+b|1\rangle

그 는 로 적습니다.

\mathbf c=\begin{pmatrix}a\\b\end{pmatrix}

된 상태에서는 |a|² + |b|² = 1이며, 0·1 측정 확률이 각각 |a|², |b|²입니다. 모든 성분이 0인 는 정규화할 수 없으므로 가 아닙니다.

이 좌표는 선택한 기저에 대한 표현입니다. 기저를 바꾸면 같은 상태의 좌표도 바뀔 수 있습니다. 또한 0 상태가 반드시 가장 낮은 에너지의 상태인 것은 아닙니다.
