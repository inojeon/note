변분 원리(Variational Principle)

어떤 상태의 에너지를 낮추면 정확한 바닥상태에 가까워질까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

는 같은 H에 대해, 허용되는 된 시험 상태의 에너지 이 정확한 에너지보다 낮지 않다는 정리입니다. E[\psi]=\langle\psi|H|\psi\rangle\ge E_0이며, 정규화하지 않은 0이 아닌 상태에는 분모 \langle\psi|\psi\rangle를 넣은 을 사용합니다.

쉽게 풀어 보면

시험 상태를 바꾸어 에너지를 내리는 것은 더 좋은 바닥상태 근사를 찾는 방법입니다. 탐색 가능한 상태를 제한하면 최선의 에너지도 높아질 수 있습니다. 같은 H에서 더 큰 상태 집합을 탐색한 최솟값은 더 작은 집합의 최솟값보다 높아지지 않습니다.

상계라는 말에는 비교 조건이 있습니다. 해밀토니안, 전자 수와 필요한 대칭 조건, 에너지 영점을 맞추어야 합니다. 계산 근사 자체가 H를 바꾸었다면 서로 다른 계산값의 크기만으로 변분 원리를 적용할 수 없습니다.

실험: 벡터를 작게 만들면 에너지도 낮아질까?

설명용 두 상태 H를 고정합니다. 에서 방향 c=(\cos\theta,\sin\theta)^T는 정규화되어 있고, 실제 입력 는 u=sc입니다. s를 바꾸어도 정규화된 물리적 상태는 같습니다. 모든 에너지는 임의 단위입니다.

조건과 수식

왜 E₀ 아래로 내려갈 수 없을까?

에르미트 H의 고유상태로 |\psi\rangle=\sum_n c_n|n\rangle를 전개합니다. 정규화 조건은 \sum_n|c_n|^2=1입니다.

E[\psi]=\sum_n|c_n|^2E_n\ge E_0\sum_n|c_n|^2=E_0

즉 에너지는 고유에너지의 가중 평균입니다. 바닥 고유공간에만 이 있으면 등호가 성립합니다. 바닥상태가 되어 있으면 그 고유공간 안의 도 등호를 만족합니다.

기저를 늘리면 항상 정확해질까?

같은 H와 같은 허용 조건에서 탐색 공간이 V_1\subseteq V_2이면 E_0\le E_{\min}(V_2)\le E_{\min}(V_1)입니다. 단순히 기저 함수 개수만 늘고 두 공간이 포함 관계가 아니라면 에너지가 단조 감소한다는 보장은 없습니다.

이 실험에서 첫째 하나의 에너지와 두 상태 모형의 정확한 바닥 에너지를 비교합니다. 실제 분자에서는 유한 기저 안의 정확한 에너지와 완전한 공간의 정확한 에너지도 구별해야 합니다. 함수가 H의 정의역에 속하고 필요한 적분이 유한해야 하며, 바닥 에너지는 아래로 유계라고 가정합니다.

변분 원리는 최적화 알고리즘이 전역 최솟값을 찾는다는 보장은 아닙니다. 또한 에너지가 가깝다고 모든 이 정확한 것도 아닙니다. 의 상계를 얻으려면 조건이나 최소–최대 원리 등 추가 조건이 필요합니다.
