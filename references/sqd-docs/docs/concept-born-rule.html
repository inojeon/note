확률 진폭(Probability Amplitude)과 보른 규칙(Born Rule)

음수나 복소수인 진폭이 어떻게 확률이 될까?

먼저 알면 좋아요 · 양자 상태(Quantum State)와 파동함수(Wavefunction) · 내적(Inner Product)과 길이

01 · 정의와 핵심

은 로부터 측정 결과의 확률을 정하는 규칙입니다. 된 |ψ⟩를 {|i⟩}에서 측정하면, 결과 i를 얻을 확률은 pᵢ = |⟨i|ψ⟩|²입니다. 계수 cᵢ = ⟨i|ψ⟩를 이라 부릅니다.

쉽게 풀어 보면

진폭은 확률을 계산하기 전의 값입니다. 실수 진폭은 음수일 수 있고, 일반적으로는 일 수 있습니다. 진폭의 절댓값을 제곱하면 음수가 아닌 확률을 얻습니다. 상태의 길이가 1이고 가 완전하면 모든 결과의 확률을 더한 값도 1입니다.

어느 기준으로 측정하는지도 함께 정해야 합니다. 아래에서는 두 결과 |0⟩, |1⟩를 구별하는 측정 기저를 고정하고 상태의 계수만 바꿉니다.

03 · 기억할 점

스스로 확인하기 · 진폭이 음수이면 확률도 음수일까요?

아니요. 확률은 진폭의 절댓값 제곱입니다. 부호나 상대 위상은 다른 기저에서의 측정에 영향을 줄 수 있습니다.

계산 확인 · 실수와 복소수의 차이

c = cos θsin θ,　p₀ = cos²θ,　p₁ = sin²θ

이 실수 모형에서는 부호가 달라도 제곱이 같습니다. ‘두 진폭 양수’와 ‘첫 진폭만 음수’를 번갈아 누르면, 는 달라지지만 이 측정의 확률은 같습니다. 하나의 부호만 바꾸면 일반적으로 다른 상태이므로, 다른 에서 측정하면 구별할 수 있습니다. 이 점은 중첩과 상대 위상으로 이어집니다.

복소 진폭 c = a + ib에서는 c²가 아니라 |c|² = c* c = a² + b²를 사용합니다. 별표는 입니다. 모든 진폭에 같은 을 곱해도 모든 측정 확률은 같습니다.

적용 범위 · 한 번의 측정, 축퇴, 연속 위치

확률은 한 번의 결과를 미리 확정하지 않습니다. 같은 상태를 새로 준비해 같은 측정을 반복하면 결과의 상대 빈도를 비교할 수 있습니다. 유한 번의 빈도는 이론 확률과 정확히 같을 필요가 없습니다.

여러 기저 가 같은 관측값 a에 속하면, 그 결과에 해당하는 으로의 Pa를 써서 p(a) = ⟨ψ|Pₐ|ψ⟩로 계산합니다.

연속 위치에서는 의 |ψ(r)|²가 입니다. 영역 R에서 찾을 확률은 ∫R|ψ(r)|² d³r이며, 정규화된 공간 파동함수에서는 전체 공간의 적분이 1입니다. 밀도 자체를 한 점의 확률로 읽지 않습니다.
