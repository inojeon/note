지도를 고르고, 한 번에 하나의 개념을 배워보세요.

각 노트는 하나의 질문을 다룹니다. 정의를 읽고 예시를 살펴본 뒤, 확인 질문으로 이해를 점검하세요. 카드에는 다음 노트에서 알아볼 질문이 적혀 있습니다.

짧은 노트를 읽는 방법
  1. 정의와 핵심에서 뜻과 필요한 전제를 확인합니다.
  2. 예시와 실험에서는 안내한 조작 한 가지부터 해 봅니다.
  3. 기억할 점의 확인 질문에 답하고, 필요한 수식만 펼칩니다.
  4. 연결해서 읽기 카드에서 궁금한 다음 질문으로 이동합니다.

점선 밑줄 용어는 마우스나 터치로 정의와 예시를 볼 수 있습니다. 위쪽 노트 검색으로 개념 이름을 바로 찾을 수도 있습니다.

각 지도는 짧은 개념 설명과 직접 조작하는 실험으로 이어집니다. 이미 익숙한 주제는 건너뛰고 궁금한 곳부터 시작해도 좋습니다.

개념 사이의 연결이 궁금하다면전체 분야, 노트의 이웃, 목표별 학습 경로를 관계도로 살펴보세요.
