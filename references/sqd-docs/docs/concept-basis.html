기저(Basis)와 좌표(Coordinates)

같은 벡터를 다른 숫자로 적을 수 있을까?

먼저 알면 좋아요 · 벡터(Vector)

01 · 정의와 핵심

의 는 그 공간을 하면서 인 들의 모음입니다. 기저에 대한 는 벡터를 기저 벡터들의 으로 나타낼 때의 계수입니다.

쉽게 풀어 보면

모든 벡터를 이 기준들의 조합으로 만들 수 있고, 각 벡터를 만드는 계수는 유일합니다. 기준들이 서로 중복된 방향을 담지 않기 때문입니다. 같은 벡터라도 기저를 바꾸면 좌표는 달라집니다.

02 · 예시와 실험

이렇게 살펴보세요같은 벡터를 두 기저의 선형결합으로 각각 복원해 보세요.

작은 예시

기준 e₁=10, e₂=01에서는 벡터 34의 좌표가 34입니다. 기준을 b₁=11, b₂=01로 바꾸면 같은 벡터가 3b₁+b₂이므로 좌표는 31입니다.

03 · 기억할 점

스스로 확인하기 · 기저를 바꾸면 벡터 자체도 바뀔까요?

같은 벡터를 다른 기준으로 적는 경우에는 좌표만 바뀝니다. 새 기저와 새 계수를 함께 사용하면 원래 벡터를 복원합니다.

적용 조건과 주의점

기저를 바꾸는 것은 대상 자체를 바꾸는 일과 다릅니다. 기저는 서로 수직일 필요가 없으며, 기저 벡터 수가 공간의 입니다.

수식으로 확인하기

v = 3e₁ + 4e₂ = 3b₁ + b₂

벡터 공간(Vector Space)벡터의 덧셈과 스칼라배가 정의되고 벡터 공간의 공리를 만족하는 집합입니다.간단한 예시실수 좌표쌍 전체에서는 두 벡터를 더해도, 2배 해도 다시 실수 좌표쌍입니다. 덧셈·스칼라배와 벡터 공간의 공리를 만족합니다.10 + 01 = 11실수 좌표쌍 전체는 성분별 덧셈과 실수배에 대해 벡터 공간을 이룹니다.관련 개념 읽기 →기저(Basis)공간을 생성하면서 선형 독립인 벡터들의 모음입니다. 모든 벡터를 기저의 유일한 선형결합으로 나타낼 수 있습니다.간단한 예시오른쪽 1과 위로 1을 기준으로 고르면, 평면의 모든 벡터를 유일한 조합으로 표현할 수 있습니다.310 + 401 = 34v = c₁b₁ + … + cₙbₙ생성(Span)주어진 벡터들의 모든 유한한 선형결합을 모은 공간입니다. 그 결과가 전체 공간이면 그 벡터들이 공간을 생성한다고 합니다.간단한 예시벡터 하나의 모든 실수배를 모으면 원점을 지나는 x축 전체를 만듭니다.span{10} = {a0 : a는 실수}span{u,v} = {au+bv : a,b는 스칼라}선형 독립(Linear Independence)벡터들의 선형결합이 영벡터가 되는 경우가 모든 계수가 0인 경우뿐이라는 조건입니다.간단한 예시첫째 좌표와 둘째 좌표가 각각 0이어야 하므로, 아래 두 벡터는 선형 독립입니다.a10 + b01 = 00 ⇒ a = b = 0a₁v₁+…+aₙvₙ = 0 ⇒ 모든 aᵢ = 0벡터(Vector)덧셈과 스칼라배가 정의된 벡터 공간의 원소입니다. 기저를 정하면 좌표로 나타낼 수 있습니다.간단한 예시평면의 표준 기저에서 오른쪽 3, 위로 4인 벡터입니다. 두 배하면 두 성분이 모두 두 배가 됩니다.v = 34 → 2v = 68같은 벡터도 기저에 따라 좌표가 달라집니다.관련 개념 읽기 →좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.선형결합(Linear Combination)여러 벡터를 각각 수 배한 뒤 더한 벡터입니다.간단한 예시첫 벡터를 2배하고 둘째 벡터를 3배해서 빼는 것도 선형결합입니다.210 − 301 = 2-32u−3v도 선형결합입니다.차원(Dimension)유한차원 벡터 공간에서 기저를 이루는 벡터의 개수입니다.간단한 예시평면 전체에는 두 기준 방향이 필요하지만, x축 위의 벡터들은 한 기준 방향만 있으면 됩니다.평면의 기저: 10, 01 → 2차원; x축의 기저: 10 → 1차원평면 전체의 차원은 2, 원점을 지나는 직선의 차원은 1입니다.
