VQE 학습 지도

상태를 만들고, 에너지를 재고,
더 낮은 에너지의 상태를 찾아갑니다.

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

은 조절 가능한 양자회로로 시험 상태를 준비하고, 측정한 평균 에너지를 고전 컴퓨터로 최소화하여 를 근사하는 알고리즘입니다.

앞서 배운 문제를 상태 준비 → 에너지 측정 → 조정의 반복으로 풉니다.

선수 개념: 양자 상태 · 해밀토니안 · 슈뢰딩거 방정식 · 고유값과 고유벡터

01 · 왜 에너지를 낮출까?

  • 평균 에너지와 기댓값(Expectation Value)한 번의 측정 결과와 평균은 어떻게 다를까?
  • 변분 원리(Variational Principle)왜 평균 에너지는 바닥상태 에너지보다 낮아질 수 없을까?

02 · 어떤 상태를 만들까?

  • 안사츠(Ansatz)어떤 상태들을 후보로 찾아볼까?
  • 매개변수화 양자회로(Parameterized Quantum Circuit)회전각을 바꾸면 상태가 어떻게 달라질까?

03 · 에너지를 어떻게 측정할까?

  • 파울리 분해(Pauli Decomposition)행렬의 에너지를 측정 가능한 항으로 어떻게 나눌까?
  • 반복 측정(Shots)과 오차같은 상태를 측정해도 추정값이 흔들리는 이유는?

04 · 반복해서 답을 찾기

  • 고전 최적화(Classical Optimization)다음 회전각을 어떻게 고를까?
  • VQE 알고리즘(Variational Quantum Eigensolver)준비·측정·계산·갱신은 어떻게 이어질까?

05 · 실제 분자로 연결하기

  • 전자 상태와 큐빗(Fermion-to-Qubit Mapping)전자 배치를 어떻게 비트열과 큐빗으로 표현할까?
  • VQE로 수소 분자(H₂) 계산하기같은 분자 문제의 VQE와 대각화 결과는 일치할까?
모든 페이지를 연결하는 작은 예제

먼저 같은 설명용 으로 회로·측정·최적화를 연결합니다. 에너지는 임의 단위입니다.

H = [[0.8, −0.5], [−0.5, 1.2]]

의 각도 θ를 바꾸어 시험 상태를 만듭니다. θ는 회로의 회전각이며, 의 두 계수에는 θ/2가 들어갑니다.

|ψ(θ)⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩

기존 변분 원리 실험은 벡터 각도를 조절합니다. 그 각도의 두 배가 여기의 회로 각도입니다. 마지막 수소 분자 페이지에서는 실제 분자에서 계산한 다른 해밀토니안을 사용합니다.

어디까지 이해하면 될까요?

먼저 01~04를 읽으면 VQE의 한 번의 반복을 설명할 수 있습니다. 화학 계산이 목적이라면 05에서 와 분자 에너지를 연결하세요.

회로가 표현할 수 있는 상태와 최적화·측정의 한계 때문에, VQE가 항상 정확한 바닥상태를 찾거나 고전 계산보다 빠르다고 보장되지는 않습니다.

변분 양자 고유값 풀이법(Variational Quantum Eigensolver, VQE)매개변수화한 양자회로로 상태를 준비하고, 에너지 기댓값을 추정한 뒤 고전 최적화로 매개변수를 조정하는 바닥상태 근사 알고리즘입니다.간단한 예시공통 모형에서 회로 각도가 0°이면 에너지는 0.8이고, 90°이면 0.5입니다. 더 낮은 에너지의 후보를 찾도록 각도를 조정합니다.상태 준비 → 측정 → 에너지 계산 → 매개변수 갱신상태 준비 → 측정 → 에너지 계산 → 매개변수 갱신관련 개념 읽기 →바닥상태(Ground State)가능한 에너지 가운데 가장 낮은 에너지를 갖는 양자 상태입니다.간단한 예시고유값이 0과 2인 단순한 에너지 모형에서는 고유값 0의 상태가 바닥상태입니다.H = 0002, c₀ = 10, Hc₀ = 0이 노트의 유한 행렬에서는 최소 고유값에 대응하는 고유벡터로 표현합니다.관련 개념 읽기 →고유값(Eigenvalue)고유벡터를 변환할 때 곱해지는 스칼라입니다.간단한 예시아래 고유벡터를 변환할 때 곱해지는 수 3이 그 벡터의 고유값입니다.A = 2112, A11 = 311 → λ = 3Av = λv에서 λ가 고유값입니다.관련 개념 읽기 →매개변수(Parameter)함수나 회로의 동작을 조절하는 수입니다. VQE에서는 회전 게이트의 각도 등이 해당합니다.간단한 예시Ry 회로의 회전각을 0°에서 90°로 바꾸면 0 상태에서 두 결과가 같은 확률인 상태로 바뀝니다.Ry(0)|0⟩ = |0⟩; Ry(π/2)|0⟩ = (|0⟩+|1⟩)/√2Ry(0)|0⟩ = |0⟩; Ry(π/2)|0⟩ = (|0⟩+|1⟩)/√2관련 개념 읽기 →해밀토니안(Hamiltonian)양자계의 에너지를 나타내는 연산자입니다. 이 노트의 유한차원 정규직교 기저에서는 에르미트 행렬로 표현합니다.간단한 예시두 에너지 준위만 갖는 단순한 모형입니다. 둘째 기저 상태의 에너지 고유값은 2입니다. 여기서 숫자는 선택한 에너지 단위로 읽습니다.H = 0002, H01 = 201Hc = Ec에서 E는 에너지 고유값입니다.관련 개념 읽기 →회전 게이트(Rotation Gate)큐빗 상태를 블로흐 구의 지정한 축 주위로 회전시키는 유니터리 게이트입니다. 전자가 실제 공간에서 도는 궤적을 뜻하지 않습니다.간단한 예시Ry의 각도 90°를 0 상태에 적용하면 두 성분이 모두 1/√2인 상태가 됩니다.Ry(θ)|0⟩의 계수는 cos(θ/2), sin(θ/2)입니다.Ry(θ)|0⟩의 계수는 cos(θ/2), sin(θ/2)입니다.관련 개념 읽기 →벡터(Vector)덧셈과 스칼라배가 정의된 벡터 공간의 원소입니다. 기저를 정하면 좌표로 나타낼 수 있습니다.간단한 예시평면의 표준 기저에서 오른쪽 3, 위로 4인 벡터입니다. 두 배하면 두 성분이 모두 두 배가 됩니다.v = 34 → 2v = 68같은 벡터도 기저에 따라 좌표가 달라집니다.관련 개념 읽기 →전자 배치(Electronic Configuration)선택한 일전자 궤도들에 전자가 어떻게 점유되어 있는지를 지정한 것입니다. 공간 궤도 점유와 스핀 궤도 점유를 구별해서 읽어야 합니다.간단한 예시두 공간 궤도에 하나씩 있는 a¹b¹은 aα·bα, aα·bβ, aβ·bα, aβ·bβ의 네 스핀 궤도 점유를 허용합니다.공간 배치 a¹b¹ → 스핀 점유 2×2=4개; a² → aα·aβ 한 가지공간 배치 a¹b¹만으로 두 전자의 스핀 점유나 전체 상태가 유일하게 정해지지는 않습니다.관련 개념 읽기 →
