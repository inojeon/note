기저 집합(Basis Set)

기저 함수가 부족하면 어떤 오차가 남을까?

먼저: 기저(Basis) · 궤도 · 내적(Inner Product)

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

는 나 일전자 궤도를 으로 근사하기 위해 선택한 함수들의 집합입니다. 유한 를 사용하면 계산을 그 함수들이 하는 함수공간으로 제한합니다. 함수들이 서로 겹칠 수 있으므로, “기저”라는 이름이 성을 보장하지는 않습니다.

쉽게 풀어 보면

컴퓨터는 일반적인 함수 전체를 그대로 다루기 어렵습니다. 미리 고른 함수들에 계수를 곱해 더하고, 그 계수를 조절해서 궤도를 표현합니다. 선택한 함수가 부족하면 계수를 아무리 잘 골라도 표현하지 못하는 모양이 남습니다.

양자화학의 원자 중심 기저 함수들은 보통 서로 하지 않습니다. S가 이 관계를 기록하므로 전개 계수의 제곱을 곧바로 확률로 읽을 수 없습니다.

실험: 함수 하나를 더하면 어떤 모양이 생길까?

실제 원자 기저 대신 구간 [−1, 1]의 설명용 함수 세 개를 사용합니다. 기저 집합을 순서대로 늘리고, 고정된 목표 함수를 각 함수공간에 직교 투영(Orthogonal Projection)한 최선의 근사와 비교합니다. 근사 함수는 따로 하지 않습니다.

ℓ₀ = 1/√2ℓ₁ = √(3/2)xℓ₂ = √(5/2)(3x²−1)/2

실제 실험 기저는 χ₁ = ℓ₀, χ₂ = (ℓ₀+ℓ₁)/√2, χ₃ = ℓ₂입니다. 각각은 길이가 1이지만 χ₁과 χ₂의 겹침은 1/√2입니다.

정규화된 목표는 f = (2ℓ₀+ℓ₁+ℓ₂)/√6입니다. 첫 m개의 기저 함수를 사용하면 그 공간은 첫 m개의 ℓ 함수가 생성하는 공간과 같습니다. 포함하지 못한 정규직교 의 제곱 합이 오차이므로, m = 1, 2, 3일 때 오차 제곱은 각각 1/3, 1/6, 0입니다.

S의 원소는 기저 함수들의 내적이며 근사 함수 노름 제곱은 c†Sc

세 함수를 모두 쓰면 c는 열벡터 1/√6, 1/√3, 1/√6입니다. 계수 제곱 합은 2/3이지만, 겹침의 교차 항을 더한 실제 노름 제곱은 1입니다.

적용 조건: 기저 오차와 전자 상관은 별개입니다

이 실험은 작은 함수공간을 큰 함수공간에 포함시키는 된 기저 집합이므로 최선의 투영 오차가 증가하지 않습니다. 일반적으로 함수 수만 같다고 정확도가 같거나, 임의로 고른 큰 집합이 항상 더 좋다는 뜻은 아닙니다.

화학에서는 등을 원자 중심에 놓고, 궤도의 방향 변형이나 넓게 퍼진 꼬리를 표현하는 함수도 추가합니다. 겹침이 너무 큰 함수들은 수치적인 선형 종속 문제를 일으킬 수 있습니다.

일전자 기저를 늘려도 한 식만 사용하는 근사의 오차가 모두 사라지는 것은 아닙니다. 기저 집합과 여러 전자 상태를 다루는 방법을 함께 지정해야 계산의 정확도를 비교할 수 있습니다.
