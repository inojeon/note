벡터(Vector)

여러 성분(Component)을 하나의 대상으로 다루려면?

먼저 알면 좋아요 · 이 노트부터 시작해도 됩니다.

01 · 정의와 핵심

는 의 원소입니다. 벡터 공간은 덧셈과 가 정의되고, ··과 · 등 벡터 공간의 를 만족하는 집합입니다.

쉽게 풀어 보면

벡터는 서로 더하거나 수를 곱해 새로운 벡터를 만들 수 있는 대상입니다. 공간에서는 를 정해 로 나타냅니다. 평면의 화살표는 대표적인 예이고, 다항식이나 함수도 벡터가 될 수 있습니다.

이 노트에서는 을 세로로 쌓는 로 씁니다. 예를 들어 34는 에서 오른쪽으로 3, 위로 4인 화살표입니다. 가로 표기 (3, 4)도 같은 좌표를 간단히 적는 관례이지만, 곱셈에서는 행·열의 구분이 중요합니다.

02 · 예시와 실험

이렇게 살펴보세요방향 각도를 바꾸면서 두 성분은 변해도 길이가 1로 유지되는지 보세요.

작은 예시

평면에서 오른쪽으로 3, 위로 4 이동하는 화살표를 34로 적습니다. 두 배하면 68이 되고, 1−1을 더하면 43이 됩니다. 같은 성분끼리 계산합니다.

03 · 기억할 점

스스로 확인하기 · 벡터의 성분 제곱을 항상 확률로 읽어도 될까요?

아니요. 일반 벡터의 성분은 좌표입니다. 정규화된 양자 상태를 정규직교 측정 기저로 표현했을 때에만 절댓값 제곱을 그 측정의 확률로 읽습니다.

적용 조건과 주의점

성분의 순서와 기저를 알아야 숫자를 해석할 수 있습니다. 열벡터는 n×1, 는 1×n 모양입니다. 는 행과 열을 바꾸는 연산입니다. 벡터가 항상 실제 공간의 위치를 뜻하는 것은 아닙니다.

수식으로 확인하기

v = 34, 2v = 68, v + 1−1 = 43

벡터(Vector)덧셈과 스칼라배가 정의된 벡터 공간의 원소입니다. 기저를 정하면 좌표로 나타낼 수 있습니다.간단한 예시평면의 표준 기저에서 오른쪽 3, 위로 4인 벡터입니다. 두 배하면 두 성분이 모두 두 배가 됩니다.v = 34 → 2v = 68같은 벡터도 기저에 따라 좌표가 달라집니다.벡터 공간(Vector Space)벡터의 덧셈과 스칼라배가 정의되고 벡터 공간의 공리를 만족하는 집합입니다.간단한 예시실수 좌표쌍 전체에서는 두 벡터를 더해도, 2배 해도 다시 실수 좌표쌍입니다. 덧셈·스칼라배와 벡터 공간의 공리를 만족합니다.10 + 01 = 11실수 좌표쌍 전체는 성분별 덧셈과 실수배에 대해 벡터 공간을 이룹니다.스칼라배(Scalar Multiplication)벡터에 수를 곱하는 연산입니다. 좌표에서는 모든 성분에 같은 수를 곱합니다.간단한 예시벡터에 −2를 곱하면 길이는 2배가 되고 방향은 반대가 됩니다.−2 × 12 = -2-4음수를 곱하면 실수 공간에서 방향이 반대가 됩니다.결합 법칙(Associativity)계산의 묶는 위치를 바꾸어도 결과가 같다는 법칙입니다.간단한 예시u, v, w가 모두 같은 단위 벡터일 때, 어느 쪽 덧셈을 먼저 해도 세 배인 벡터가 됩니다.u = v = w = 10 → (u+v)+w = u+(v+w) = 30(u+v)+w = u+(v+w) a(bv) = (ab)v교환 법칙(Commutativity)연산에서 두 입력의 순서를 바꾸어도 결과가 같은 성질입니다. 전자 좌표를 맞바꾸는 교환이나 페르미온의 반교환과는 다른 개념입니다.간단한 예시두 벡터를 더하는 순서를 바꾸어도 결과가 같습니다. 하나는 오른쪽 1, 다른 하나는 위로 2인 경우입니다.10 + 02 = 02 + 10 = 12u+v = v+u 행렬 곱셈은 일반적으로 이 법칙을 만족하지 않습니다.분배 법칙(Distributivity)합에 대한 수 배를 각각의 수 배의 합으로 풀어 쓸 수 있다는 법칙입니다.간단한 예시두 벡터를 더한 뒤 2배해도, 각각 2배한 뒤 더해도 같습니다.2(10 + 01) = 20 + 02 = 22a(u+v) = au+av (a+b)v = av+bv영벡터(Zero Vector)어떤 벡터에 더해도 그 벡터를 바꾸지 않는 덧셈의 항등원입니다.간단한 예시평면의 영벡터는 모든 성분이 0입니다. 어떤 벡터에 더해도 그 벡터를 그대로 둡니다.0 = 00, 21 + 0 = 21v+0 = v 어떤 기저에서나 모든 좌표가 0입니다.덧셈의 역원(Additive Inverse)벡터에 더했을 때 영벡터가 되는 벡터입니다.간단한 예시성분의 부호를 모두 바꾼 벡터를 더하면 영벡터가 됩니다.2-1 + -21 = 00v+(−v) = 0공리(Axiom)이론에서 기본 전제로 받아들이는 규칙입니다. 벡터 공간 공리는 어떤 집합과 연산을 벡터 공간이라고 부를지 정합니다.간단한 예시벡터 공간 공리 중 하나는 영벡터가 있다는 조건입니다. 평면의 표준 연산에서는 아래처럼 0을 더해도 원래 벡터가 됩니다.34 + 00 = 34예: 벡터를 더했을 때 같은 공간 안에 남아야 합니다.유한차원(Finite-dimensional)유한 개의 기저 벡터로 공간 전체를 표현할 수 있다는 뜻입니다.간단한 예시실수 3차원 좌표 공간은 아래 세 벡터로 생성할 수 있고, 이들이 기저이므로 차원은 유한한 수 3입니다.100, 010, 001평면은 2차원, 3차원 공간은 기저 벡터 3개로 표현합니다.관련 개념 읽기 →기저(Basis)공간을 생성하면서 선형 독립인 벡터들의 모음입니다. 모든 벡터를 기저의 유일한 선형결합으로 나타낼 수 있습니다.간단한 예시오른쪽 1과 위로 1을 기준으로 고르면, 평면의 모든 벡터를 유일한 조합으로 표현할 수 있습니다.310 + 401 = 34v = c₁b₁ + … + cₙbₙ관련 개념 읽기 →좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.관련 개념 읽기 →성분(Component)좌표 벡터나 행렬의 개별 수입니다. 벡터 성분의 의미는 기저와 성분의 순서에 따라 달라집니다.간단한 예시아래 열벡터의 첫째 성분은 3, 둘째 성분은 4입니다.34성분이 3, 4인 평면 벡터에서 첫째 성분은 3입니다.열벡터(Column Vector)성분들을 세로로 나열한 n×1 행렬 형태의 벡터 표현입니다.간단한 예시성분 3과 4를 세로로 적으면 2행 1열인 열벡터입니다.34 ← 2×1행렬 A가 m×n이면 n×1 열벡터를 곱해 m×1 열벡터를 얻습니다.표준 기저(Standard Basis)좌표 하나만 1이고 나머지가 모두 0인 좌표 벡터들입니다.간단한 예시평면의 표준 기저는 각 좌표 방향으로 한 칸인 두 벡터입니다.e₁ = 10, e₂ = 01평면에서는 오른쪽 한 칸과 위로 한 칸을 기준으로 삼습니다.관련 개념 읽기 →행렬(Matrix)수를 행과 열로 배열한 것입니다. 입력·출력의 기저를 정하면 선형변환을 행렬로 표현할 수 있습니다.간단한 예시아래는 수를 2행 3열로 배열한 행렬입니다. 3개 성분의 열벡터를 받아 2개 성분의 열벡터로 보낼 수 있습니다.A = 123456 ← 2×3m×n 행렬은 m개의 행과 n개의 열을 가집니다.관련 개념 읽기 →단위 벡터(Unit Vector)선택한 노름에 대해 길이가 1인 벡터입니다.간단한 예시성분이 3/5, 4/5인 벡터의 표준 유클리드 길이는 1입니다.q = 3/54/5, ‖q‖ = √(9/25+16/25) = 10이 아닌 v를 v/‖v‖로 바꾸면 단위 벡터가 됩니다.관련 개념 읽기 →행벡터(Row Vector)성분들을 가로로 나열한 1×n 행렬 형태의 벡터 표현입니다.간단한 예시성분 3과 4를 가로로 적으면 1행 2열인 행벡터입니다.34 ← 1×2실수 열벡터를 전치하면 대응하는 행벡터가 됩니다.전치(Transpose)행렬의 행과 열을 맞바꾸는 연산입니다.간단한 예시첫째 행의 1, 2가 첫째 열로, 둘째 행의 3, 4가 둘째 열로 옮겨집니다.A = 1234 → Aᵀ = 1324(Aᵀ)ᵢⱼ = Aⱼᵢ 복소수 행렬의 켤레전치는 이 연산에 복소켤레를 더한 것입니다.관련 개념 읽기 →
