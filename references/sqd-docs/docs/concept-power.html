멱법(Power Method)과 반복

행렬을 계속 곱하면 어떤 성분(Component)이 남을까?

먼저 알면 좋아요 · 고유벡터(Eigenvector)와 고유값(Eigenvalue) · 내적(Inner Product)과 길이

01 · 정의와 핵심

은 시작 에 을 반복해서 곱하고 하여, 에 대응하는 를 근사하는 반복 알고리즘입니다. 지배 고유값은 절댓값이 가장 큰 을 뜻합니다.

쉽게 풀어 보면

각 고유방향의 은 반복할 때 해당 고유값의 거듭제곱에 비례해 변합니다. 적절한 조건에서는 절댓값이 큰 고유값의 성분이 상대적으로 두드러집니다. 길이를 다시 맞추면 수치의 크기가 과도하게 커지거나 작아지는 것을 줄일 수 있습니다.

무슨 식을 반복할까?

vk+1 =Avk‖Avk‖

vk는 k번째 벡터, A는 매번 곱하는 같은 행렬입니다. 분모 ‖Avk‖는 곱셈 결과의 , 즉 길이입니다.

① A를 곱하기 → ② 결과의 길이로 나누기.
이 정규화(Normalization)는 방향을 유지하면서 길이만 1로 맞춥니다. Avk가 이면 0으로 나눌 수 없으므로 이 반복식을 적용할 수 없습니다.

첫 세 단계의 실제 계산 펼치기

아래 실험의 행렬과 시작 벡터로 계산해 봅시다.

A = 2112v0 = 10

1회: 곱한 뒤 길이로 나누기

Av0 = 21‖Av0‖ = √(2²+1²) = √5
v1 = 1√521

2회와 3회: 같은 규칙 반복

v2 = 1√4154v3 = 1√3651413

2회째에도 이전의 에 A를 곱하고 길이로 나눕니다. 이전 단계의 공통 배율은 정규화에서 약분되므로 위처럼 쓸 수 있습니다.

어느 방향으로 갈까?

vk → 1√211

이 시작 벡터에서는 두 성분이 비슷해지며 고유값 3의 고유벡터 방향으로 접근합니다. 그 방향의 성분은 곱셈마다 3배, 다른 고유방향의 성분은 1배가 되기 때문입니다. 정규화해도 두 성분의 상대 비율 변화는 유지됩니다.

03 · 기억할 점

스스로 확인하기 · 멱법은 언제나 가장 낮은 에너지를 찾을까요?

아니요. 보통의 멱법은 조건이 맞을 때 절댓값이 가장 큰 고유값의 방향을 찾습니다. 시작 벡터에 그 성분이 있어야 합니다.

적용 조건과 주의점

실험의 ±45°는 정확한 고유벡터 로 계산합니다. 실제 수치 계산에서는 반올림 오차가 작은 다른 고유성분을 만들 수 있습니다.

가능한 행렬에서 절댓값이 유일하게 큰 고유값과 그 방향의 시작 성분이 있어야 일반적인 설명이 성립합니다. 음의 지배 고유값이면 부호가 교대할 수 있습니다. 최소 고유값을 바로 찾는 방법은 아닙니다.

수식으로 확인하기

vₖ₊₁ = Avₖ / ‖Avₖ‖. 고유성분의 상대 크기에는 (λ₂/λ₁)ᵏ가 곱해집니다.

H가 해밀토니안이면 정규화한 상태의 에너지 기댓값이며, u의 전체 배율에 무관합니다.간단한 예시설명용 H = diag(1, 3), u = (2, 0)ᵀ에서 분자는 4, 노름 제곱도 4입니다. 정규화한 에너지는 4가 아니라 1입니다.u = 20; (u†Hu)/(u†u) = 4/4 = 1벡터를 두 배 해도 분자와 분모가 함께 네 배가 되므로 레일리 몫은 같습니다.관련 개념 읽기 →좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.관련 개념 읽기 →대각화(Diagonalization)고유벡터 기저로 바꾸어 행렬을 대각행렬로 표현하는 것입니다.간단한 예시P의 두 열은 A의 고유벡터입니다. 이 기저로 바꾸면 각 성분을 3배·1배하는 D로 계산할 수 있습니다.A = 2112, P = 111-1, D = 3001; A = PDP⁻¹A = PDP⁻¹ 모든 정사각행렬이 대각화되는 것은 아닙니다.관련 개념 읽기 →수렴(Convergence)반복을 계속할수록 값이나 방향이 특정 목표에 가까워지는 성질입니다.간단한 예시수열 1/2, 1/4, 1/8, …은 계속 절반이 되므로 0에 가까워집니다. 이것이 수렴의 간단한 예입니다.aₖ = (1/2)ᵏ → 0 (k → ∞)멱법에서는 보통 지배 고유벡터가 놓인 방향으로의 수렴을 살펴봅니다.
