행렬(Matrix)수를 행과 열로 배열한 것입니다. 입력·출력의 기저를 정하면 선형변환을 행렬로 표현할 수 있습니다.간단한 예시아래는 수를 2행 3열로 배열한 행렬입니다. 3개 성분의 열벡터를 받아 2개 성분의 열벡터로 보낼 수 있습니다.A = 123456 ← 2×3m×n 행렬은 m개의 행과 n개의 열을 가집니다.행(Row)행렬에서 수를 가로로 나열한 줄입니다.간단한 예시아래 행렬의 첫째 행은 1, 2이고 둘째 행은 3, 4입니다. 행은 가로줄입니다.1234행렬의 크기 m×n에서 m은 행의 수입니다.열(Column)행렬에서 수를 세로로 나열한 줄입니다.간단한 예시아래 행렬의 첫째 열은 1, 3이고 둘째 열은 2, 4입니다. 열은 세로줄입니다.1234선형변환 행렬의 각 열은 입력 기저 벡터의 변환 결과입니다.선형변환(Linear Transformation)벡터의 덧셈과 스칼라배를 보존하는 함수입니다.간단한 예시T가 가로 성분을 2배, 세로 성분을 3배로 만드는 변환이라면 덧셈과 수 배를 보존합니다.Txy = 2x3y; T11 = 23T(au+bv) = aT(u)+bT(v)벡터(Vector)덧셈과 스칼라배가 정의된 벡터 공간의 원소입니다. 기저를 정하면 좌표로 나타낼 수 있습니다.간단한 예시평면의 표준 기저에서 오른쪽 3, 위로 4인 벡터입니다. 두 배하면 두 성분이 모두 두 배가 됩니다.v = 34 → 2v = 68같은 벡터도 기저에 따라 좌표가 달라집니다.관련 개념 읽기 →스칼라배(Scalar Multiplication)벡터에 수를 곱하는 연산입니다. 좌표에서는 모든 성분에 같은 수를 곱합니다.간단한 예시벡터에 −2를 곱하면 길이는 2배가 되고 방향은 반대가 됩니다.−2 × 12 = -2-4음수를 곱하면 실수 공간에서 방향이 반대가 됩니다.관련 개념 읽기 →기저(Basis)공간을 생성하면서 선형 독립인 벡터들의 모음입니다. 모든 벡터를 기저의 유일한 선형결합으로 나타낼 수 있습니다.간단한 예시오른쪽 1과 위로 1을 기준으로 고르면, 평면의 모든 벡터를 유일한 조합으로 표현할 수 있습니다.310 + 401 = 34v = c₁b₁ + … + cₙbₙ관련 개념 읽기 →유한차원(Finite-dimensional)유한 개의 기저 벡터로 공간 전체를 표현할 수 있다는 뜻입니다.간단한 예시실수 3차원 좌표 공간은 아래 세 벡터로 생성할 수 있고, 이들이 기저이므로 차원은 유한한 수 3입니다.100, 010, 001평면은 2차원, 3차원 공간은 기저 벡터 3개로 표현합니다.관련 개념 읽기 →좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.관련 개념 읽기 →성분(Component)좌표 벡터나 행렬의 개별 수입니다. 벡터 성분의 의미는 기저와 성분의 순서에 따라 달라집니다.간단한 예시아래 열벡터의 첫째 성분은 3, 둘째 성분은 4입니다.34성분이 3, 4인 평면 벡터에서 첫째 성분은 3입니다.관련 개념 읽기 →
