반복 측정(Shots)과 표본 오차(Sampling Error)

같은 상태를 준비했는데 왜 에너지 추정값이 달라질까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

은 같은 를 새로 준비하고 측정하는 실행을 여러 번 반복하는 것입니다. 결과의 빈도로 확률과 을 추정하며, 유한한 횟수에서는 가 생깁니다.

상태는 같아도 측정 묶음은 달라집니다

동전을 여러 번 던져 앞면 비율을 구하듯, +1과 −1의 횟수로 평균을 구합니다. 한 전자를 계속 측정하는 것이 아니라 매번 같은 상태로 다시 준비합니다.

X 평균 추정 = (+1 횟수 − −1 횟수) / 측정 횟수

앞 페이지와 같은 설명용 H = I − 0.5X − 0.2Z를 사용합니다. X와 Z는 각각 별도의 상태 준비와 측정이 필요합니다. I 항은 정확히 1입니다.

횟수가 많으면 전형적인 흔들림의 크기가 줄어듭니다. 그러나 한 번 더 측정한 결과가 이전보다 반드시 정확한 것은 아닙니다.

추정식·표준오차와 실험 조건

추정 에너지 = 1 − 0.5 X 평균 추정 − 0.2 Z 평균 추정

표준오차는 항별 분산에 계수 제곱을 곱해 합친 후 N으로 나눈 값의 제곱근

표준오차(Standard Error)는 독립적인 측정 묶음을 반복했을 때 추정값 분포의 표준편차입니다. 여기서는 모형의 정확한 확률을 알기 때문에 이론값을 표시합니다. 실제 장치에서는 미지의 확률을 추정해야 합니다. ±1 표준오차는 결과가 반드시 들어가는 범위가 아닙니다.

는 정확한 에너지 기댓값에 적용됩니다. 유한 측정의 추정값이 바닥상태 에너지보다 낮게 나와도 원리를 위반하지 않습니다.

이 실험은 시드가 있는 의사난수로 독립 측정을 모사합니다. 다시 측정하거나 조건을 바꾸면 난수열을 이어 쓰고, 처음으로 버튼만 초기 시드와 조건을 복원합니다. 하드웨어 잡음은 포함하지 않습니다. 상태는 cos(θ/2)|0⟩ + sin(θ/2)|1⟩이며 에너지는 임의 단위 u입니다.
