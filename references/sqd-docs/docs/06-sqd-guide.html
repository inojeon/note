SQD 이해하기
Sample-based Quantum Diagonalization

qiskit-addon-sqd의 구조를 따라가며 알고리즘을 설명합니다. 4절부터는 N₂(활성 8궤도·10전자) 샘플 2만 개에 3% 비트 뒤집힘 잡음을 넣고 실제로 SQD를 돌린 결과를 따라갑니다. 입력이 어디서 오는지는 문서 1~5에 있습니다.

양자컴퓨터에서 뽑은 비트열은 "답의 후보 목록"이고, 진짜 계산은 고전 컴퓨터가 그 후보들로 짠 작은 행렬을 대각화하는 것. 이것이 SQD의 한 줄 요약입니다.

1. 왜 SQD인가

분자의 바닥상태를 정확히 구하려면 가능한 모든 전자 배치로 행렬을 만들어 대각화해야 하는데, 배치 수는 궤도 수에 대해 지수적으로 늘어납니다. 고전 selected-CI는 "중요한 배치만 골라" 작은 행렬을 만들지만, 어떤 배치가 중요한지 미리 알기 어렵습니다.

SQD는 그 선별을 양자컴퓨터에 맡깁니다. 근사 바닥상태를 준비하고 측정하면 비트열 하나가 배치 하나이고, 중요한 배치일수록 자주 나옵니다(문서 5). 그 비트열들을 기저로 삼아 고전 컴퓨터에서 대각화하고, 대각화 결과로 잡음 섞인 비트열을 고쳐 다시 대각화하는 반복이 SQD입니다.

2. 비트열 규약

비트열 하나는 β 배치와 α 배치를 이어 붙인 것입니다. 궤도 N개면 길이 2N, 오른쪽 N비트가 α, 왼쪽 N비트가 β, 각 절반에서 궤도 번호가 큰 쪽이 왼쪽. 문서 2에서 본 큐비트 번호 매기기의 결과입니다.

4. 한 바퀴 이야기: N₂로 따라가기

4절부터는 하나의 실제 실행을 따라갑니다. 입력은 N₂ 정확한 바닥상태에서 뽑은 비트열 20,000개에 비트당 3% 뒤집힘 잡음을 섞은 것. 고유 비트열 643종류 중 전자 수가 맞는 것은 107종류, 확률로는 63%뿐입니다. 나머지 37%는 잡음으로 망가진 것인데, 버리기엔 아깝습니다.

아래 표는 실제 8번 반복의 기록입니다. 첫 반복은 오차 4 mHa, 복구가 시작된 둘째 반복에서 2.5 mHa로 뚝 떨어지고, 이후 부분공간이 조금씩 커지며 1.4 mHa까지 내려갑니다.

5. 후선별: 확실히 틀린 것 버리기

전자 수가 안 맞는 비트열은 물리적으로 불가능하므로 바로 버립니다(문서 5의 6절). N₂ 예에서는 643종류 중 536종류가 여기서 걸러집니다. 걸러진 것 중 가장 흔한 셋을 보면 전부 HF 배치에서 비트 하나만 뒤집힌 것입니다.

걸러진 비트열횟수무엇이 틀렸나
00011110|00011111414β 궤도 0의 전자가 사라짐 (1→0)
00011111|00011101392α 궤도 1의 전자가 사라짐
10011111|00011111382β 궤도 7에 전자가 생김 (0→1)

버려진 것들이 원래 무엇이었는지는 "보면" 알 수 있습니다. 그것을 자동으로 하는 것이 구성 복구입니다.

6. 구성 복구: 점유도로 고치기

첫 대각화를 하고 나면 궤도 점유도가 나옵니다. 각 궤도에 전자가 평균 몇 개 있는지(0~1)입니다. N₂의 첫 반복 결과는 이렇습니다.

복구 규칙은 이 점유도를 "뒤집을 확률"로 쓰는 것입니다. 전자 수가 맞을 때까지 비트를 하나씩 뒤집는데, 어느 비트를 뒤집을지를 점유도로 정합니다.

상황뒤집을 확률예
전자가 모자람 → 어떤 0을 1로?점유도가 높은 궤도일수록 높음궤도 0(0.999)의 0은 거의 확실히 1로, 궤도 7(0.001)의 0은 거의 안 건드림
전자가 남음 → 어떤 1을 0으로?점유도가 낮은 궤도일수록 높음궤도 7의 1은 거의 확실히 0으로, 궤도 0의 1은 거의 안 건드림

5절의 첫 번째 비트열 00011110|00011111(β 전자 4개)에 이 규칙을 200번 적용하면, 200번 모두 궤도 0을 채워 HF 배치로 돌아옵니다. 점유도 0.999와 0.001의 차이가 그만큼 결정적입니다. 복구 뒤 같은 비트열이 된 것들은 확률을 합치므로, 잡음으로 흩어졌던 HF 배치의 무게가 다시 모입니다. N₂ 예에서는 복구 후 유효 비트열이 107종류에서 176종류로 늘었습니다.

7. 부분공간 만들기

고친 비트열에서 samples_per_batch개를 확률에 비례해 뽑아 배치(batch)를 만들고, 배치마다 대각화합니다. 여기서 가장 오해하기 쉬운 점: 뽑힌 비트열 50개가 그대로 기저 50개가 되는 것이 아닙니다.

비트열을 α 절반과 β 절반으로 가르고, 각각의 고유한 문자열 집합 Sα, Sβ를 만들어 그 모든 조합을 기저로 씁니다. N₂에서 비트열 50개를 뽑으면 α 문자열 17종, β 문자열 16종이 나오고, 기저는 17 × 16 = 272개가 됩니다. 샘플에 없던 조합 222개가 공짜로 들어옵니다.

옵션효과
carryover (이월)직전 반복에서 진폭이 컸던 문자열을 다음 배치에 무조건 포함. 좋은 배치가 추첨에서 빠져도 유지
symmetrize_spinSα = Sβ로 통일. α↔β 대칭을 보장하고 공간이 커짐
max_dim각 스핀 문자열 수 상한. 메모리 제한용

8. 대각화와 수렴

배치마다 PySCF의 selected-CI 커널이 272차원 행렬을 대각화해 에너지, 고유벡터, 점유도를 돌려줍니다. 배치 3개 중 에너지가 가장 낮은 것을 그 반복의 결과로 삼고, 그 점유도를 다음 반복의 복구에 씁니다.

멈추는 조건은 둘을 동시에 요구합니다. 직전 반복과의 에너지 차이가 energy_tol 이하이고, 점유도 변화의 최대값이 occupancies_tol 이하. 반환값은 마지막 결과가 아니라 지금까지 중 에너지가 가장 낮은 결과입니다.

9. Standard vs Trim: 배치를 어떻게 돌릴까

"배치를 몇 개 만들고, 각각 어떻게 풀고, 무엇을 보고할지"를 정하는 것이 policy입니다. 기본 StandardPolicy는 배치를 독립적으로 뽑아 각각 풀고 최선을 고릅니다. TrimPolicy는 배치들을 서로 겹치지 않게 나눠 풀고, 각 배치에서 살아남은 문자열을 모아 한 번 더 풉니다.

10. 코드와 결과 객체

from qiskit_addon_sqd.fermion import diagonalize_fermionic_hamiltonian

result = diagonalize_fermionic_hamiltonian(
    hcore, eri,                 # 문서 1
    bit_array,                  # 문서 5
    samples_per_batch=50,       # 7절: 배치당 비트열 수 → 부분공간 크기
    norb=8, nelec=(5, 5),
    num_batches=3,              # 9절: 반복당 대각화 수
    max_iterations=8,           # 4절: 복구 반복 상한
    energy_tol=1e-8, occupancies_tol=1e-5,   # 8절
    callback=lambda rs: print([r.energy for r in rs]),   # 반복마다 배치 결과
    seed=1,
)
print(result.energy + ecore)             # -109.03296 (CASCI -109.03441)
occ_a, occ_b = result.orbital_occupancies   # 6절의 점유도
result.sci_state.amplitudes.shape        # (26, 28) = |S_α| × |S_β|

결과 객체 SCIResult는 에너지, 점유도, 그리고 SCIState(고유벡터와 문자열 집합)를 담습니다. 고유벡터의 모양이 |Sα| × |Sβ| 행렬이라는 것이 7절의 데카르트 곱 구조를 그대로 반영합니다. 점유도는 이 행렬의 제곱을 행·열 방향으로 더해 얻습니다.

함수 본체를 줄이면 아래와 같습니다. 실제 변수명 그대로입니다.

raw_bitstrings, raw_probs = bit_array_to_arrays(bit_array)           # 원본, 루프 내내 불변
for iteration in range(max_iterations):
    bitstrings, probs = _recover_or_postselect(config, current_occupancies)   # 5·6절
    ci_strings = policy.prepare_subspaces(request)                   # 7절, 배치별 (S_α, S_β)
    results = sci_solver(ci_strings, hcore, eri, norb, nelec)         # 8절, PySCF
    state = _process_sci_results(...)                                 # 최선 갱신, 수렴 판정
    if state.converged: break
    current_occupancies = state.current_occupancies                   # 다음 반복의 복구에
return best_result

다중 프로세스(MPI)에서는 sci_solver 호출만 모든 프로세스가 참여하고, 나머지는 rank 0이 혼자 하고 broadcast로 나눕니다. mpi4py가 없으면 같은 코드가 단일 프로세스로 돌아갑니다.

마무리: 이 문서에서 가져갈 것

  • SQD = 양자 샘플로 후보 목록 → 고전 대각화 → 점유도로 샘플 교정 → 반복.
  • 후선별은 "확실히 틀린" 비트열을 버리고(N₂: 643 → 107종류), 구성 복구는 점유도로 그것들을 되살린다(→ 176종류).
  • 부분공간은 뽑힌 비트열이 아니라 α 문자열 × β 문자열의 모든 조합(50개 → 272차원).
  • 반복마다 부분공간이 커지고 에너지가 내려간다. N₂: 4.0 → 1.4 mHa, 3,136개 중 728개로.
  • policy는 배치 일정만 바꾸고, 루프 구조는 같다.
