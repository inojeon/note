학습 지도 · 양자화학에서 양자컴퓨터로

큐빗·회로·측정

상태를 표현하고, 바꾸고, 읽는 방법을
하나씩 연결합니다.

무엇을 연결하는 지도일까요?

양자화학은 전자의 상태와 에너지를 다룹니다. 양자컴퓨터에서는 그 문제를 으로 표현하고, 회로로 상태를 준비한 뒤 측정합니다. 이 지도는 전자 상태를 배운 뒤 VQE의 회로를 이해하기까지 필요한 개념을 연결합니다.

먼저 세 가지 역할을 구별하세요

현재 어떤 상태로 준비되었는지 나타내는 숫자들입니다.
준비된 상태를 다른 상태로 바꾸는 연산입니다.
에너지 측정의 가능한 값과 확률을 계산하는 데 쓰는 연산자입니다.

VQE의 상태 준비 실험에서는 해밀토니안을 고정하고, 게이트로 시험 상태를 바꿉니다. 는 그 상태의 표현이며 회전을 수행하는 연산자가 아닙니다.

이미 배운 내용: 양자 상태와 파동함수 · 확률 진폭·정규화 · 중첩과 상대 위상

01 · 상태를 표현하기

  • 두 상태 계(Two-Level System)여러 상태 중 두 상태만 다룬다는 것은 무슨 뜻일까?
  • 큐빗(Qubit)기준 상태는 둘인데 가능한 상태는 왜 더 많을까?
  • 계산 기저(Computational Basis)왜 0 상태는 계수가 모두 0인 벡터가 아닐까?

02 · 상태를 바꾸기

  • 양자 게이트(Quantum Gate)상태를 바꾸는 행렬은 어떤 조건을 만족할까?
  • 회전 게이트(Rotation Gate)와 블로흐 구(Bloch Sphere)무엇을 회전하며 각도는 계수와 어떻게 연결될까?

03 · 결과를 읽기

  • 측정 기저(Measurement Basis)상태가 같아도 측정 기준에 따라 결과가 달라질까?
  • 계산 기저 측정과 에너지 측정0·1을 읽는 것과 에너지를 읽는 것은 어떻게 다를까?

04 · 여러 큐빗과 화학으로 이어가기

  • 여러 큐빗과 텐서곱(Tensor Product)큐빗 두 개는 왜 네 개의 기저 상태를 가질까?
  • 얽힘(Entanglement)전체 상태를 각 큐빗의 상태로 나눌 수 없다는 뜻은?
  • 전자 상태와 큐빗의 대응(Encoding)큐빗의 0·1은 전자의 무엇을 나타낼까?

VQE로 돌아가기

한 큐빗 예제는 01~03을 읽은 뒤 평균 에너지와 기댓값에서 확인하세요. 시작 상태 → → 준비된 상태 → 고정된 H로 에너지 계산 순서가 이어집니다.

분자 문제는 04의 여러 큐빗과 표현까지 읽은 뒤 VQE 학습 지도와 수소 분자 계산로 연결하세요.

해밀토니안도 상태를 변화시키지 않나요?

맞습니다. 해밀토니안은 에너지 연산자이면서 슈뢰딩거 방정식을 통해 시간 변화도 결정합니다. 여기서 고정한다고 말하는 것은 VQE가 푸는 에너지 문제를 바꾸지 않는다는 뜻입니다. 회로의 조절값을 바꾸어 준비하는 시험 상태는 달라집니다.

큐빗(Qubit)두 개의 직교 기저 상태로 표현하는 양자 정보의 단위입니다. 가능한 상태가 0과 1 두 개뿐인 것이 아니라 그 중첩도 포함합니다.간단한 예시0과 1을 같은 확률로 측정하는 순수상태의 예는 (|0⟩+|1⟩)/√2입니다.α|0⟩ + β|1⟩; |α|² + |β|² = 1α|0⟩ + β|1⟩; |α|² + |β|² = 1관련 개념 읽기 →상태 벡터(State Vector)순수 양자 상태를 선택한 정규직교 기저에서 확률 진폭의 열벡터로 나타낸 표현입니다. 물리적 예측을 위해 정규화하며 전역 위상은 같은 물리적 상태를 나타냅니다.간단한 예시계산 기저에서 0 상태는 첫째 진폭 1, 둘째 진폭 0으로 나타냅니다.|0⟩ = 10상태 이름 0은 영벡터를 뜻하지 않습니다.관련 개념 읽기 →양자 게이트(Quantum Gate)이상적인 닫힌 양자계에서 상태에 유니터리 변환을 적용하는 회로의 연산입니다. 측정은 일반적으로 이 가역 변환과 다릅니다.간단한 예시X 게이트는 0과 1의 상태를 서로 바꿉니다.X|0⟩ = |1⟩; X|1⟩ = |0⟩X|0⟩ = |1⟩; X|1⟩ = |0⟩관련 개념 읽기 →해밀토니안(Hamiltonian)양자계의 에너지를 나타내는 연산자입니다. 이 노트의 유한차원 정규직교 기저에서는 에르미트 행렬로 표현합니다.간단한 예시두 에너지 준위만 갖는 단순한 모형입니다. 둘째 기저 상태의 에너지 고유값은 2입니다. 여기서 숫자는 선택한 에너지 단위로 읽습니다.H = 0002, H01 = 201Hc = Ec에서 E는 에너지 고유값입니다.관련 개념 읽기 →파동함수(Wavefunction)양자 상태를 위치 등의 좌표로 나타내는 일반적으로 복소수인 함수입니다. 전자 하나의 공간 파동함수는 ψ(r) = ⟨r|ψ⟩로, 여러 전자에서는 스핀을 포함한 모든 전자 좌표를 받는 Ψ(x₁,…,xN)으로 표현합니다.간단한 예시정규화된 1차원 모형에서 0부터 L까지 ψ(x)=1/√L이고 밖에서 0이면, 구간 앞 절반에서 찾을 확률은 1/2입니다.∫₀^(L/2) |ψ(x)|² dx = (L/2)/L = 1/2파동함수는 전자의 이동 궤적이 아닙니다.관련 개념 읽기 →회전 게이트(Rotation Gate)큐빗 상태를 블로흐 구의 지정한 축 주위로 회전시키는 유니터리 게이트입니다. 전자가 실제 공간에서 도는 궤적을 뜻하지 않습니다.간단한 예시Ry의 각도 90°를 0 상태에 적용하면 두 성분이 모두 1/√2인 상태가 됩니다.Ry(θ)|0⟩의 계수는 cos(θ/2), sin(θ/2)입니다.Ry(θ)|0⟩의 계수는 cos(θ/2), sin(θ/2)입니다.관련 개념 읽기 →전자 배치(Electronic Configuration)선택한 일전자 궤도들에 전자가 어떻게 점유되어 있는지를 지정한 것입니다. 공간 궤도 점유와 스핀 궤도 점유를 구별해서 읽어야 합니다.간단한 예시두 공간 궤도에 하나씩 있는 a¹b¹은 aα·bα, aα·bβ, aβ·bα, aβ·bβ의 네 스핀 궤도 점유를 허용합니다.공간 배치 a¹b¹ → 스핀 점유 2×2=4개; a² → aα·aβ 한 가지공간 배치 a¹b¹만으로 두 전자의 스핀 점유나 전체 상태가 유일하게 정해지지는 않습니다.관련 개념 읽기 →
