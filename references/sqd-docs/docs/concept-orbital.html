오비탈(Orbital)

오비탈은 전자가 도는 길일까?

먼저 알면 좋은 개념: 양자 상태와 파동함수 · 보른 규칙

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

은 전자 하나의 상태를 표현하는 입니다. 공간 에 대한 과, 공간·스핀 좌표를 함께 받는 을 구별합니다. 공간 오비탈의 절댓값 제곱은 그 한 전자 상태의 위치 를 줍니다.

쉽게 풀어 보면

오비탈 그림은 전자의 궤적이 아닙니다. 같은 상태를 준비해 위치를 반복 측정할 때, 어디에서 결과를 얻기 쉬운지를 나타냅니다. 흔히 보는 입체 표면은 특정 밀도값의 등위면이거나 일정 확률을 포함하도록 고른 경계입니다. 전자가 그 표면 위에만 있다는 뜻은 아닙니다.

원자 중심의 함수는 , 분자 전체에 걸친 함수는 분자 오비탈(Molecular Orbital)이라고 부릅니다. 여러 전자의 정확한 상태 전체를 오비탈 하나와 같다고 볼 수는 없습니다.

실험 · 파동함수와 밀도는 어떻게 다를까?

길이 L인 1 의 설명용 입니다. 원자 오비탈의 모양을 계산한 그림이 아닙니다. 가로축은 위치를 L로 나눈 값입니다.

계산 확인 · 파동함수, 제곱, 적분

우물 안에서 된 공간 함수는 φₙ(x) = √(2/L) sin(nπx/L), 0 < x < L이고, 밖에서는 0입니다. 경계에서도 함수는 0입니다.

그림에는 √L φₙ(x)와 L|φₙ(x)|²를 표시했습니다. u = x/L, b = a/L라 두면

P(0≤x≤a) = ∫₀ᵃ|φₙ(x)|² dx
= b − sin(2nπb)/(2nπ)입니다. 전체 영역에서 적분하면 1입니다. 확률 밀도는 한 점의 확률이 아니며, 여기서는 길이의 역수 단위를 갖습니다.

적용 조건 · 마디와 여러 전자

마디(Node)는 파동함수가 0인 곳입니다. 위 실험의 내부 마디는 상태 번호보다 하나 적습니다. 이 규칙은 이 1차원 모형에 대한 것이며, 모든 오비탈에 같은 방식으로 적용되지 않습니다.

다전자 계산에서는 여러 스핀 오비탈로 반대칭 다전자 파동함수를 만듭니다. 공간 오비탈 하나의 밀도와 분자 전체의 는 구별해야 합니다. 한 공간 오비탈에 반대 스핀 전자 둘을 넣는 것은 파울리 배타 원리와 양립합니다.

오비탈(Orbital)전자 하나의 상태를 나타내는 파동함수입니다. 공간 좌표만의 공간 오비탈과 공간·스핀을 함께 받는 스핀 오비탈을 구별합니다.간단한 예시길이 L의 1차원 우물의 첫 상태에서 전체 구간의 위치 확률은 1이고, 왼쪽 절반에서 찾을 확률은 1/2입니다.전체 영역: 100%; 왼쪽 절반: 50%오비탈은 전자의 이동 궤적이 아닙니다.파동함수(Wavefunction)양자 상태를 위치 등의 좌표로 나타내는 일반적으로 복소수인 함수입니다. 전자 하나의 공간 파동함수는 ψ(r) = ⟨r|ψ⟩로, 여러 전자에서는 스핀을 포함한 모든 전자 좌표를 받는 Ψ(x₁,…,xN)으로 표현합니다.간단한 예시정규화된 1차원 모형에서 0부터 L까지 ψ(x)=1/√L이고 밖에서 0이면, 구간 앞 절반에서 찾을 확률은 1/2입니다.∫₀^(L/2) |ψ(x)|² dx = (L/2)/L = 1/2파동함수는 전자의 이동 궤적이 아닙니다.관련 개념 읽기 →좌표(Coordinates)선택한 기저에 대해 벡터를 표현하는 계수들입니다.간단한 예시b₁, b₂를 아래처럼 고르면, 같은 벡터의 이 기저에 대한 좌표는 3과 1입니다.b₁ = 11, b₂ = 01; v = 34 = 3b₁+b₂ → 새 좌표 31v = c₁b₁ + c₂b₂이면 좌표 성분은 c₁, c₂입니다.관련 개념 읽기 →공간 오비탈(Spatial Orbital)전자 위치의 함수인 일전자 궤도입니다. 스핀 함수까지 곱한 스핀 궤도와 구별합니다.간단한 예시aα와 aβ는 공간 모양이 같아도 스핀 부분이 직교하므로 두 전자가 하나씩 점유할 수 있습니다.a(r)α(s), a(r)β(s): 같은 공간 궤도, 다른 스핀 궤도같은 공간 궤도 a에 α와 β 스핀을 각각 곱하면 서로 다른 두 스핀 궤도입니다.관련 개념 읽기 →스핀 오비탈(Spin Orbital)전자 하나의 공간 좌표와 스핀 좌표를 함께 받는 파동함수입니다. 공간 함수와 스핀 함수의 곱으로 쓰는 경우가 흔합니다.간단한 예시φα가 이미 한 전자로 점유되어 있다면 같은 φα에 두 번째 전자를 추가할 수 없습니다. φβ는 다른 스핀 오비탈입니다.n(φα) = 0 또는 1; n(φβ) = 0 또는 1같은 스핀 오비탈에는 전자를 최대 하나만 넣을 수 있습니다.확률 밀도(Probability Density)연속 변수의 영역 확률을 적분으로 계산할 때 사용하는 밀도입니다. 위치 표현에서는 정규화된 공간 파동함수의 |ψ(r)|²가 위치 확률 밀도입니다.간단한 예시1차원 구간 0부터 L까지 밀도가 1/L로 일정하면, 길이 L/2인 부분 구간의 확률은 1/2입니다.∫₀^(L/2) (1/L) dx = 1/2밀도 자체는 한 점에서의 확률이 아닙니다.관련 개념 읽기 →원자 오비탈(Atomic Orbital)원자 중심의 전자 한 개 공간 함수를 뜻합니다. 수소형 원자의 정확한 고유함수이거나, 다전자 원자의 유효 한 전자 함수 등 맥락에 따라 구체적 정의가 달라집니다.간단한 예시수소형 원자에서 주양자수 n=1인 껍질에는 1s 공간 오비탈이 하나 있습니다. 서로 다른 두 스핀 함수를 붙일 수 있습니다.1s 공간 함수 1개 × 스핀 함수 2개 = 스핀 오비탈 2개분자 오비탈은 여러 원자 중심 함수를 조합하여 나타낼 수 있습니다.차원(Dimension)유한차원 벡터 공간에서 기저를 이루는 벡터의 개수입니다.간단한 예시평면 전체에는 두 기준 방향이 필요하지만, x축 위의 벡터들은 한 기준 방향만 있으면 됩니다.평면의 기저: 10, 01 → 2차원;
