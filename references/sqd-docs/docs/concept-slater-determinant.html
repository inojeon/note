슬레이터 행렬식(Slater Determinant)

전자 둘의 이름을 바꾸면 왜 부호가 바뀔까?

먼저 알면 좋아요 · 전자 배치(Electronic Configuration) · 파울리 배타 원리(Pauli Exclusion Principle)

01 · 정의와 핵심

은 일전자 들을 으로 조합한 반대칭 다전자 입니다. N개의 스핀 궤도를 사용하면 인자는 1 나누기 루트 N 팩토리얼입니다. 전자 두 개의 를 교환하면 부호가 바뀌며, 같은 스핀 궤도를 두 번 넣으면 0이 됩니다.

쉽게 풀어 보면

전자 1에 궤도 a, 전자 2에 궤도 b를 따로 배정한 곱만으로는 전자의 구별 불가능성과 반대칭 조건을 만족하지 못합니다. 두 배정을 빼서 결합하면 전자 이름을 바꿀 때 전체 부호가 뒤집힙니다. 전체 부호가 바뀌어도 확률은 같습니다.

Ψ(x₁,x₂) = [χa(x₁)χb(x₂) − χb(x₁)χa(x₂)]/√2

x는 위치와 스핀을 함께 포함한 일전자 좌표입니다. 같은 공간 궤도에 반대 스핀의 전자가 있는 것은 서로 다른 스핀 궤도이므로 허용됩니다.

02 · 예시와 실험

이렇게 살펴보세요좌표 이름을 맞바꿀 때 진폭의 부호와 확률을 비교하세요.

실험: 좌표 이름을 바꾸면 진폭과 확률은?

설명용 이산 모형입니다. 같은 스핀 을 고정한 두 이산 위치 상태 L, R만 사용합니다. 반대 스핀까지 허용하면 일전자 공간도 더 커집니다. 정규직교 일전자 함수는 각각 L, R에서 다음 의 값을 가집니다: χa는 열벡터 0.8, 0.6; χb는 열벡터 −0.6, 0.8. 숫자는 L, R에서의 함수 값이며 원자 위치나 실제 값이 아닙니다.

03 · 기억할 점

스스로 확인하기 · 두 전자의 좌표를 교환하면 확률도 달라질까요?

전체 파동함수의 부호는 바뀌지만 절댓값 제곱은 같으므로 같은 좌표 교환에 대한 확률은 같습니다.

계산 확인: 교환 부호, 정규화, 중복 열

행렬식의 행은 전자 좌표, 열은 스핀 궤도입니다. 좌표 교환은 두 행을 바꾸므로 행렬식에 −1을 곱합니다. 궤도 순서를 바꾸는 열 교환도 전체 부호를 바꿉니다.

처음 모형에서는 LR의 진폭이 (0.8×0.8 − (−0.6)×0.6)/√2 = 1/√2이며 RL은 반대 부호입니다. LL과 RR은 0이므로 확률 합은 1/2 + 1/2 = 1입니다.

같은 궤도를 두 번 넣으면 두 열이 같아 모든 좌표에서 행렬식이 0입니다. 이는 정규화할 수 없는 영함수이며 두 전자가 같은 스핀 궤도를 점유하는 상태를 만들 수 없다는 뜻입니다.

적용 조건: 한 행렬식으로 충분한가?

1/√N!은 사용한 스핀 궤도들이 정규직교할 때의 정규화입니다. 선형독립이지만 인 궤도에서는 겹침에 따른 별도 정규화가 필요합니다. 중복된 궤도는 어떤 상수를 곱해도 정상적인 상태가 되지 않습니다.

하나의 행렬식은 전자의 반대칭 조건을 보장하지만 모든 을 표현하지는 못합니다. 일반적인 다전자 상태에는 여러 행렬식의 이 필요할 수 있습니다. 교환부호 실험은 전자를 실제로 움직이는 경로가 아니라 함수의 입력 이름을 교환하는 계산입니다.
