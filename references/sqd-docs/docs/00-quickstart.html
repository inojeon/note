SQD 퀵스타트 따라가기
공식 Quickstart를 한 줄씩 풀어 읽기

qiskit-addon-sqd 공식 문서의 Quickstart 노트북을 뼈대로 삼아, 각 셀이 무엇을 하는지와 왜 그런 결과가 나오는지를 설명합니다. 코드는 노트북 그대로이고, 숫자는 이 세션에서 다시 실행해 얻은 값입니다(패키지 버전에 따라 반복 횟수가 노트북과 한두 번 다를 수 있습니다). 각 단계 끝에 더 깊이 볼 문서를 연결해 두었습니다.

Quickstart의 요점은 하나입니다. 양자컴퓨터 없이 완전히 무작위인 비트열을 넣어도 SQD는 정확한 바닥상태에 도달한다. 이 예제가 작아서 가능한 일이지만, 알고리즘의 각 부품이 무엇을 하는지 보기에는 가장 좋은 예제입니다.

한눈에 보기

1. 입력 준비

N₂를 STO-3G 기저로 만들고, 내각 궤도 2개를 얼린 활성 공간 8궤도·10전자를 잡습니다. 문서 1과 같은 절차인데 기저만 작습니다(STO-3G는 N 원자당 함수 5개, 전체 10개).

from pyscf import ao2mo, gto, mcscf, scf

mol = gto.M(atom="N 0 0 0; N 0 0 1.09768", basis="sto-3g", spin=0, charge=0, verbose=0)
mf = scf.RHF(mol).run()
cas = mcscf.CASCI(mf, ncas=8, nelecas=10)        # 활성 궤도 8, 활성 전자 10 → PySCF가 (5,5)로 나눔
hcore, nuclear_repulsion_energy = cas.get_h1eff()   # (8,8) 와 상수 (내각 + 핵 반발)
eri = ao2mo.restore(1, cas.get_h2eff(), cas.ncas)    # (8,8,8,8)
nelec = cas.nelecas                                 # (5, 5)
# Spatial orbitals: 8 / Qubits: 16 / Electrons (alpha, beta): (5, 5)

변수 이름이 nuclear_repulsion_energy지만 실제 값은 핵 반발 에너지 + 얼린 내각 전자의 에너지입니다(문서 1의 ecore와 같은 것). SQD가 돌려주는 에너지에 이 상수를 더해야 전체 에너지가 됩니다. 노트북의 모든 출력이 result.energy + nuclear_repulsion_energy인 이유입니다.

2. 잡음 샘플 만들기

실제 워크플로에서는 회로를 설계하고 QPU에서 샘플링합니다. Quickstart는 그 자리를 균일 난수 비트열 10,000개로 채웁니다. 바닥상태에 대한 정보가 전혀 없는 최악의 입력입니다.

import numpy as np
from qiskit_addon_sqd.counts import generate_bit_array_uniform

rng = np.random.default_rng(24)
bit_array = generate_bit_array_uniform(10_000, num_orbitals * 2, rand_seed=rng)

난수 샘플의 특이한 점이 하나 있습니다. 유효 비트열이 458종류로 많습니다. 좋은 회로에서는 중요한 배치 몇십 개가 반복해서 나오지만, 난수는 3,136개 전체에 얇게 퍼집니다. 이것이 3절에서 부분공간이 전체 공간까지 자라는 이유입니다.

3. SQD로 후처리

이제 핵심입니다. 난수 비트열을 넣고 반복마다 "전자 수 맞추기 → 작은 공간에서 대각화 → 점유도로 비트열 교정"을 돌립니다.

from functools import partial
from pyscf import fci
from qiskit_addon_sqd.fermion import SCIResult, diagonalize_fermionic_hamiltonian, solve_sci_batch

# 비교용 정답: 활성 공간 FCI
exact_energy, _ = fci.direct_spin1.kernel(hcore, eri, num_orbitals, nelec)
exact_energy += nuclear_repulsion_energy          # -107.652521 Ha

sci_solver = partial(solve_sci_batch, spin_sq=0.0, max_cycle=200)

result_history = []
def callback(results: list[SCIResult]):
    result_history.append(results)
    for i, result in enumerate(results):
        print(result.energy + nuclear_repulsion_energy,
              np.prod(result.sci_state.amplitudes.shape))   # 에너지, 부분공간 차원

result = diagonalize_fermionic_hamiltonian(
    hcore, eri, bit_array,
    samples_per_batch=20,
    norb=num_orbitals, nelec=nelec,
    occupancies_tol=1e-7,
    max_iterations=30,
    sci_solver=sci_solver,
    symmetrize_spin=True,
    callback=callback,
    seed=np.random.default_rng(32),
)

세 번째 반복의 급락이 알고리즘의 심장입니다. 처음 두 번은 난수에서 걸러진 비트열로 만든 공간이라 HF 배치(바닥상태의 92%)가 들어 있지 않습니다. 그래도 그 공간의 최저 에너지 상태는 "낮은 궤도가 차 있는 쪽"으로 기울어 있어서, 점유도가 궤도 0~4는 높고 5~7은 낮게 나옵니다. 그 점유도로 난수 비트열을 교정하면 HF 배치와 그 주변이 만들어지고, 그것이 공간에 들어오는 순간 오차가 30배 줄어듭니다.

4. 옵션 하나씩

Quickstart의 호출에는 문서 6에서 다루지 않은 인자가 몇 개 있습니다.

인자값뜻
sci_solverpartial(solve_sci_batch, spin_sq=0.0, max_cycle=200)대각화 함수를 바꿔 끼우는 자리. 기본 solver에 "총 스핀 S² = 0(싱글릿)으로 제한"과 "반복 상한 200"을 미리 넣어 둔 것. 싱글릿 제한이 없으면 같은 공간에서 트리플릿 상태가 더 낮게 나올 수 있어 엉뚱한 답을 고를 위험이 있음
symmetrize_spinTrueSα와 Sβ를 합집합으로 통일. 닫힌 껍질 분자는 α↔β 대칭이라 이렇게 해야 공간이 대칭이 되고 수렴이 빠름. 이 예제에서 끄면 수렴에 13번 걸리고 1 mHa 오차가 남음
samples_per_batch20배치당 비트열 수. 20이면 8번, 100이면 3번 만에 수렴. 작게 잡은 것은 반복 과정을 보여 주기 위해서
occupancies_tol1e-7점유도 변화가 이보다 작아야 수렴. 매우 엄격하게 잡아 전체 공간에 닿을 때까지 돌림
max_iterations30상한. 실제로는 8번에 멈춤
num_batches(기본값 1)튜토리얼은 3. 여기서는 배치 하나라 출력에 Subsample 0만 보임
seeddefault_rng(32)부분추출과 복구의 난수. 샘플 생성(24)과 별도

5. 이 예제가 보여 주는 것과 보여 주지 않는 것

보여 주는 것. 구성 복구가 얼마나 강한지. 바닥상태 정보가 0인 입력에서 출발해도, 대각화 → 점유도 → 교정의 피드백만으로 정확한 답에 도달합니다. 각 단계(후선별, 복구, 부분추출, 대각화, 수렴)가 코드에서 어떻게 호출되는지도 가장 짧은 형태로 보입니다.

보여 주지 않는 것. 이것이 되는 이유는 전체 공간이 3,136차원이라 고전 컴퓨터가 통째로 다룰 수 있기 때문입니다. 부분공간이 자라서 전체 공간이 되면 당연히 정답입니다. 궤도 36개·전자 36개면 전체는 10¹⁸이라 이런 식으로는 닿을 수 없고, 그때는 양자 회로가 "중요한 배치"를 처음부터 집어 줘야 합니다. 즉 Quickstart는 후처리의 작동 원리를 보여 주는 것이지, 양자컴퓨터가 필요한 이유를 보여 주는 것이 아닙니다. 그 이유는 문서 4·5·6에 있습니다.

전체 코드

from functools import partial
import numpy as np
from pyscf import ao2mo, gto, mcscf, scf, fci
from qiskit_addon_sqd.counts import generate_bit_array_uniform
from qiskit_addon_sqd.fermion import SCIResult, diagonalize_fermionic_hamiltonian, solve_sci_batch

# 1. 입력
mol = gto.M(atom="N 0 0 0; N 0 0 1.09768", basis="sto-3g", spin=0, charge=0, verbose=0)
mf = scf.RHF(mol).run()
cas = mcscf.CASCI(mf, ncas=8, nelecas=10)
hcore, nuclear_repulsion_energy = cas.get_h1eff()
num_orbitals = cas.ncas
eri = ao2mo.restore(1, cas.get_h2eff(), num_orbitals)
nelec = cas.nelecas

# 2. 잡음 샘플 (균일 난수)
rng = np.random.default_rng(24)
bit_array = generate_bit_array_uniform(10_000, num_orbitals * 2, rand_seed=rng)

# 3. SQD
exact_energy, _ = fci.direct_spin1.kernel(hcore, eri, num_orbitals, nelec)
exact_energy += nuclear_repulsion_energy
sci_solver = partial(solve_sci_batch, spin_sq=0.0, max_cycle=200)
result_history = []

def callback(results: list[SCIResult]):
    result_history.append(results)
    for i, r in enumerate(results):
        e = r.energy + nuclear_repulsion_energy
        print(f"iter {len(result_history)}  E={e:.6f}  dim={np.prod(r.sci_state.amplitudes.shape)}  err={e - exact_energy:.6f}")

result = diagonalize_fermionic_hamiltonian(
    hcore, eri, bit_array, samples_per_batch=20, norb=num_orbitals, nelec=nelec,
    occupancies_tol=1e-7, max_iterations=30, sci_solver=sci_solver,
    symmetrize_spin=True, callback=callback, seed=np.random.default_rng(32),
)
print(result.energy + nuclear_repulsion_energy, exact_energy)   # -107.652521 -107.652521

다음 단계

Quickstart에서 난수로 대신한 2단계를 실제 양자 회로로 바꾸면 공식 튜토리얼이 됩니다. 그 튜토리얼은 STO-6G 시뮬레이터 예제와 cc-pVDZ 26궤도·52큐비트 실기기 예제로 되어 있고, 이 문서 모음의 1 → 6이 그 흐름을 따라갑니다.

Quickstart 단계튜토리얼에서는이 문서 모음에서는
1. 입력 준비같음 (STO-6G / cc-pVDZ)문서 1, 2
2. 잡음 샘플LUCJ 회로 → transpile → Sampler (시뮬레이터 또는 QPU)문서 3, 4, 5
3. SQD 후처리같음 + initial_occupancies, max_dim, carryover_threshold, 배치 3개문서 6
