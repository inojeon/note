대각화와 좌표축 바꾸기

같은 행렬을 다른 기저로 보면 무엇이 달라질까?

먼저 알면 좋아요 · 대각화(Diagonalization)

01 · 정의와 핵심

변환(Change of Basis)은 같은 와 을 다른 기준으로 표현하는 것입니다. 실수 의 열을 모은 Q에서는 새 이 B = QᵀAQ입니다. Q가 기저이면 B는 이 됩니다.

02 · 예시와 실험

이렇게 살펴보세요축을 0°에서 45°로 바꾸세요. 같은 변환의 비대각 원소가 어떻게 달라지는지 보세요.

축을 돌리면 사라지는 숫자

행렬 A는 그대로 두고 축만 돌려 보세요. 고유벡터 방향인 45°에서 새 행렬 B의 대각선 밖 이 0이 됩니다.

고정된 변환 A =2112파랑: 입력 v · 주황: 출력 Av

45°에서 입력 방향을 바꿔 보세요. 첫 좌표는 언제나 3배, 둘째 좌표는 1배가 됩니다. 는 벡터를 고유벡터로 만드는 일이 아니라, 변환을 고유벡터 기저에서 표현하는 일입니다.

03 · 기억할 점

스스로 확인하기 · 좌표축을 돌리면 변환 A가 다른 물리적 작용이 될까요?

이 실험은 같은 변환을 다른 기저로 표현합니다. B = QᵀAQ의 숫자가 달라도 원래 공간에서의 입력과 출력은 같습니다.

수식으로 확인하기

A = PDP⁻¹, D = P⁻¹AP.
이 실험은 직교행렬 Q = [[cos θ, −sin θ], [sin θ, cos θ]]를 사용합니다. Q의 열은 회전한 단위 기저입니다.
Q⁻¹ = Qᵀ, B = QᵀAQ. θ = 45°에서 B = D = diag(3, 1)이고 A = QDQᵀ입니다.
