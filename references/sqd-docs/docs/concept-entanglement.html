얽힘(Entanglement)

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

은 전체 상태를 부분계의 독립적인 상태들의 곱 또는 그러한 들의 확률적 혼합으로 표현할 수 없는 성질입니다. 특히 전체가 라면, 두 개의 개별 의 으로 나눌 수 없는 상태를 뜻합니다.

전체 상태는 알지만,
각 큐빗에 따로 순수상태를 지정할 수 없을 수 있습니다.

의 한 예는 00과 11의 같은 진폭 입니다. 에서 측정하면 둘 다 0이거나 둘 다 1입니다. 각 의 결과만 보면 반반이지만 둘의 결과는 연결되어 있습니다.

결과가 서로 맞는다는 사실만으로 얽힘을 확인할 수는 없습니다. 매번 동전을 던져 00 또는 11을 준비해도 같은 상관관계가 나옵니다. 를 바꿔 보면 이 두 준비 방법의 차이가 드러납니다.

+·−는 X 측정의 두 결과 이름이며, 각각 X의 +1·−1에 대응합니다. 00·01·10·11처럼 짝의 왼쪽은 A, 오른쪽은 B입니다.

왜 개별 순수상태로 나눌 수 없을까?

벨 상태 Φ⁺의 계산 기저 는 다음과 같습니다.

수식

곱 상태의 ac, ad, bc, bd로 이 를 만들려고 해봅시다. ac와 bd가 모두 0이 아니려면 a, b, c, d 모두 0이 아니어야 합니다. 그러면 ad와 bc를 0으로 만들 수 없습니다. 따라서 벨 상태는 두 개별 순수상태의 곱이 아닙니다.

개별 큐빗에는 여전히 상태가 있지만, 하나의 순수상태 벡터로 나타낼 수 없는 입니다. 전체 순수상태와 부분계의 상태를 구별해야 합니다.

확률적 혼합·측정·정보 전달

확률적 혼합 예제에서는 준비할 때마다 50% 확률로 00, 50% 확률로 11을 선택합니다. 한 개의 상태 벡터를 두 벡터의 평균으로 만드는 것이 아닙니다. 각 준비 상태에서 계산한 측정 확률을 평균합니다.

벨 상태는 Z/Z와 X/X 모두에서 결과가 서로 같습니다. 이 특정 혼합은 Z/Z에서만 같고 X/X에서는 네 결과가 같은 확률입니다. 이 실험은 알려진 이상적 상태들을 비교하며, 임의의 미지 상태에 대한 일반적인 얽힘 판정 절차를 대체하지는 않습니다.

벨 상태에서 한쪽만 본 결과는 무작위입니다. 상대가 선택한 측정 기준을 자신의 결과만으로 읽을 수 없으므로 얽힘으로 빛보다 빠르게 메시지를 보낼 수 없습니다.
