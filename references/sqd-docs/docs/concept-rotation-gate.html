회전 게이트(Rotation Gate)와 블로흐 구

회전각을 바꾸면 무엇이 달라질까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

는 각도를 로 받아 의 상태를 연속적으로 바꾸는 유니터리 게이트입니다. 한 큐빗에서는 의 축 주위 회전으로 표현할 수 있습니다.

돌아가는 것은 상태의 표현입니다

전자가 실제 공간에서 원을 그리며 도는 그림이 아닙니다. 블로흐 구는 한 큐빗의 를 점 하나로 표시하는 수학적 그림입니다. 위쪽 극은 0 상태, 아래쪽 극은 1 상태입니다.

여기서는 0 상태에 y축 회전 게이트 Ry를 적용합니다. 바꾸는 것은 상태를 준비하는 게이트의 각도입니다. 에너지 을 회전시키는 실험이 아닙니다.

왜 계수에는 절반의 각도가 들어갈까?

Ry의 정의에 따라 두 계수는 다음과 같습니다. 구에서의 회전각 θ와 실수 의 좌표 각도 θ/2는 서로 다릅니다.

a=\cos(\theta/2)

b=\sin(\theta/2)

90° 회전이면 두 계수는 각각 약 0.7071이고, 0·1 측정 확률은 각각 50%입니다. 계수 자체를 확률로 읽지 않습니다.

행렬과 블로흐 좌표로 확인하기
R_y(\theta)=\begin{pmatrix}\cos(\theta/2)&-\sin(\theta/2)\\\sin(\theta/2)&\cos(\theta/2)\end{pmatrix}

이 을 0 상태에 곱하면 첫째 열이 출력 상태가 됩니다. 이 실험의 블로흐 좌표는 다음과 같습니다.

(x,y,z)=(\sin\theta,0,\cos\theta)

화면 각도 단위는 도(°)이며, 내부 삼각함수 계산에서는 으로 변환합니다. 일반적인 상태를 만들려면 을 조절하는 다른 회전도 필요합니다.

360°와 720° · 왜 벡터 부호가 달라질까?

360°에서 출력은 −|0⟩입니다. 원래 와 전체 부호가 반대지만, 만 다르므로 같은 물리적 상태입니다. 블로흐 구의 점과 모든 측정 확률도 같습니다. 720°에서는 벡터의 부호까지 처음으로 돌아옵니다.

이것은 두 사이의 을 바꾸는 것과 다릅니다. 여기서는 큐빗 전체에 적용한 회전을 비교합니다.
