전자 적분(Electron Integrals)

오비탈로부터 에너지 계산에 필요한 숫자를 어떻게 만들까?

먼저 알면 좋아요 · 분자 오비탈(Molecular Orbital)

01 · 정의와 핵심

전자 적분(Electron Integrals)은 선택한 사이에서 에너지 연산자의 를 구한 값입니다. h_{pq}=\langle\phi_p|\hat h|\phi_q\rangle은 전자 하나의 운동과 핵 인력을, (pq|rs)은 두 전자의 쿨롱 반발을 나타냅니다. 여기서는 뒤에 정의한 화학자 표기(Chemist’s Notation)를 사용합니다.

쉽게 풀어 보면

적분은 공간 전체의 기여를 더하는 연산입니다. h_{pp}는 오비탈 p에 있는 전자 한 개의 운동·핵 인력 에너지 평균이고, (pp|rr)은 p와 r의 사이의 직접 반발 기여입니다. 이 값들은 확률이 아니라 에너지 단위의 수입니다.

서로 다른 오비탈을 연결하는 h_{pq}와 (pq|rs)도 필요합니다. 비대각 적분에는 오비탈의 부호·이 들어가므로, 모든 적분이 양수일 필요는 없습니다. 적분만으로 다전자 상태가 정해지지는 않으며, 어떤 오비탈을 점유하고 어떻게 하는지도 필요합니다.

02 · 예시와 실험

이렇게 살펴보세요오비탈 혼합 각도를 바꾸며 운동·핵 인력·전자 반발의 기여를 따로 보세요.

실험: 같은 오비탈의 1전자 에너지와 두 전자의 반발

실제 원자 대신 설명용 이산 두 지점 모형을 사용합니다. A, B는 고정된 지점 입니다. \phi=\cos\theta\,A+\sin\theta\,B를 α·β 전자 한 개씩이 함께 점유합니다. 숫자는 모두 같은 임의 에너지 단위입니다.

03 · 기억할 점

스스로 확인하기 · 1전자 적분만 있으면 전자 둘의 에너지를 모두 알 수 있을까요?

일반적으로 전자 사이 반발을 나타내는 2전자 적분도 필요합니다. 핵 반발을 포함할지와 다전자 상태도 정해야 합니다.

조건과 수식

화학자 표기에서 각 첨자는 어디에 들어갈까?

고정된 핵 위치, 비상대론적 전자 과 원자 단위를 가정합니다. 오비탈은 공간오비탈이며 별표는 입니다.

h_{pq}=\int\phi_p^*(\mathbf r)\hat h\phi_q(\mathbf r)\,d\mathbf r
\hat h=-\frac12\nabla^2-\sum_A\frac{Z_A}{|\mathbf r-\mathbf R_A|}
\rho_{pq}(\mathbf r)=\phi_p^*(\mathbf r)\phi_q(\mathbf r)
\begin{aligned}(pq|rs)&=\iint\frac{\rho_{pq}(\mathbf r_1)\rho_{rs}(\mathbf r_2)}{r_{12}}\\&\quad d\mathbf r_1d\mathbf r_2\end{aligned}

p,q는 첫째 전자 에, r,s는 둘째 전자 좌표에 붙습니다. 원자핵 사이의 반발 에너지는 이 전자 적분들에 포함하지 않고 별도로 더합니다. 물리학자 표기는 첨자를 묶는 순서가 다를 수 있으므로, 이름보다 적분의 정의를 확인해야 합니다.

이산 모형의 숫자는 어떻게 계산할까?

계수 를 c, 지점 밀도를 d_i=|c_i|^2로 놓습니다. 실험에서는 h=c^T(T+V)c, J=d^TGd를 계산합니다. G의 대각 원소는 유한한 지점 내 반발을 나타내는 모형 값입니다. 실제 쿨롱 핵의 특이점을 두 점에 직접 대입한 값이 아닙니다.

두 전자를 구별 가능한 고전 입자로 바꾼 것은 아닙니다. 이 경우의 반대 스핀 점유를 반대칭화한 단일 에서 얻는 에너지와 같은 형태를 사용합니다. 같은 스핀 전자는 같은 공간오비탈을 동시에 점유할 수 없습니다.
