큐빗(Qubit)

기준 상태는 둘인데 가능한 상태는 왜 더 많을까?

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

은 두 개의 상태로 표현하는 양자 정보의 단위입니다. 기준 상태를 0과 1이라고 부르며, 그 둘의 도 가능합니다.

0과 1은 상태에 붙인 이름입니다. 가능한 상태가 두 개뿐이라는 뜻이 아닙니다. 원자에서는 두 에너지 상태를 골라 큐빗으로 사용할 수 있지만, 큐빗이 항상 전자 하나를 뜻하는 것은 아닙니다.

실험 · 기준 상태 둘, 준비할 상태는 여러 개

같은 상태를 매번 새로 준비하고 0·1을 구분하는 측정을 반복한다고 생각해 보세요.

0으로 측정될 확률
1로 측정될 확률

확률 막대는 이론값입니다. 실제 유한 횟수의 측정 비율은 흔들릴 수 있습니다.

확률이 같으면 같은 상태일까?

+와 −와 +i 상태는 모두 0·1 확률이 반반이지만, 두 사이의 이 다릅니다. 다른 측정 기준을 사용하면 구별할 수 있습니다. +i의 i는 제곱하면 −1이 되는 허수 단위입니다.

여기서는 를 다룹니다. 일반적인 한 큐빗 순수상태는 다음처럼 나타냅니다.

|\psi\rangle=\alpha|0\rangle+\beta|1\rangle

|\alpha|^2+|\beta|^2=1

α와 β는 입니다. 전체에 같은 을 곱한 표현은 물리적으로 같은 순수상태입니다.
