해밀토니안 행렬원소(Hamiltonian Matrix Elements)

오비탈 적분은 어떻게 전자 배치 사이의 행렬이 될까?

먼저 알면 좋아요 · 전자 적분(Electron Integrals)

01 · 정의와 핵심

다전자 는 선택한 다전자 상태 사이에서 H_{IJ}=\langle D_I|\hat H|D_J\rangle로 정의한 수입니다. 로 만든 기저에서는, 1전자·을 에 따라 조립해 구합니다.

쉽게 풀어 보면

전자 적분의 첨자는 을 가리키지만, H_{IJ}의 행·열은 여러 전자가 점유한 하나의 을 가리킵니다. 둘의 크기와 의미는 다릅니다. 은 그 배치의 에너지 평균이고, 비대각 은 서로 다른 배치를 연결합니다.

보통의 전자 에는 한 번에 전자 하나에 작용하는 항과 두 전자에 작용하는 항이 있습니다. 따라서 정규직교 오비탈 점유를 세 개 이상 바꿔야 연결되는 행렬식 사이는 직접 가 0입니다. 단일·이중 치환은 연결될 수 있지만, 대칭이나 적분값 때문에 역시 0일 수 있습니다.

02 · 예시와 실험

이렇게 살펴보세요치환 수를 0부터 3까지 바꾸며 1전자 항과 2전자 항을 따로 확인하세요.

실험: 점유를 몇 개 바꾸면 직접 연결이 끊길까?

정규직교 스핀오비탈 6개에 같은 스핀 전자 3개를 넣은 설명용 1·2체 모형입니다. 점유 번호를 오름차순으로 쓴 행렬식의 규약을 고정합니다. 기준 점유는 1, 2, 3입니다. 에너지는 임의 단위로 표시합니다.

03 · 기억할 점

스스로 확인하기 · 직접 행렬원소가 0이면 두 배치가 전혀 섞일 수 없을까요?

직접 연결이 없다는 뜻입니다. 다른 배치를 거치는 간접 혼합은 가능할 수 있습니다.

조건과 수식

적분과 연결하는 수식: 정규직교 스핀오비탈 기저

스핀좌표(Coordinates)까지 포함한 오비탈을 χ로 쓰고, 이 절에서는 물리학자 순서의 적분을 먼저 정의합니다. 앞 페이지의 화학자 표기와 첨자의 순서를 혼동하지 마세요.

f_{pr}(x)=\chi_p^*(x)\chi_r(x)
\begin{aligned}v_{pqrs}&=\iint\frac{f_{pr}(x_1)f_{qs}(x_2)}{r_{12}}\\&\quad dx_1dx_2\end{aligned}

\langle pq\Vert rs\rangle=v_{pqrs}-v_{pqsr}는 항을 뺀 반대칭화 적분입니다. 모든 스핀이 α인 실수 공간오비탈이라면 \langle pq\Vert rs\rangle=(pr|qs)-(ps|qr)로 화학자 표기와 연결됩니다.

\hat H=\hat H_1+\hat H_2
\hat H_1=\sum_{pq}h_{pq}a_p^\dagger a_q
\begin{aligned}\hat H_2&=\frac14\sum_{pqrs}\langle pq\Vert rs\rangle\\&\quad\times a_p^\dagger a_q^\dagger a_s a_r\end{aligned}

대각 성분은 점유 오비탈의 \sum_i h_{ii}+\frac12\sum_{ij}\langle ij\Vert ij\rangle입니다. 단일 치환 i → a에는 h_{ai}+\sum_{j\in C}\langle aj\Vert ij\rangle가, 이중 치환 i,j → a,b에는 \langle ab\Vert ij\rangle가 기여합니다. C는 두 행렬식의 공통 점유 집합입니다. 비대각 성분에는 행렬식의 오비탈 순서에 따른 위상 부호도 곱합니다. 이 실험의 선택한 치환은 표시한 순서 규약에서 그 부호가 +1입니다.

실험의 모형과 선택규칙의 한계

아래에서만 첨자 p,q는 0부터 5입니다. 1전자 값은 대각 h_{pp}=-1+0.3p, 비대각 h_{pq}=0.12/(1+|p-q|)로 정했습니다. p < q인 쌍을 (0,1), (0,2), …, (4,5) 순서로 번호 매깁니다.

쌍 번호가 u,v인 반대칭화 적분은 같은 쌍에서 0.3+0.02(p+q), 다른 쌍에서 0.04/(1+|u-v|)로 정하고, 쌍 내부 순서를 바꾸면 부호를 뒤집습니다. 이는 선택규칙을 보여 주는 일반 2체 모형이며 실제 쿨롱 적분을 재현하지 않습니다.

세 개 이상 치환의 0은 같은 정규직교 스핀오비탈 집합으로 만든 행렬식과 최대 2체인 H에 대한 규칙입니다. 서로 다른 오비탈 집합이나 명시적 3체 항에는 그대로 적용할 수 없습니다. 직접 연결이 0이어도 다른 행렬식을 거치는 간접 혼합은 가능합니다. 핵 반발은 의 대각에 동일하게 더해지며 실험에서는 생략했습니다.
