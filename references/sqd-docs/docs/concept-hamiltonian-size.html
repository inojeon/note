적분 수와 상태 공간의 크기

적분은 계산할 수 있는데 왜 많은 전자의 상태는 어려울까?

먼저 알면 좋아요 · 큰 분자의 해밀토니안: 적분에서 VQE·SQD까지

01 · 정의와 핵심

의 적분 계수 수와 다전자 상태 공간의 은 서로 다른 양입니다. M개 의 1·에는 각각 M²·M⁴개의 첨자 조합이 있지만, N전자의 가능한 점유 배치 수는 M개 중 N개를 고르는 조합 수입니다.

02 · 예시와 실험

이렇게 살펴보세요40궤도·20전자와 더 작은 예를 비교하며 적분 수와 배치 수의 증가를 보세요.

실험 · 적분 계수와 상태 공간의 크기 비교

궤도와 전자 수를 선택하세요. 수치 규모를 비교하는 예이며 특정 분자를 지정한 것은 아닙니다.

첨자 조합 · M²
2전자 적분 첨자 조합 · M⁴
전자 수만 고정한 배치 수스핀 투영 조건을 추가하지 않은 수
α·β 전자 수까지 반반 고정 M/2개, α·β 전자 각각 N/2개

위 M²·M⁴는 대칭·스핀에 의한 0이나 압축을 적용하기 전 첨자 조합 수입니다. 계산 시간이나 독립적인 적분의 정확한 개수가 아닙니다. 상태 계수 저장량은 전자 수만 고정한 모든 배치에 실수 배정밀도 8바이트를 쓴 가정이며, 복소수 배정밀도는 두 배입니다. 프로그램의 추가 메모리는 제외합니다.

03 · 기억할 점

스스로 확인하기 · 40⁴는 독립적인 적분 수나 계산 시간인가요?

대칭과 0, 압축을 고려하기 전의 첨자 조합 수입니다. 독립 적분 수·메모리·실행 시간은 구현과 조건에 따라 달라집니다.

조합 수와 저장량 계산식

DN = M개 중 N개 선택

Dαβ = (M/2개 중 N/2개 선택)의 제곱

두 번째 식은 짝수 M·N과 α·β 전자 수가 같은 경우입니다. 스핀 투영을 고정하는 것과 전체 스핀의 고유상태만 선택하는 것은 다릅니다. 상태 계수 하나에는 D개의 수가 필요하며, 전체 조밀한 D×D 을 저장하면 D²개의 수가 필요합니다. 실제 프로그램은 대칭, 희소성, 분해 또는 행렬을 저장하지 않는 연산을 활용할 수 있습니다.
