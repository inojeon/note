대각화(Diagonalization)

기준을 바꾸면 행렬 계산이 단순해질까?

먼저 알면 좋은 개념: 기저(Basis)와 좌표(Coordinates) · 고유벡터(Eigenvector)와 고유값(Eigenvalue) · 대칭 행렬(Symmetric Matrix)

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

A를 P와 D를 이용해 A = PDP⁻¹로 나타내는 것을 라고 합니다. 이때 P의 열은 A의 이고 D의 은 대응하는 입니다.

쉽게 풀어 보면

고유벡터들을 새로운 로 선택하면, 변환은 각 에 고유값을 곱하는 계산이 됩니다. 같은 변환을 더 단순한 좌표로 표현하는 것입니다. 여기서 가역행렬은 이 존재하는 이고, 대각행렬은 대각선 밖 이 모두 0인 행렬입니다.

A = PDP⁻¹를 실제 숫자로 읽기

행렬을 누르면 역할과 성질을 확인할 수 있습니다. 오른쪽의 세 행렬을 곱하면 왼쪽 A가 됩니다.

=××

이름은 이 식에서의 역할을 강조한 것입니다. P만 가역인 것은 아니며, 이 예의 A와 D도 가역행렬입니다.

에 작용하는 순서는 오른쪽부터입니다.
P⁻¹: 고유벡터 좌표로 읽기 → D: 각 좌표를 3배·1배 → P: 원래 좌표로 돌려놓기.

정말 A가 되는지 곱셈으로 확인하기

이 P는 길이 1로 맞추지 않은 고유벡터를 사용합니다. 아래 회전 실험의 Q는 길이 1인 고유벡터를 사용합니다. 고유벡터의 길이나 부호를 다르게 골라도, 역행렬을 함께 맞추면 같은 A를 대각화할 수 있습니다.

45°에서 입력 방향을 바꿔 보세요. 첫 좌표는 언제나 3배, 둘째 좌표는 1배가 됩니다. 대각화는 벡터를 고유벡터로 만드는 일이 아니라, 변환을 고유벡터 기저에서 표현하는 일입니다.

수식으로 확인하기

A = PDP⁻¹, D = P⁻¹AP.
이 실험은 직교행렬 Q = [[cos θ, −sin θ], [sin θ, cos θ]]를 사용합니다. Q의 열은 회전한 단위 기저입니다.
Q⁻¹ = Qᵀ, B = QᵀAQ. θ = 45°에서 B = D = diag(3, 1)이고 A = QDQᵀ입니다.

적용 조건과 주의점

독립인 고유벡터가 충분해야 합니다. 모든 정사각행렬이 대각화되는 것은 아닙니다. 실수 은 항상 기저로 대각화할 수 있습니다.
