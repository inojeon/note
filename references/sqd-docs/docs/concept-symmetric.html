대칭 행렬(Symmetric Matrix)

행과 열을 바꿔도 같은 행렬은 왜 특별할까?

먼저 알면 좋은 개념: 행렬과 선형변환(Linear Transformation) · 내적(Inner Product)과 길이

정의

점선 밑줄 용어에 마우스를 올리거나 터치하면 뜻을 볼 수 있습니다.

실수 A가 해도 같아 Aᵀ = A를 만족하면 이라고 합니다. 으로는 모든 i, j에 대해 aᵢⱼ = aⱼᵢ입니다.

쉽게 풀어 보면

을 기준으로 마주 보는 수가 같습니다. 에 따라 실수 을 가지며, 를 선택할 수 있습니다. 그래서 수직인 축들에서 변환을 따로 이해할 수 있습니다.

작은 예시

A=2112는 대칭입니다. 11 방향은 3배, 1−1 방향은 1배가 됩니다. 두 방향의 은 0입니다.

수식으로 확인하기

Aᵀ = A. 복소수에서 대응하는 조건: A† = A (에르미트 행렬(Hermitian Matrix))

적용 조건과 주의점

대칭이라고 모든 고유값이 양수인 것은 아닙니다. 와 고유값의 뜻은 다음 개념에서 따로 설명합니다.

이어서 연결하기

정사각행렬(Square Matrix)행의 수와 열의 수가 같은 행렬입니다.간단한 예시행이 2개이고 열도 2개이므로 정사각행렬입니다.2112 ← 2×2크기가 n×n입니다. 고유값과 대각화를 다루는 기본 대상입니다.관련 개념 읽기 →전치(Transpose)행렬의 행과 열을 맞바꾸는 연산입니다.간단한 예시첫째 행의 1, 2가 첫째 열로, 둘째 행의 3, 4가 둘째 열로 옮겨집니다.A = 1234 → Aᵀ = 1324(Aᵀ)ᵢⱼ = Aⱼᵢ 복소수 행렬의 켤레전치는 이 연산에 복소켤레를 더한 것입니다.대칭 행렬(Symmetric Matrix)전치해도 원래와 같은 실수 정사각행렬입니다.간단한 예시대각선 양옆의 두 성분이 모두 1입니다. 행과 열을 바꿔도 같은 행렬입니다.A = 2112, Aᵀ = 2112Aᵀ = A성분(Component)좌표 벡터나 행렬의 개별 수입니다. 벡터 성분의 의미는 기저와 성분의 순서에 따라 달라집니다.간단한 예시아래 열벡터의 첫째 성분은 3, 둘째 성분은 4입니다.34성분이 3, 4인 평면 벡터에서 첫째 성분은 3입니다.관련 개념 읽기 →주대각선(Main Diagonal)행렬의 왼쪽 위에서 오른쪽 아래로 이어지는, 행·열 번호가 같은 위치들입니다.간단한 예시왼쪽 위 2에서 오른쪽 아래 5로 이어지는 방향이 주대각선입니다. 다른 두 수 7, 8은 그 밖에 있습니다.2785대칭 행렬은 이 선을 기준으로 마주 보는 성분이 같습니다.스펙트럼 정리(Spectral Theorem)실수 대칭 행렬은 정규직교 고유벡터 기저를 가지며, 그 기저에서 실수 대각행렬로 표현된다는 정리입니다.간단한 예시아래 대칭 행렬은 서로 수직인 단위 고유벡터 q₁, q₂를 가지며, 그 기저에서 대각 성분 3, 1로 표현됩니다.A = 2112; q₁ = (1/√2)11, q₂ = (1/√2)1-1; D = 3001A = QDQᵀ, QᵀQ = I 복소수 에르미트 행렬에서는 A = QDQ†입니다.고유값(Eigenvalue)고유벡터를 변환할 때 곱해지는 스칼라입니다.간단한 예시아래 고유벡터를 변환할 때 곱해지는 수 3이 그 벡터의 고유값입니다.A = 2112, A11 = 311 → λ = 3Av = λv에서 λ가 고유값입니다.관련 개념 읽기 →정규직교 고유벡터 기저(Orthonormal Eigenbasis)서로 직교하고 길이가 1인 고유벡터들로 구성한 기저입니다.간단한 예시이 대각행렬의 두 표준 기저 벡터는 각각 고유값 3, 1의 단위 고유벡터입니다. 서로 직교하며 평면의 기저를 이룹니다.A = 3001, q₁ = 10, q₂ = 01실수 대칭 행렬과 복소수 에르미트 행렬에는 이런 기저를 선택할 수 있습니다.내적(Inner Product)두 벡터에서 하나의 수를 만드는 연산입니다. 길이와 직교성을 정의하는 데 사용합니다.간단한 예시실수 표준 내적은 대응하는 성분의 곱을 더합니다.12 · 34 = 1×3+2×4 = 11실수 좌표의 표준 내적은 같은 위치 성분들의 곱을 더합니다.관련 개념 읽기 →고유벡터(Eigenvector)행렬로 변환한 결과가 원래 벡터의 수 배가 되는 0이 아닌 벡터입니다.간단한 예시이 벡터에 A를 곱하면 방향은 같고 크기만 3배가 됩니다.A = 2112, A11 = 33 = 311Av = λv, v ≠ 0관련 개념 읽기 →
